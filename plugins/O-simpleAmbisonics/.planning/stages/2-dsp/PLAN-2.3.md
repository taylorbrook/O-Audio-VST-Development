## The binaural control step (shared spec for T3 and T4 — the model must match it op-for-op)

```
prepare (fs):                                     (engine; before snapToParams)
  conv.prepare (fs)            // L, K, zpre, delay from fs; resample + DC-calibrate when fs ≠ 48 000 (C3);
                               // copy the header floats when fs == 48 000; spectra for the three sets; FDL (C14)

snapToParams():                                   (prepare / reset — after the 2.2 snaps)
  conv.reset()                 // in / prev / out / outB / FDL zeroed, head = 0
  conv.snapToSet (params.order)   // cur = order, pending = −1, queued = −1, fading = false, bankMix.snapTo (0), prevBank = curBank = 0
  binauralOnly = mixer.bothEndpointsAtOne()

controlStep():                                    (the 2.1 / 2.2 steps as now — through rot.build — then:)
  conv.arrive():       if (fading && curBank == 1):  cur = pending; pending = −1; fading = false; curBank = prevBank = 0
                                                     if (queued ≥ 0): q = queued; queued = −1; requestSet (q)
  conv.requestSet (params.order):   if (fading): queued = n                       // latest wins, every step
                                    else if (n != cur): pending = n; fading = true; bankMix.snapTo (0); prevBank = curBank = 0
  conv.step (kRampStep):
    prevBank = curBank; if (fading) curBank = bankMix.step (1, kRampStep)          // LinearRamp, exact arrival
    head = (head + K − 1) mod K                                                    // newest FDL slot
    for ch < 16:  tmp = [prev[ch] | in[ch] | 0 × 128];  prev[ch] = in[ch]
                  fft.performRealOnlyForwardTransform (tmp, true);  FDL[ch][head] = tmp[0 … 130)
    accumulate (set, dst):  dst[ear][0 … 130) = 0
                            for ch < (set+1)², k < K:  X = FDL[ch][(head + k) mod K];  H = spec[set][ch][ear][k]
                              dst[ear][2b] += Xr·Hr − Xi·Hi;  dst[ear][2b+1] += Xr·Hi + Xi·Hr   (b < 65, both ears)
                            fft.performRealOnlyInverseTransform (dst[ear]);  out/outB[ear] = dst[ear][64 … 128)
    accumulate (cur, acc) → out;   if (fading) accumulate (pending, accB) → outB
  binauralOnly = (mixer.prevMix == 1 && mixer.curMix == 1)                         // D3, one bool per grid
  fillFrameState()                                                                 // unchanged, no new field

renderSample (x, t, pos):                         pos = gridPos + j
  … bus → tap (2.2) → shPeak (unchanged)
  conv.push (tap, pos)                              // this grid's input, consumed by the NEXT step
  binL/R = fading ? out[ear][pos] + m·(outB[ear][pos] − out[ear][pos]) : out[ear][pos]
           m = prevBank + t·(curBank − prevBank)    // A3 form, float
  stereo decode → mixer.delayStereo (unchanged)
  binauralOnly ? (outL = binL, outR = binR) : mixer.blend (dL, dR, binL, binR, t, outL, outR)
```

Structural latency = exactly 64: the output written at step *s* is the convolution of the grid that just ended, emitted during grid *s*; `out[0 … 63] == 0` on the first grid. `arrive` before `requestSet` before `step` is mandatory (R10): a request sampled on the arrival step must see `fading == false`. Ramp arrivals at 48 k: 0 → 1 at step 15 (float); the band ramps' 1 → 0 arrive at 16 — one grid apart, both fades, recorded so nobody "fixes" it. `decoder` and `order` on the same step do not interact (independent ramps, independent legs; the convolver fades regardless of `decoder` — D12).

Reference twin (double): the same state machine with a **float** `bankMix` (C5); `bin[ear] = Σ_ch<(set+1)² Σ_t<L h[set][ch][ear][t] · hist[ch][n − 64 − t]` in double from the header floats widened (48 k) or from the engine's resampled table (`setExternalFilters`, fs ≠ 48 k); `snapBankFade` outputs the pending set from the request step (the state machine still arrives after the same number of steps). `snapCoefficientsPerGrid` / `snapOrderGains` untouched.
