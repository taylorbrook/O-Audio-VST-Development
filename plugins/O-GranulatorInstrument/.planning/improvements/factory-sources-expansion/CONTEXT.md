   - Display names (id = name in lower case with underscores): Guitar Overtones, Guitar Drift, Stream, Park, Waves, Woods, Garden, Crystal, Fire, Bubbles, Metal Grate, Stick Snaps, Scissors, Contrabassoon.
   - Acceptance: each embedded source decodes to the documented window at 48 kHz; per-source cap 3 MB; level within the spread of the existing 8.

3. **19 synthetic sources, as proposed in `BRIEF.md`**
   - Tonal: fm_bell, glass, bowed, reed, organ, choir, sub, saw_stack, chord_minor, chord_sus. Plucked / struck: kalimba, marimba_bar, metal_plate. Texture: wind, rain_synth, vinyl, shimmer. Rhythmic: clicks, pulse_triplet. Pitched ones at C3.
   - Research may rename or swap one if two render too alike; say so in RESEARCH.md.
   - Acceptance: generated by `tests/render-harness/factory_gen.cpp`, deterministic, pinned.

4. **A root per source, written by the Factory picker**
   - Every table entry carries a root (MIDI note + cents). The samples keep their native pitch; nothing is resampled for tuning.
   - Picking any source from the Factory list for lane N writes stream N's `sN_root_note` and `sN_root_fine` — every source, every pick (C3 / 0 ct for the C3 sources and the unpitched ones).
   - Roots are the sounding fundamental: Guitar Drift D2 (38) −10 ct; Guitar Overtones D2 (38) −10 ct (it is the harmonics of that D2); Crystal Db4 (61) +18 ct; Contrabassoon G#0 (20) −19 ct.
   - Contrabassoon: measured 2026-11-13 by autocorrelation at 25.6–25.7 Hz, steady over the note, which is G#0 −19 ct. The file name says −31; Taylor's answer read "931 cents flat of a G#0", taken as 31. Research re-measures and reports; if the two still differ by more than a few cents, Taylor picks.
   - Preset loads, session restores, file drops, browse and Record-in do not write the root. Clear does not reset it.
   - Acceptance: a harness row loads each off-C3 source through the picker path and reads back the two parameters; a pitch row shows the played key sounds at the key's pitch (class and octave) for the four off-C3 samples.

5. **Seamless long textures**
   - Stream, Park, Waves, Woods, Garden, Fire, Bubbles: the ingest folds about the last 0.5 s into the head with an equal-power crossfade, so a full-length loop region wraps without a dip. Pitched samples, one-shot collections and the contrabassoon keep plain 10 ms fades.
   - Acceptance: a seam row (level across the wrap within a stated tolerance, no click by the local-frame measure).

6. **Picker for 41 sources**
   - Still reached from an empty lane only (the 1.1.0 rule; a loaded lane is cleared first).
   - Categories (Tonal, Plucked / Struck, Voice, Texture, Drone, Rhythmic, Field), scroll, type-ahead, wider list; category names localized in fr / zh.
   - Acceptance: `ui_frontend_check.js`, check-i18n, fr / zh lint, three-language fit, keyboard path (arrows, type-ahead, Enter, Escape).

7. **Pipeline**
   - One manifest generates the `GiFactory.h` table (now with category and root), the CMake file list and the golden sha256.
   - Ingest script for samples: 48 kHz, level-matched to the existing 8, 16-bit for noisy material.
   - Embedded budget raised from 8 MB to about 24 MB; a size-budget row and a level-spread row in the harness.
