## Conventions (binding for Stage 1)

- **IDs are exact and case-sensitive.** Instanced IDs are literal: `s1_level` … `s4_level`, `menv1_attack` … `menv2_release`, `lfo1_rate` … `lfo4_mode`, `mod1_source` … `mod16_depth`, `macro1` … `macro4`. Generate them in a loop in a `*ParamIds.h`; Stage 1 adds a golden test that the generated list equals "Full ID list (registration order)" below.
- **`juce::ParameterID { id, 1 }`** (version hint 1) on every parameter — required for AU/VST3 parameter identity.
- **Registration order = the order of "Full ID list"** (the v1-ui.yaml control order). Host parameter indices follow it; never re-order.
- **Float ranges are `juce::NormalisableRange<float> (start, end, interval, skew)`** — interval 0 (continuous) unless the Type column says "interval 1". The WebView frontend receives ONLY start/end/skew/interval: **never use a lambda-mapped range** (critical_lambda_normalisable_range_invisible_to_webview_slider_frontend). Rows marked *log-like* call `range.setSkewForCentre (centre)`; the resulting skew is listed for checking.
- **Choice parameters are `juce::AudioParameterChoice`** with exactly the listed strings in exactly the listed order (the index is what sessions and presets store). Bools are `juce::AudioParameterBool`.
- **Host-facing names** are the "Name" column of the Full ID list (e.g. `S1 · Level`, `LFO 2 · Mode`); `modM_dest` choice strings are the destinations' host names.
- **Defaults are in engineering units** (Float), index (Choice) or On/Off (Bool). `getParameterDefaults` reports `convertFrom0to1 (getDefaultValue())` for every Float AND every Choice (the stepped knobs reset through it).
- **`sN_level` at −60 dB is −∞** (silence); the UI prints `−inf dB` at ≤ −59.95.
- **`sN_root_note`** is a Float with interval 1 (MIDI note 0…127; 60 = C4, so 48 = C3). The UI shows it as a note name; it never quantises the played key.
- **Mod dest** = the stored index of this parameter in the append-only modulation destination table (`modM_dest` choice value). `alias` rows are Tempo-mode division knobs: a drop onto them routes to the Free-mode destination named.
- **No parameter writes another parameter from a listener** (critical_vst3_nested_param_write_in_listener_never_reaches_host): solo is additive in the mixer; sync/free pairs both stay registered and bound; `sN_loop_start` > `sN_loop_end` is ORDERED in the DSP, never by writing the other parameter; `rec_arm` stays On after a capture (the run state Armed → Recording → Done is engine state, not a parameter).
- **Actions are native functions, not parameters** (Load / Relink / Clear / Reset slot, Reset all, Embed toggle, Save recording) — see "Plugin state & native functions".

### Feedback network (5)

**Design Sync S3:** same ID / range / default as O-Granulator, new semantics. λ = 0.95 · (feedback / 100) is the CONVEX write amount per record-head lap: `wc' = (1 − λ)·wc + λ·r`. It is not a loop gain; the copy never exceeds max(pristine peak, 0.7) for any voice count (ARCHITECTURE §3). The feedback writes into each stream's WORKING COPY at a 1× record head (D7). **S4 (`freeze`):** the record heads stop, nothing is written, the chains stay warm and their returns are discarded.

| ID | Type | Range / choices | Default | Skew | Mod dest | Description |

| `fb_low_cut` | Float | 20 … 2000 Hz | 80 Hz | log-like: `setSkewForCentre (200)` → skew 0.28906 | 115 | High-pass filter on the grains written back into the working copies. |
| `fb_high_cut` | Float | 1000 … 20000 Hz | 12000 Hz | log-like: `setSkewForCentre (4472.136)` → skew 0.40781 | 116 | Low-pass filter on the grains written back into the working copies. |

### `<Slots>` — Design Sync S9 / S10 (one `<Slot index="1…4">` child each)

| Key | Type | Default | Notes |
|-----|------|---------|-------|
| `source` | String | `""` (empty slot) | Scheme `factory:<id>` (S10) · `file:<absolute path>` · `rec:<absolute path>` (the 32-bit float WAV Record-in writes under `userMusicDirectory/Ouaricon/O-GranulatorInstrument/Recordings/`). Missing file → the lane shows "relink". |
| `name` | String | `""` | Display name (user text, never localized). |
| `embed` | bool | **on** for `rec:`, **off** for `file:`; ignored for `factory:` | Opt-in per slot (S11 lane Embed tool). |
| `embedded` | base64 FLAC-24 blob (optional) | absent | Present only when `embed` is on. **Cap: 16 MB encoded per slot** — above it the slot cannot be embedded (the UI says "too large to embed") and only the path is stored. |
| `fileSize` | int64 (bytes) | 0 | For relink matching. |
| `contentHash` | String (hex) | `""` | xxHash64 of the first 1 MB of decoded PCM, for relink matching. |
| `rootNoteHint` | — | not written in v1 | Reserved key name (ARCHITECTURE); v1 never writes it. |
| `trimmed` | bool | false | The source was longer than the slot maximum and only its first 30 s was loaded (S8). |
| *(not saved)* working copy | — | — | Reload restarts every working copy from its pristine source (feedback writes are not persisted). |

**Slot maximum (S8 / D2):** 30 s per slot with a hard cap of 2,880,000 frames (30 s up to 96 kHz, 15 s at 192 kHz). A longer file is loaded trimmed (`trimmed` = true).

**Resolve order on load (ARCHITECTURE "State Persistence"):** absolute path (exists and size matches) → embedded blob → filename + hash search in the Recordings folder → `factory:` → **missing** (slot empty, lane "relink", plugin stable). `setStateInformation` only parses and enqueues loader jobs; it never decodes inline.

**Factory sources (S10):** embedded BinaryData FLAC, addressed as `factory:<id>`, each ≤ 8 MB. Always resolvable, never embedded into the session, never "relink".

**Final pitch clamp (S6):** after key tracking and every offset, grain pitch is clamped to **±48 semitones** (MipTape L = 4). No parameter.

## Design Sync applied (ARCHITECTURE.md S1–S11)

- **S1** `grain_limit` = 4 choices 32 / 64 / 128 / 256, default index 3 (256). The draft's 512 entry is dropped (D3: ≈ 62 % of a core).
- **S2** `pitch_bend_range`: non-MPE applies to every note; under MPE it is the master-channel range only, and member channels use RPN 0 (default 48 semitones, MPE spec). Description change only.
- **S3** `feedback`: λ = 0.95 · x, the convex write amount per record-head lap (not a loop gain). Description change only.
- **S4** `freeze`: the record heads stop; the chains stay warm and their returns are discarded.
- **S5** `sN_position`: start point inside the loop region AND the live read centre (modulatable).
- **S6** Final pitch clamp ±48 semitones after key tracking and all offsets. No parameter.
- **S7** Newest-voice rule for per-voice sources on global destinations (D4); the matrix marks such rows "mono". Lists unchanged (126 destinations, 18 sources).
- **S8** Slot maximum 30 s (15 s at 192 kHz); `rec_length` / `rec_length_sync` capped at it; longer files load trimmed.
- **S9** `<Slots>` keys `embed`, `fileSize`, `contentHash`, `trimmed`; source schemes `factory:` / `file:` / `rec:`; embed cap 16 MB FLAC-24 per slot.
- **S10** Factory sources are embedded BinaryData FLAC, `factory:<id>`, ≤ 8 MB.
- **S11** Embed toggle per slot = native function `setSlotEmbed` → state.

## Draft vs mockup

Every ID, type, range, default, skew, interval and choice order in the draft equals the finalized v1-ui.yaml, except the Design Sync items above. One DESCRIPTION-level conflict is recorded, not silently resolved:

1. **`polyphony` steal wording.** Draft: "steals the oldest *or quietest* voice with a fade". v1-ui.yaml tooltip: "steals the oldest voice with a fade". ARCHITECTURE §3 decides the policy (oldest-first, protecting the lowest and highest held notes, preferring released voices; the quietest of the 4 steal spares is ended only when all spares are still fading). This spec carries the mockup wording; the behaviour is ARCHITECTURE §3 either way. Confirm or amend at Stage 1 planning.
