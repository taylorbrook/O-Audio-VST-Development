# Resume Point

## Current State: Phase 2.8 Complete - Tuning Engine Implemented

Phase 2.8 (Tuning Engine) is complete. OuariconLyrica now has a flexible tuning system that converts MIDI notes to frequencies with support for custom A4 reference frequency (masterTune parameter: 400-480 Hz) and per-note pitch bend (pitchBendRange parameter: 1-48 semitones). The TuningEngine uses 12-TET as the baseline tuning system and provides scale frequency retrieval for the future glissando controller. MIDI pitch wheel messages now control pitch bend in real-time. Optional features (MTS-ESP and Scala file loading) are stubbed for future implementation.

## Key Architecture Decisions

- **Core Algorithm:** Bidirectional Digital Waveguide Synthesis
- **Polyphony Target:** 16-32 voices at <50% CPU
- **String Model:** Dual delay lines with bridge/nut filters + stiffness allpass
- **Sympathetic Resonance:** Frequency-domain coupling with material-based intensity
- **Body Resonance:** 50-100ms convolution IR (with modal fallback)
- **Tuning:** MTS-ESP + Scala + 12-TET fallback
- **Glissando:** Free (continuous) and Scale-Locked (stepped) modes
