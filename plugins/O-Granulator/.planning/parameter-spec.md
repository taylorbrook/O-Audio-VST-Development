## Conventions (binding for Stage 1)

- **IDs are exact and case-sensitive.** Instanced IDs are literal: `s1_level` … `s4_level`, `lfo1_rate` … `lfo4_rate`, `mod1_source` … `mod16_depth`, `macro1` … `macro4`, `pitch_follow_s1` … `pitch_follow_s4`. Generate them in a loop in `GranulatorParamIds.h`; Stage 1 adds a golden test that the generated list equals "Full ID list (registration order)" below.
- **`juce::ParameterID { id, 1 }`** (version hint 1) on every parameter — required for AU/VST3 parameter identity.
- **Registration order = the order of "Full ID list"** (the YAML control order). Host parameter indices follow it; never re-order.
- **Float ranges are `juce::NormalisableRange<float> (start, end, 0.0f, skew)`** — interval 0 (continuous) unless stated. The WebView frontend receives ONLY start/end/skew/interval: **never use a lambda-mapped range** (critical_lambda_normalisable_range_invisible_to_webview_slider_frontend). Rows marked *log-like* call `range.setSkewForCentre (centre)` with the geometric mean as centre; the resulting skew is listed for checking.
- **Choice parameters are `juce::AudioParameterChoice`** with exactly the listed strings in exactly the listed order (the index is what sessions and presets store). Bools are `juce::AudioParameterBool`.
- **Defaults are in engineering units** (Float), index (Choice) or On/Off (Bool). `getParameterDefaults` reports `convertFrom0to1 (getDefaultValue())` for every Float and Choice.
- **`sN_level` at −60 dB is −∞** (silence); the UI prints `−inf dB` at ≤ −59.95.
- **Mod dest** = the stored index of this parameter in the append-only modulation destination table (`modM_dest` choice value). `alias` rows are Tempo-mode division knobs: a drop onto them routes to the Free-mode destination named.
- **No parameter writes another parameter from a listener** (critical_vst3_nested_param_write_in_listener_never_reaches_host): solo is additive in the mixer; sync/free pairs both stay registered and bound.

**PitchCollections is extracted, not forked.** O-GrainScatter's `PitchCollections` (Id enum, names, `builtIns()` tables, `Table`, `parsePitch`, `tableFromPitches`, `tableFromText`, `tableFromScala`) moves from `plugins/O-GrainScatter/Source/dsp/PitchEngine.h` into a shared module, **provisional path `modules/tuning/pitch-collections`**, during implementation. The module gains the `edo N [period]` shorthand (error `badEdo`, GrainScatter gets it too), a `tableFromText` overload that reports the offending token, and `toScala (name, text)`. O-Granulator maps its choice index → Id at the parameter boundary (0 Off, 1…5 → 0…4, 6…31 → 6…31). Max 64 degrees (`kMaxPitches`). Do not copy the file into `plugins/O-Granulator/Source/`.
