  <name>Task 2: Create PluginProcessor with APVTS and pass-through</name>
  <files>plugins/OBass/Source/PluginProcessor.h, plugins/OBass/Source/PluginProcessor.cpp</files>
  <action>
Create the main audio processor following OuariconComp pattern:

**PluginProcessor.h:**
- Class: OBassAudioProcessor inheriting from juce::AudioProcessor
- Include juce_audio_processors and juce_dsp headers
- AudioProcessorValueTreeState member named `parameters`
- Private static createParameterLayout() method
- Standard AudioProcessor overrides (prepareToPlay, processBlock, etc.)
- DSP spec member: juce::dsp::ProcessSpec spec
- Placeholder comments for: crossover filter, mono summer, intermediate buffers

**Initial parameters (create now, will be used later):**
- crossover_freq: NormalisableRange 40-200Hz, default 80Hz, skew for frequency
- latency_mode: AudioParameterChoice with "Low Latency", "High Fidelity" (default Low Latency)
- bypass: AudioParameterBool, default false

**PluginProcessor.cpp:**
- Implement createParameterLayout() with above parameters
- Constructor: stereo input/output buses, initialize APVTS
- prepareToPlay: Store spec (sampleRate, blockSize, numChannels)
- processBlock:
  - ScopedNoDenormals at start
  - Check bypass parameter - if true, return immediately (true bypass)
  - For now, just pass audio through (no processing)
- Standard state save/load using APVTS (getStateInformation/setStateInformation)
- Factory function createPluginFilter()

Do NOT include OuariconPresetManager yet (added in Phase 6).
  </action>
  <verify>grep -l "class OBassAudioProcessor" plugins/OBass/Source/PluginProcessor.h</verify>
  <done>PluginProcessor.h/.cpp exist with APVTS, parameters, and pass-through processBlock</done>
