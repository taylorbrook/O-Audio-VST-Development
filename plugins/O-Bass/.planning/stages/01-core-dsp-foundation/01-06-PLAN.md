**Header changes (CrossoverFilter.h):**
1. Add `#include <atomic>` at top
2. Replace `Mode currentMode = Mode::LowLatency` with `std::atomic<Mode> activeMode { Mode::LowLatency }` for RT-safe reads
3. Keep `currentMode` as a non-atomic variable for tracking the "committed" mode during prepare()

**Implementation changes (CrossoverFilter.cpp):**

**prepare() function:**
1. Always call both IIR and FIR preparation (already does IIR, already does FIR)
2. After calling `precomputeFIRBank()`, synchronize `currentFirIndex = pendingFirIndex` and call `loadFilterAtIndex(currentFirIndex)` to ensure FIR is always ready
3. Sync `pendingFirIndex` to `currentFirIndex` so FIR is always at the desired frequency

**setMode() function - THE KEY CHANGE:**
Replace the entire function body with:
```cpp
void CrossoverFilter::setMode(Mode newMode)
{
    // RT-SAFE: Just flip the atomic flag
    // Both IIR and FIR filters are always prepared and ready
    activeMode.store(newMode, std::memory_order_release);
}
```

Remove ALL allocation logic from setMode():
- Remove the `if (currentMode != newMode)` block
- Remove `iirLowpass.reset()`, `iirHighpass.reset()`, `updateIIRFilters()` from this function
- Remove `firLowpass.reset()` from this function
- Remove the `if (pendingFirIndex != currentFirIndex)` check and `loadFilterAtIndex()` call

**getMode() function:**
Change to read from atomic: `return activeMode.load(std::memory_order_acquire);`

**process() function:**
Change `if (currentMode == Mode::LowLatency)` to `if (activeMode.load(std::memory_order_acquire) == Mode::LowLatency)`

**setCutoffFrequency() function:**
Change `if (currentMode == Mode::HighFidelity)` to `if (activeMode.load(std::memory_order_acquire) == Mode::HighFidelity)`

**getLatencyInSamples() function:**
Change `if (currentMode == Mode::LowLatency)` to `if (activeMode.load(std::memory_order_acquire) == Mode::LowLatency)`

**reset() function:**
Reset BOTH filter paths regardless of mode (both are always ready):
```cpp
void CrossoverFilter::reset()
{
    iirLowpass.reset();
    iirHighpass.reset();
    firLowpass.reset();
    smoothedCutoff.setCurrentAndTargetValue(targetCutoffHz);
}
```
