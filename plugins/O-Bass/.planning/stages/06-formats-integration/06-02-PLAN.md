  <action>
    Build OBass in Release configuration and install to system plugin folders.

    **Build:**
    ```bash
    cd /Users/taylorbrook/Dev/VST-development/build
    ninja OBass_VST3 OBass_AU
    ```

    **Clear AU cache and install:**
    ```bash
    killall -9 AudioComponentRegistrar 2>/dev/null || true
    rm -rf ~/Library/Caches/AudioUnitCache/
    rm -rf ~/Library/Caches/com.apple.audiounits.cache

    rm -rf ~/Library/Audio/Plug-Ins/VST3/OBass.vst3
    rm -rf ~/Library/Audio/Plug-Ins/Components/OBass.component

    cp -R build/plugins/OBass/OBass_artefacts/Release/VST3/OBass.vst3 ~/Library/Audio/Plug-Ins/VST3/
    cp -R build/plugins/OBass/OBass_artefacts/Release/AU/OBass.component ~/Library/Audio/Plug-Ins/Components/
    ```

    **Verify installation:**
    ```bash
    ls -la ~/Library/Audio/Plug-Ins/VST3/OBass.vst3
    ```

<task type="auto">
  <name>Task 2: Run pluginval Validation</name>
  <files></files>
  <action>
    Run pluginval at strictness level 5 (minimum for compatibility) on VST3:

    ```bash
    /Applications/pluginval.app/Contents/MacOS/pluginval \
      --strictness-level 5 \
      --validate ~/Library/Audio/Plug-Ins/VST3/OBass.vst3
    ```

    If validation fails:
    - Check output for specific test failures
    - Common issues: parameter listener leaks, state restore failures, threading problems
    - Fix issues and re-run Plan 01 if code changes needed

    If validation passes at level 5, try level 10 for comprehensive testing:
    ```bash
    /Applications/pluginval.app/Contents/MacOS/pluginval \
      --strictness-level 10 \
      --validate ~/Library/Audio/Plug-Ins/VST3/OBass.vst3
    ```
  </action>
  <verify>pluginval output shows "ALL TESTS PASSED" or lists any failures</verify>
  <done>pluginval validation completed at strictness 5+ without failures</done>
</task>

<task type="auto">
  <name>Task 3: Run auval Validation</name>
  <files></files>
  <action>
    Run Apple's Audio Unit validation tool:

    ```bash
    auval -v aufx OuBa OuAu
    ```

    OBass is an effect plugin (aufx), not an instrument (aumu).
    Manufacturer code: OuAu (Ouaricon Audio)
    Plugin code: OuBa (OuBass)

    Expected output sections:
    - Validation of AU Component
    - Audio Unit Test Result (should show PASS)

    If validation fails:
    - "Component instantiation timed out" -> constructor doing I/O (shouldn't happen with v1.5.0 preset manager)
    - Parameter validation errors -> check parameter ranges
  </action>
  <verify>auval output ends with "AU VALIDATION SUCCEEDED" or similar pass message</verify>
  <done>auval validation passed for AU format</done>
</task>
