**In processBlock(), after mono summing and before recombine:**

Replace the current cleanModeProcessor.process() call with dual-path processing:

```cpp
// Update crossfade target based on mode parameter
float modeValue = modeParam->load();
modeCrossfade.setTargetValue(modeValue);  // 0.0 = Clean, 1.0 = Colored

// Set enhance amount on both processors
float enhance = smoothedEnhance.getNextValue();
cleanModeProcessor.setEnhanceAmount(enhance);
coloredModeProcessor.setEnhanceAmount(enhance);

// High-band energy for spectral blending (both processors use same value)
float highEnergy = calculateHighBandEnergy(highBandBuffer);
cleanModeProcessor.setHighBandEnergy(highEnergy);
coloredModeProcessor.setHighBandEnergy(highEnergy);  // If ColoredModeProcessor has this method

// Copy mono buffer for colored processing
coloredBuffer.makeCopyOf(monoBuffer);

// Process both paths
cleanModeProcessor.process(monoBuffer);      // Clean result in monoBuffer
coloredModeProcessor.process(coloredBuffer); // Colored result in coloredBuffer

// Crossfade between paths
float* cleanData = monoBuffer.getWritePointer(0);
const float* coloredData = coloredBuffer.getReadPointer(0);

for (int i = 0; i < monoBuffer.getNumSamples(); ++i)
{
    float blend = modeCrossfade.getNextValue();
    cleanData[i] = cleanData[i] * (1.0f - blend) + coloredData[i] * blend;
}
```

**Important considerations:**
- Both processors run during crossfade (20ms), then only active one matters
- SmoothedValue handles the per-sample interpolation
- Output is in monoBuffer, which continues to stereo expand and recombine
