## Context to Preserve

**Architecture Highlights:**
- 4 independent RepeatLane instances (circular buffer per lane)
- TriggerRouter with 5 modes (beat sync, envelope, sidechain, manual, MIDI)
- TapeDegrader (6 effects: saturation, wow, flutter, hiss, rolloff, dropout)
- PatternSequencer (16-step gate per lane, 64 total steps)
- PitchShifter (resampling MVP, phase vocoder future enhancement)
- SwingEngine (timing offset calculation)

**Critical Implementation Notes:**
- Use juce::dsp::DelayLine for circular buffers (NOT custom implementation)
- AudioPlayHead::getPosition() for PPQ tracking (check has_value())
- 5ms crossfade at all loop boundaries (click-free)
- Per-lane freeze buffers (4 separate buffers)
- Post-mix tape degradation (single instance, not per-lane)
- MIDI notes C3-F3 trigger lanes 1-4, G3 all lanes, A3 freeze

**High-Risk Areas:**
1. Pitch shifting (use resampling for MVP, not phase vocoder)
2. CPU budget (4 lanes = target <15%, lazy evaluation essential)
3. Tempo change mid-playback (lock BPM on trigger start)

**Module Dependencies:**
- juce_dsp (REQUIRED for DelayLine, BallisticsFilter, all DSP components)
- juce_gui_extra (REQUIRED for WebBrowserComponent)
- juce_audio_basics (REQUIRED for AudioPlayHead, MidiBuffer)

**CMakeLists.txt Requirements:**
- NEEDS_MIDI_INPUT TRUE
- NEEDS_WEB_BROWSER TRUE
- IS_SYNTH FALSE (it's an effect, not instrument)
- Sidechain bus: `.withInput("Sidechain", stereo, false)` (optional)
- juce_generate_juce_header() MUST be called after target_link_libraries()
