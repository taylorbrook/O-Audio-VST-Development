# DSP Architecture: O-simpleWavetable

**CRITICAL CONTRACT:** This specification is immutable during Stages 1-4. Stage 1 (Foundation) cannot proceed without it. Stage 2 (DSP) implements this architecture. Stage 3 (GUI) implements the visual handoff described here.

**Generated by:** Stage 0 Research & Planning (2026-10-05)
**Plugin type:** Synth (pedagogical wavetable). MIDI in, stereo out (mono signal duplicated), 16-voice poly or mono, WebView UI.
**Sibling anchors:** O-simpleAdditive (voice model, `VizRing`, lead-voice snapshot, output stage, WebView CMake), O-simpleSubtractive (Mono last-note path `renderMonoLegato`, ±2 st pitch bend), O-Prism (`WavetableData` flat layout, FFT mipmap builder, `WavetableImporter` hardening, `NoteDiv` table, generation reaper with entry/exit counters, REG-01), O-simpleGrain (`webview-drop-streaming` + `FileChooser` import UX, state child tree pattern).

All JUCE classes below were checked against the pinned local JUCE **8.0.15** at `/Users/taylorbrook/JUCE/modules/` and, where available, Context7 (`/websites/juce_master`).

## Complexity & Research Summary

- **Tier: 5.** It is a Tier 4 synth (MIDI, oscillator, voices). File I/O (audio import), embedded binary state, and a first-class live visualization raise it to Tier 5/6. **Research depth: DEEP**, but most infrastructure is inherited from siblings. The new work is the bank and mipmap engine, the latched/crossfaded frame read, the import→state pipeline, and the frozen-cycle swap crossfade.
- **Numerical verification done in Stage 0:** a Python/numpy model of the oscillator (2048-point table, the mip scheme below, linear vs 4-point Hermite read). It was measured with a Blackman-Harris window over 1 s at MIDI 21–108 and fs 44.1/48/96 kHz. Results are in Algorithm Details §A2. The Drive-bank gain law was also swept for monotonicity (§A4).

### Resolved open questions (one line each; detail in the sections below)

| # | Question | Decision |
|---|----------|----------|
| 1 | In-cycle phase interpolation | **Linear** with 1 guard sample. Measured worst alias is −74 dB (A0); about −90 dB or lower from C3 up; −121 dB at C8. Cubic only helps below C3 and is not needed for QUAL-02. |
| 2 | Mipmap scheme | **11 levels** L=0..10, `Kmax_L = min(1023, 1024 >> L)`. Built by FFT truncation (DC and Nyquist bins zeroed). Strict level `L = clamp(ceil(log2(f·2048/fs)), 0, 10)`, so no harmonic ever exceeds Nyquist. *(Amended 2026-10-05, see §Stage 2 Amendments.)* **No continuous inter-level crossfade.** A level change (pitch bend, or a sample-rate change) fires the 5 ms frozen-cycle crossfade instead. Prism-style trilinear crossfade (one level too rich) measured −15.6 dB alias at C8, so it is rejected. |
| 3 | Sine→Square formulation | Reaches **h31 on frame 32**. 16 odd harmonics are spread over 31 frame steps with a fractional "frontier" harmonic, so every frame is distinct and the 1–32 graph changes on every frame. |
| 4 | Formant bank | Male vowel averages (Peterson & Barney 1952) for **A→E→I→O→U**. Three cascade resonators, B = 90/110/170 Hz. Formant frequencies are interpolated in log-frequency between anchors at frames 1, 8.75, 16.5, 24.25 and 32. Source is 1/n, harmonics 1..48. **Reference fundamental f_ref = 110 Hz**, so F1–F3 (≤ 3010 Hz) land inside harmonics 1–32 of the graph. |
| 5 | Drive bank | `tanh(g·sin)/tanh(g)`, `g_k = 0.25·100^((k−1)/31)` (−12 dB → +28 dB drive). Verified: frame 1 has h3 at −46 dB; h3, h5, h7 and THD are all strictly monotonic. |
| 6 | Pulse Width bank | Band-limited Fourier pulse (1023 harmonics). Duty `d_k = 0.5·(1/16)^((k−1)/31)` (50% → 3.125%). The first spectral null moves from h2 to h32. |
| 7 | RT-safe bank swap | Built-ins are immutable, process-wide and never freed (`SharedResourcePointer`). The imported bank is published by an `std::atomic<const WavetableBank*>` and retired through Prism's **generation reaper (entries/exits, REG-01)**. Click-free behaviour comes from a per-voice **frozen-cycle crossfade** (5 ms), so no voice holds an old bank across blocks. |
| 8 | Import pipeline | Background job: `AudioFormatManager` → read ≤ 256·2048 samples → average channels to mono → slice into 2048-sample frames (tail dropped) → per frame: DC/Nyquist removal by FFT, peak-normalize with a +24 dB cap → **quantize to int16** → build mips from the int16 data → `callAsync` publish. *(Amended 2026-10-05, see §Stage 2 Amendments.)* Files shorter than 2048 samples are rejected with a message. |
| 9 | State encoding | `IMPORTED_BANK` child: filename, frame count, `encoding="flac16"`, base64 of **mono 16-bit FLAC** of the concatenated level-0 frames (≈ 0.4–0.8 MB worst case). Encoded once at import and cached. Reload is bit-identical because the live bank is built from the same int16 data. |
| 10 | "Imported" selected with no import | Oscillator outputs **silence** (null bank; envelopes and voices still run). The UI shows an empty stack with "Import audio to fill this bank" and highlights the Import button. A successful import auto-selects Bank = Imported. *(User sign-off requested: see Open Conflicts.)* |
| 11 | Bit-depth quantizer | **Mid-rise**, sign-symmetric: levels ±(i+½)/2^(b−1), i=0..2^(b−1)−1, so **3 bits = exactly 8 levels**. Full = early-out bypass (bit-identical). Choice param: Full, 16 … 3 (15 entries). |
| 12 | LFO sync | **Separate `lfo_div` choice** (16 divisions, default 1/1). The UI swaps the Rate knob for the Division knob when Sync = Tempo. Tempo mode phase-locks to host PPQ while playing and free-runs at host BPM (or 120) otherwise. One global phase, never reset by notes. |
| 13 | S&H | New uniform value in [−1, 1] at each LFO cycle wrap, from a `juce::Random` re-seeded in `prepareToPlay` (deterministic offline renders). |
| 14 | Position smoothing | Knob: `SmoothedValue` linear 20 ms. Then **per voice**, with Interpolation On, a one-pole smoother on the summed effective position (τ = 2 ms). It removes clicks from LFO square/saw/S&H edges and zero-time envelope segments, and is seeded at note-on (no glide from the previous note). |
| 15 | Interpolation Off with modulation | Frame index `round(effPos·(N−1))` is **latched at each cycle wrap** (and at note-on). Modulation therefore steps cycle-by-cycle. For the sine-phase built-in banks the step happens where the waveform passes through 0, so the step is a timbre change, not a click. |
| 16 | Output Level −inf | Float −60..+6 dB, default −6. `Decibels::decibelsToGain(db, −60)` gives exactly 0 at the floor. The text function shows "-inf" at ≤ −60 (sibling convention; no lambda-defined range, see project memory on lambda ranges and the WebView). |
| 17 | Visual handoff | Audio thread publishes **atomics only** (lead voice's effective Position, mip level read, latched frame, sounding flag, bank generation). The **message-thread** 30 Hz timer re-renders the exact cycle from the immutable bank (built-ins: the shared array; Imported: **only** through `getImportedBankSnapshot()`, a `shared_ptr` copy taken under `bankStateLock`, never the raw atomic — *amended 2026-10-06, see §Stage 2 Amendments 12*), applies the quantizer, and runs a 2048-point real FFT (periodic, so no window; bins 1..32 are harmonics 1..32 exactly). The bars equal an offline FFT of the heard cycle by construction. |
| 18 | Pitch bend | ±2 semitones (O-simpleSubtractive convention). Feeds mip-level selection. *(Not in the brief; flagged.)* |

## Core Components

### 1. Bank Data (`WavetableBank`)
- **JUCE Class:** Custom immutable struct (flat `std::vector<float>`; layout lifted from O-Prism `WavetableData`).
- **Purpose:** One bank = N frames × 11 mip levels × (2048 + 1 guard) floats, plus metadata (name, frameCount, per-frame thumbnail for the UI).
- **Parameters Affected:** `bank`.
- **Configuration:**
  - `kTableSize = 2048`, `kGuard = 1` (guard sample = sample 0), `kLevels = 11`, `kMaxFrames = 256`, `kBuiltInFrames = 32`.
  - Index: `data[((level·numFrames) + frame)·2049 + i]`.
  - Memory: built-in 32 frames ≈ 2.9 MB per bank (5 banks ≈ 14.4 MB, shared process-wide). Imported 256 frames ≈ 23 MB (up to 46 MB briefly during a swap).
  - **Immutable after publish.** This is what makes lock-free audio reads and message-thread UI reads safe.
  - Optional memory optimisation (Stage 4, only if needed): levels whose `Kmax` is at or above the bank's highest non-zero harmonic are byte-identical. Sine→Saw/Square/Formant could share levels 0..5 by pointer.

### 2. Built-in Bank Generators (`BankFactory`)
- **JUCE Class:** Custom. Spectral construction + `juce::dsp::FFT` (juce_dsp) for the time-domain Drive formula. Shared via `juce::SharedResourcePointer<BuiltInBanks>` so all plugin instances in a process share one 14 MB copy.
- **Purpose:** Generate the five 32-frame lesson banks at load time from formulas (no shipped audio).
- **Parameters Affected:** none (static data). The `bank` choice selects one.
- **Configuration:** Every built-in frame is defined as a **sine-phase harmonic amplitude vector** `b_n` (n = 1..1023), except Drive, which is computed in time and FFT'd. All are then sent through the Mipmap Builder. The formulas are in Algorithm Details §A3–A6.
  - Bank order (param index): 0 Sine→Saw, 1 Sine→Square, 2 Pulse Width, 3 Formant, 4 Drive, 5 Imported.
  - Each frame: DC removed (bin 0 = 0); level 0 peak-normalized to **1.0** (DSP-04: common peak, ±0.5 dB trivially met).
  - Build cost ≈ 5 × 32 × (1 FFT + 11 IFFT) ≈ 1,900 2048-point transforms. That is tens of ms, done once per process on first construction, synchronously, so banks are always ready for pluginval and the first note.

### 3. Mipmap Builder
- **JUCE Class:** `juce::dsp::FFT` (order 11), `performRealOnlyForwardTransform` / `performRealOnlyInverseTransform` (juce_dsp; inverse is scaled by 1/N internally, verified in `juce_FFT.cpp`). Port of O-Prism `buildFrameMipmaps`, with **two fixes**: zero the Nyquist bin at every level, and `Kmax_0 = 1023`.
- **Purpose:** Per frame, produce 11 band-limited copies; level L keeps harmonics 1..`Kmax_L`.
- **Configuration:** `Kmax_L = min(1023, 1024 >> L)`: 1023, 512, 256, 128, 64, 32, 16, 8, 4, 2, 1. Zero bins `> Kmax_L` (positive and mirrored negative halves, as in Prism), zero the DC and Nyquist bins, IFFT, write, then set guards. **Level peaks are not re-normalized** (re-normalizing would make loudness depend on pitch). The quantizer clamps any Gibbs overshoot.
- Runs **only** off the audio thread: at construction for built-ins, and on the import/restore worker for the imported bank.

### 4. Wavetable Oscillator (inside `WtVoice`)
- **JUCE Class:** Custom (phase accumulator in double, linear in-cycle read, frame crossfade or latch).
- **Purpose:** FUNC-01, DSP-01, DSP-02. Read the cycle at the note's pitch from the frame(s) at the effective Position.
- **Parameters Affected:** `position` (via effective position), `interp`, `bandlimit`, `bank`.
- **Configuration (per sample):**
  ```
  inc     = f / fs                       // f = midiHz(note) · 2^(bend/12), clamped < 0.5·fs
  idx     = phase · 2048; i0 = (int) idx; t = idx − i0       // i0 clamped ≤ 2047 (Prism IN-08)
  read(fr)= lerp(tab[L][fr][i0], tab[L][fr][i0+1], t)        // guard sample makes i0+1 safe
  Interp On : fp = effPos·(N−1); f0 = floor(fp); f1 = min(f0+1, N−1)
              s  = lerp(read(f0), read(f1), fp − f0)
  Interp Off: s  = read(latchedFrame)  // latchedFrame = round(effPos·(N−1)), updated at phase wrap and note-on
  phase += inc; if (phase >= 1) { phase -= 1; latch… }
  ```
  - **Level L:** `bandlimit` On → `clamp(ceil(log2(f·2048/fs)), 0, 10)`, recomputed per block (and on a pitch-wheel event). *(Amended 2026-10-05, see §Stage 2 Amendments.)* `bandlimit` Off → L = 0 (all 1023 harmonics: the intended aliasing).
  - Phase is reset to 0 at note-on (sine-phase frames start at 0, so there is no onset click and the envelope does the rest). Phase is never reset mid-note.

### 5. Frozen-Cycle Crossfader (per voice)
- **JUCE Class:** Custom (two preallocated `float[2049]` buffers per voice, ping-pong).
- **Purpose:** QUAL-03. Click-free transitions for every discontinuous read-config change. One mechanism covers all of them.
- **Triggers (detected per block, or at a MIDI sub-block boundary):** bank pointer changed (bank param, import publish, Imported→empty), `bandlimit` toggled, mip level changed, `interp` toggled.
- **Configuration:** on a trigger, the voice renders its *current output cycle* (old config at the current frame mix; if a crossfade is already running, the current *mixed* cycle) into the free buffer: 2048 lerps. It then crossfades linearly from that frozen cycle (read at the same phase) to the live read over **5 ms** (`xfadeLen = round(0.005·fs)`). Linear equal-gain is correct because both sides are the same note's waveform (highly correlated).
- **Why frozen instead of keeping the old bank pointer:** no voice ever dereferences a retired bank after the block in which it was replaced. The Prism reaper's "+2 generations / quiescent" rules then stay valid even with crossfades longer than a block or a host that idles the audio thread.
- **Not crossfaded (deliberate):** Interpolation-Off frame steps (the lesson; latched at the cycle wrap) and bit-depth changes (a deliberate staircase change, bounded by one LSB step).

### 6. Bit-Depth Quantizer
- **JUCE Class:** Custom.
- **Purpose:** DSP-03. Quantize the oscillator output after interpolation and crossfade, before the amp envelope.
- **Parameters Affected:** `bit_depth` (choice index 0 = Full, i → bits = 17 − i, so 16..3).
- **Configuration:** `M = 2^(b−1)`; `k = min(floor(|x|·M), M−1)`; `q = sign(x)·(k + 0.5)/M` with sign(0) = +1. Full → `return x` (early-out; bit-identical bypass). 3 bits gives levels ±{1,3,5,7}/8 = ±0.125, ±0.375, ±0.625, ±0.875: **8 levels**, symmetric, no DC on symmetric input. Per-block constants (`M`, `1/M`) are computed once (sibling pattern).
- **Departure from O-simpleAdditive** (mid-tread `round(x·L)/L`, which gives 2^b+1 levels): required by the DSP-03 acceptance "3 bits = 8 levels".

### 7. Amplitude Envelope
- **JUCE Class:** `juce::ADSR` (juce_audio_basics). Same as the siblings.
- **Parameters Affected:** `amp_attack`, `amp_decay`, `amp_sustain`, `amp_release`; velocity → linear gain. *(Amended 2026-10-05, see §Stage 2 Amendments.)*
- **Configuration:** `setSampleRate` in the custom `prepareToPlay` before `setParameters`. Push parameters only when they change. Project memory: per-block `setParameters` during release can kill the release, so dirty-check before calling. **Voice lifetime is gated on the amp env only.**

### 8. Modulation Envelope → Position
- **JUCE Class:** `juce::ADSR` (per voice).
- **Parameters Affected:** `menv_attack/decay/sustain/release`, `env_amount` (−1..+1).
- **Configuration:** contribution = `env_amount · modEnv(t)` (env 0..1). Same dirty-checked `setParameters` rule. A long mod release never keeps a voice alive.

### 9. Global Position LFO
- **JUCE Class:** Custom phase accumulator (sibling convention; `juce::dsp::Oscillator` is not needed). `juce::AudioPlayHead::PositionInfo` (`getBpm`, `getPpqPosition`, `getIsPlaying` return `juce::Optional`, verified) for sync. `juce::Random` for S&H. *(Amended 2026-10-05, see §Stage 2 Amendments.)*
- **Parameters Affected:** `lfo_rate`, `lfo_sync`, `lfo_div`, `lfo_shape`, `lfo_depth`.
- **Configuration:**
  - Rendered **per sample into a preallocated block buffer** `lfoBuf[maxBlock]` once per block (global). Voices read `lfoBuf[n]`. A per-block LFO, as O-simpleAdditive did, would zipper at 20 Hz with Interpolation On.
  - Shapes (phase φ ∈ [0,1)): Sine `sin 2πφ`; Triangle `1 − 4|φ − 0.5|` shifted to start at 0 going up; Saw `2φ − 1`; Square `φ < 0.5 ? 1 : −1`; S&H held value, re-drawn at the wrap.
  - Contribution = `lfo_depth · 0.5 · lfo(t)`. At 100% depth and Position 50% this sweeps exactly frame 1 ↔ frame N.
  - Tempo mode: `beatsPerCycle = NoteDiv[lfo_div]`. When playing with PPQ: `φ = frac(ppq/beatsPerCycle)` at block start, then advance at `bpm/60/beatsPerCycle` per second. When stopped, or with no playhead (Standalone): free-run at host BPM, or 120 if absent. Non-finite or ≤ 0 BPM → 120 (Prism guard).

### 10. Effective Position
- **JUCE Class:** `juce::SmoothedValue<float, ValueSmoothingTypes::Linear>` (knob, 20 ms) + custom per-voice one-pole.
- **Configuration:** `raw = clamp(knobSmoothed[n] + lfoContribution[n] + env_amount·modEnv, 0, 1)` (DSP-05). Interpolation On: `effPos += α·(raw − effPos)`, α for τ = 2 ms, seeded `effPos = raw` at note-on. Interpolation Off: the latch reads `raw` (smoothing is irrelevant to a cycle-rate latch).

### 11. Voice Manager (Poly / Mono) + Pitch Bend
- **JUCE Class:** `juce::Synthesiser` + 16 × `WtVoice : juce::SynthesiserVoice` + `WtSound`. Mono uses O-simpleSubtractive's `renderMonoLegato` pattern (mode "Mono" only: last-note priority, retrigger on every new note, fall back to the held note on release **with retrigger off**, no glide). *(Amended 2026-10-05, see §Stage 2 Amendments.)*
- **Parameters Affected:** `voice_mode`. Pitch wheel ±2 st.
- **Configuration:** note stealing on. Poly↔Mono switch → `allNotesOff(0,false)` + clear the stack (sibling). A monotonic `noteAge` stamp at note-on lets the lead voice be found for the display. The custom `prepareToPlay` is dispatched by `dynamic_cast` (JUCE 8 `SynthesiserVoice` has no virtual prepare).

### 12. Bank Store + Swap + Reaper
- **JUCE Class:** `std::atomic<const WavetableBank*>` (audio-thread read), `std::shared_ptr<const WavetableBank>` ownership (`importedOwner`) under `bankStateLock` — published by the import worker and by `setStateInformation`, not only the message thread (Amendment 8 / 12) — Prism reaper (`blockEntries` / `blockGeneration` counters, `retiredBanks` vector, timer sweep).
- **Purpose:** DSP-06, PERF-01. Lock-free publish of the imported bank and safe deferred free.
- **Configuration:** see System Architecture §Threading. The audio thread resolves `bank` → pointer **once per block** (built-in pointer from the shared array, or `importedBank.load(acquire)`; `nullptr` = silence).

### 13. Importer
- **JUCE Class:** `juce::AudioFormatManager` (`registerBasicFormats`: WAV/AIFF/FLAC/Ogg; on macOS also CoreAudio formats), `juce::AudioFormatReader`, `juce::FileChooser::launchAsync` (juce_gui_basics), `webview-drop-streaming` module (macOS WKWebView drops, as in O-simpleGrain), `juce::ThreadPool` (1 thread) or `juce::Thread::launch`, `juce::FlacAudioFormat` (`JUCE_USE_FLAC` defaults to 1, verified), `juce::MemoryOutputStream`, `juce::MemoryBlock::toBase64Encoding`. *(Amended 2026-10-05, see §Stage 2 Amendments.)*
- **Purpose:** FUNC-03, FUNC-04, COMPAT-03.
- **Configuration:** Algorithm Details §A8.

### 14. Visualization Renderer (message thread)
- **JUCE Class:** `juce::Timer` (30 Hz, editor), `juce::dsp::FFT` (order 11), `WebBrowserComponent::emitEventIfBrowserIsVisible`.
- **Purpose:** UI-01..03 data. Bank stack (once per bank change), current cycle and harmonics 1–32 (each tick).
- **Configuration:** System Architecture §Visualization Data Path.

### 15. Output Stage
- **JUCE Class:** `juce::SmoothedValue` gain (20 ms), `buffer.applyGainRamp`, block `std::isfinite` scrub, `ScopedNoDenormals` (sibling).
- **Parameters Affected:** `output_level`.
- **Configuration:** voice output = `q(x) · ampEnv · velocity · kVoiceGain` (`kVoiceGain = 0.5`, tuned in Stage 2 against suite loudness; frames sit at peak 1.0 so the quantizer uses its full range). Sum → output gain → copy channel 0 to all output channels.

## Processing Chain

```
MIDI in (host + on-screen keyboard via MidiMessageCollector)
  │
  ├─ per block (audio thread) ─────────────────────────────────────────────
  │   blockEntries++                                   (reaper REG-01)
  │   resolve bank ptr  ← bank param + importedBank.load(acquire) (nullptr = silent)
  │   lfoBuf[n]         ← global LFO (free Hz | tempo: PPQ-locked)  ← lfo_*
  │   knobBuf[n]        ← SmoothedValue(position, 20 ms)
  │   push dirty-checked ADSR params, bit-depth, interp, bandlimit to voices
  │
  ├─ Synthesiser (Poly 16)  |  renderMonoLegato-style voice 0 (Mono)
  │   WtVoice, per block: f = midiHz·bendFactor; L = bandlimit ? ceil(log2(f·2048/fs)) : 0
  │          trigger frozen-cycle xfade if (bank ptr | L | interp | bandlimit) changed
  │   WtVoice, per sample:
  │     raw    = clamp(knobBuf[n] + depth·0.5·lfoBuf[n] + envAmt·modEnv(), 0, 1)
  │     effPos = Interp On ? onePole_2ms(raw) : raw
  │     s      = Interp On ? lerp(read(f0), read(f1), frac) : read(latchedFrame)
  │              (read = linear in-cycle at level L; latch updates at phase wrap)
  │     s      = xfadeActive ? lerp(frozen(phase), s, w) : s
  │     s      = quantize(s, bit_depth)          (Full = bypass)
  │     out   += s · ampEnv() · velocity · kVoiceGain
  │
  ├─ lead voice (newest sounding noteAge) → atomics: effPos, L, latchedFrame, sounding
  ├─ output gain (SmoothedValue dB→lin, −60 dB floor = 0) ← output_level
  ├─ isfinite scrub; duplicate to all channels
  └─ blockGeneration++                                  (reaper REG-01)

message thread (editor Timer 30 Hz)
  atomics + params + current bank (immutable) → render exact cycle → quantize →
  FFT(2048, no window) → |X[1..32]| → "cycleUpdate" { cycle[256], harmonics[32], pos, frame, level }
  on bank change → "bankUpdate" { name, frames: N × 128-pt thumbnails (level 0), filename }
```

**Routing notes:** fully feed-forward (no feedback loop). No oversampling. **Zero latency** (`setLatencySamples(0)` in `prepareToPlay`). The display path is read-only and never in the audio return path. Bit-quantize is **before** the amp env, per the brief, so the envelope adds no steps of its own.

## System Architecture

### MIDI Handling
- `IS_SYNTH TRUE`, `NEEDS_MIDI_INPUT TRUE` (critical pattern #22). `BusesProperties().withOutput("Output", stereo(), true)`, set in the constructor. Accept mono or stereo output only.
- Note-on: f0 from `MidiMessage::getMidiNoteInHertz`; velocity → gain (linear). Pitch wheel: ±2 st; `pitchWheelMoved` sets the bend factor and recomputes L at the next sample sub-block.
- All-notes-off / all-sound-off handled in both modes (sibling).

### File I/O System (Import)
**File types:** WAV, AIFF, FLAC (COMPAT-03), at any sample rate (there is no resampling, so the sample rate is irrelevant to slicing). Ogg and CoreAudio formats come free from `registerBasicFormats`.
**Entry points:** (a) Import button → native function → `FileChooser::launchAsync` (message thread); (b) drag-drop onto the WebView through the `webview-drop-streaming` module (base64 bytes, decoded with `juce::Base64::convertFromBase64`; project memory: `MemoryBlock::fromBase64Encoding` rejects `btoa()` output).
**Loading strategy:** one background job per import (a newer import cancels or supersedes an older one via a generation id). The result is posted back with `MessageManager::callAsync` (SafePointer-guarded) → `publishImportedBank()`.
**Error handling:** unreadable or unsupported file, non-finite sample rate, length < 2048 samples ("needs at least one 2048-sample frame, about 46 ms at 44.1 kHz"), or zero channels → an `importStatus` event with the reason. The existing bank is untouched. Header lengths are never trusted: read `min(lengthInSamples, 256·2048)` only (Prism WR-13 hardening, tightened to what we actually use).

### Threading / RT-safe swap (DSP-06, PERF-01)
| Data | Producer | Consumer | Mechanism |
|------|----------|----------|-----------|
| Built-in banks | process-wide init | audio + message | immutable, `SharedResourcePointer`, never freed while any instance lives |
| Imported bank | import/restore worker → message thread | audio, message (UI) | `std::atomic<const WavetableBank*>` release/acquire for the audio thread; `importedOwner` (`shared_ptr`) under `bankStateLock`, published by the worker or `setStateInformation`. UI reads **only** via `getImportedBankSnapshot()` (Amendment 12) |
| Retired imported bank | message thread | — | `retiredBanks` + **Prism REG-01 reaper**: free when `exits ≥ stamp+2` OR `entries == exits` (quiescent); swept on retire and by a 250 ms timer |
| Params | host/UI | audio | APVTS `getRawParameterValue()->load()` cached pointers |
| Display state | audio | message | `std::atomic<float/int/bool>` relaxed, plus `std::atomic<uint32_t> bankGen` |
| Encoded import blob | worker → message | `getStateInformation` (any thread) | `juce::CriticalSection` (never taken on the audio thread) |

Voices never hold a bank pointer across a swap (the frozen-cycle crossfade), so the reaper's two rules are sufficient. **Do not** free a bank from `setStateInformation` directly; always retire it.

### State Persistence
- APVTS tree (`PARAMETERS`) + child `IMPORTED_BANK` { `version`=1, `filename` (string), `numFrames` (string-typed on reload: project memory says ValueTree XML round-trips lose type, so parse with `getIntValue()`), `encoding`="flac16", `data` = base64 of mono 16-bit FLAC (nominal 48 kHz, header-only meaning) }.
- **Save:** copy the cached base64 string (encoded once at import on the worker). Nothing heavy runs in `getStateInformation`.
- **Restore** (`setStateInformation`, off the audio thread): `replaceState`; if the child exists, decode FLAC → int16 → float frames → build mips (≈ 50 ms worst case) → publish and retire. If it is absent, retire any imported bank (empty). Restoring a session where `bank`=Imported and no blob is present → silent bank + UI prompt (decision 10).
- **Size:** 256 frames × 2048 × 16 bit = 1 MB raw PCM; FLAC typically 40–70% of that; base64 +33% → about **0.6–1.0 MB** worst case in the project or preset. Bit-identical reload (the live bank was built from the same int16 data).
- **Fallback encoding** (if FLAC writing proves troublesome on any platform): raw int16 little-endian + `GZIPCompressorOutputStream` (`encoding="pcm16gz"`), selected by the `encoding` tag. The reader supports both from v1.0.
- **Presets:** factory presets never include an imported bank (built-in banks only) and never set `output_level` (project memory). If the shared `preset-manager` module is used, check the known stale `<CustomState>` child issue (memory `critical_preset_manager_stale_customstate_child`). A user preset *with* an imported bank must replace, not merge, the `IMPORTED_BANK` child.

### Visualization Data Path (UI-01..03, PERF-03)
- **Audio thread, per block:** lead voice = the sounding voice with the newest `noteAge`. Store `dispPos` (its last effective Position), `dispLevel` (L actually read), `dispFrame` (latched frame, Interpolation Off), `dispSounding`. When nothing is sounding: `dispSounding=false`, and the UI uses the knob Position with level 0.
- **Message thread, 30 Hz:** read atomics + `bank`, `interp`, `bit_depth`; take the current bank: a built-in from the shared array, or Imported **only** through `getImportedBankSnapshot()` (a `shared_ptr` copy under `bankStateLock`; the worker and `setStateInformation` also publish, so a raw atomic load on the message thread can race a retire — Amendment 12). Render the 2048-sample cycle exactly as the voice does (same lerp code, shared header) → quantizer → copy → `performFrequencyOnlyForwardTransform` (or the real FFT + magnitude) → harmonics k = 1..32 = bins 1..32 (periodic cycle, so no window and no leakage), shown as 20·log10(|X_k|/max) with a −60 dB floor (UI choice). Cycle downsampled to 256 points by *point sampling* (not max-abs, which would hide staircases). Emit `cycleUpdate` only when the inputs changed (hash) to keep the WebView quiet.
- **Bank panel:** on bank change / import / editor open → `bankUpdate` with N × 128-point level-0 thumbnails (≤ 256 × 128 floats). The UI decimates the stack drawing for N > 64. Project memory: `emitEventIfBrowserIsVisible` drops events while hidden, so the JS sends `uiReady` and C++ re-sends the bank and import status.
- **Optional** live output scope/spectrum (inherited `VizRing`) is **not required** by the brief. Omit it in v1.0 to keep one truthful cycle picture.

## Algorithm Details

### A1. Read path
See Core Components §4. Phase accumulates in double. The in-cycle read is linear with a guard sample. Frames are crossfaded (On) or latched (Off).

### A2. Mipmap level selection: numerical verification
Model: saw-like frame with 1023 harmonics (worst case for imported, Drive and Pulse frames), linear read, 1 s render, Blackman-Harris, max inharmonic component relative to the peak harmonic.

| fs | note | L | Kmax | **linear** | cubic | one-level-richer (Prism-style) | Band-limit **Off** |
|----|------|---|------|-----------|-------|------------------------|---------|
| 44.1k | A0 | 1 | 512 | **−74.3** | −77.4 | −61.9 | −61.9 |
| 44.1k | C2 | 2 | 256 | −82.0 | −92.1 | −50.8 | −50.9 |
| 44.1k | C4 | 4 | 64 | −93.1 | −93.1 | −38.3 | −38.3 |
| 44.1k | C6 | 6 | 16 | −92.1 | −92.1 | −26.0 | −26.0 |
| 44.1k | C7 | 7 | 8 | −114.5 | −129.3 | −20.8 | −20.8 |
| 44.1k | **C8** | 8 | 4 | **−121.1** | −123.4 | **−15.6** | −15.6 |
| 96k | C8 | 7 | 8 | −114.9 | −123.5 | −21.6 | −21.6 |

Conclusions: (1) strict selection + linear passes QUAL-02 (≥ 60 dB) with ≥ 14 dB margin everywhere and ~60 dB margin at C8; (2) any scheme that lets the richer level contribute (Prism's trilinear `log2` level crossfade) fails QUAL-02; (3) Band-limit Off is clearly aliased from C4 upward (DSP-02 demo works; at C7 aliases at −21 dB). Cost of strictness: the top harmonic sits between fs/4 and fs/2 depending on the note's place in the octave (≈ 11–22 kHz at 44.1k). For Sine→Saw frame 32 this means the harmonics graph loses bars above Nyquist/2 on high notes. That is truthful (it is what is heard) and teachable ("the band-limited copy for this octave stops at harmonic K").

### A3. Sine→Saw (32 frames)
`b_n(k) = 1/n` for n ≤ k, else 0 (k = 1..32). Frame 1 = sine; frame 32 = h1..h32. Then normalize the peak.

### A4. Drive
Time domain: `x_k[i] = tanh(g_k·sin(2πi/2048)) / tanh(g_k)`, `g_k = 0.25·100^((k−1)/31)` → FFT → mips. Verified: frame 1 h3 −45.8 dB (≈ sine), frame 9 −26 dB, frame 17 −13 dB, frame 32 −9.6 dB (h3), 38 harmonics above −60 dB. h3/h5/h7 and THD strictly increase (FUNC-02 "rising odd content monotonically"). Even harmonics are 0 by symmetry. Log spacing reads like a dB drive knob.

### A5. Sine→Square
Frontier `c(k) = 1 + 15·(k−1)/31` (1 → 16 odd harmonics). Odd harmonic j (n = 2j−1, j = 1..16): `b_n = (1/n)·clamp(c(k) − (j−1), 0, 1)`; even = 0 (FUNC-02: even ≥ 60 dB down, exactly 0 here). Every frame is distinct (32 audible steps with Interpolation Off), frame 32 = square to h31, and the frontier bar grows in the graph. Rejected: one odd harmonic per frame (h33..h63 lie off the 1–32 graph, so frames 17–32 look identical), and two frames per harmonic (16 duplicate frames give dead steps).

### A6. Pulse Width
Pulse centred at φ = 0.5 with duty d: `x(φ) = Σ_{n=1}^{1023} (2/(nπ))·sin(nπd)·cos(2πn(φ − 0.5))` (DC dropped). `d_k = 0.5·(1/16)^((k−1)/31)`. d = ½ is a square; nulls at multiples of 1/d move from h2 to h32. Normalize the peak (narrow pulses get quieter in RMS; that is honest). Gibbs ripple is inherent to band-limited pulses and is reduced per mip level.

### A7. Formant
`f_ref = 110 Hz`, harmonics n = 1..48, source `1/n`. Envelope = product of three 2-pole resonator magnitudes `R_i(f) = (F_i² + (B_i/2)²) / sqrt(((f−F_i)² + (B_i/2)²)·((f+F_i)² + (B_i/2)²))`, evaluated at `f = n·f_ref`. `b_n = (1/n)·Π R_i(n·f_ref)`.
Vowel anchors (Peterson & Barney 1952, adult male averages; from established literature, not re-checked online this session):

| Vowel | F1 | F2 | F3 |
|-------|----|----|----|
| A /ɑ/ | 730 | 1090 | 2440 |
| E /ɛ/ | 530 | 1840 | 2480 |
| I /i/ | 270 | 2290 | 3010 |
| O /ɔ/ | 570 | 840 | 2410 |
| U /u/ | 300 | 870 | 2240 |

Anchors at frames 1, 8.75, 16.5, 24.25, 32; `F_i` interpolated in log-frequency between neighbours. B = 90/110/170 Hz (slightly wider than speech so peaks span about 2 harmonics at 110 Hz and move smoothly). Tooltip lesson: the formants are baked into the cycle, so they scale with pitch (at 220 Hz the "vowel" is an octave higher), unlike a real voice.

### A8. Import pipeline (worker thread)
1. Reader from file or bytes; validate sample rate and length. `n = min(len, 256·2048)`; read up to all channels in chunks into a preallocated (worker-side) buffer; **mono = mean of channels**.
2. `F = min(floor(n/2048), 256)`; F = 0 → reject.
3. Per frame: FFT → zero DC + Nyquist → IFFT (DC removal, DSP-04); peak p; gain = `min(1/p, 10^(24/20))` (p = 0 → leave silent); scale.
4. Quantize frames to int16 (`round(x·32767)`), convert back to float. **This is the canonical level 0.**
5. Encode int16 → FLAC (mono, 16-bit) → base64; cache it with the filename.
6. Build 11 mips per frame (§Core 3), thumbnails.
7. `callAsync` → message thread: check that the generation is still current → `publishImportedBank` (atomic store; retire old) → set `bank` = Imported via `beginChangeGesture / setValueNotifyingHost / endChangeGesture` → `bankUpdate` + `importStatus{filename, frames}`.
Tooltip lesson: slices are not pitch-synchronous, so they buzz at the loop point. Pitch follows the 2048-sample cycle length (f = note Hz, regardless of the source).
Per-frame normalization with a +24 dB cap is a deliberate reading of DSP-04 for imports: every slice is legible in the stack, but near-silent slices aren't blown up into noise.

### Processing Order (load-bearing)
1. `blockEntries++` first; `blockGeneration++` last, on **every** return path (including a zero-channel early return).
2. Resolve the bank pointer once, before any voice renders.
3. LFO and knob buffers are filled before voices render (voices read per sample).
4. Per-voice change detection (bank/L/interp/bandlimit) runs **before** that voice's first sample in the block (and after each pitch-wheel sub-block split).
5. Quantize after the frame interpolation and crossfade, before the amp env.
6. Display atomics are written after rendering.

### Parameter Interactions
- Position + LFO + Env sum then clamp. A full-depth LFO at Position 0 spends half its cycle clamped at frame 1 (expected; tooltip: "centre Position to use the full sweep").
- Interpolation Off + fast LFO: steps occur at most once per cycle. At low notes a fast LFO is under-sampled per cycle (PPG-like; that is the lesson).
- Band-limit × pitch: brightness steps by octave are hidden by the 5 ms crossfade on bends. A static note never changes level.
- Bit depth × crossfades: quantization is applied after the mix, so crossfades step through quantizer levels (correct, and inaudible at 5 ms).
- `bank` = Imported, empty → silent; envelopes still run, so importing during a held note fades the new bank in through the crossfade.

### Thread Boundaries
See System Architecture §Threading table. The audio thread performs no allocation, no locks, no FFT, and no file I/O.

## Architecture Decisions

1. **Strict per-octave mips, no inter-level blend (WHY):** the measured QUAL-02 margin is decisive. Blending a richer level (Prism/Vital-style trilinear selection) aliases at −15.6 dB at C8. Finer levels (2–3 per octave, as some commercial synths do) would recover bandwidth but multiply import memory (46–70 MB). **Tradeoff:** up to one octave of top-end loss at 44.1k, which the harmonics panel shows honestly.
2. **Linear in-cycle read (WHY):** with strict mips the table is always ≥ 2× oversampled relative to its content, and the worst case is −74 dB. Cubic costs 2× reads for no requirement gain. It stays a one-line switch if Stage 4 listening asks for it.
3. **Latched stepping (WHY):** switching frames at the cycle wrap makes "Interpolation Off" teach *stepping*, not clicks (sine-phase frames pass through 0 there), matching the brief's "teach stepping, not a second unrelated artifact".
4. **Frozen-cycle crossfade (WHY):** one mechanism for all four discontinuities, and it decouples voice state from bank lifetime, which makes the RT-safe swap provably simple.
5. **Message-thread cycle + FFT (WHY):** the cycle is a deterministic function of (bank, position, level, interp, bits), so re-deriving it off-thread is exact and costs the audio thread only a few atomics. An output-tap FFT (sibling `VizRing`) would show envelope/mix/voice smear, not "the cycle being read".
6. **FLAC-16 embedded import (WHY):** smallest lossless JUCE-native option, and decoding in restore is cheap. Building the live bank from the int16 data makes save/reload bit-identical.
7. **Separate `lfo_div` (WHY):** switching Free↔Tempo preserves both settings; hosts show meaningful automation names; suite precedent (O-Prism `lfoNDivision`).
8. **Mid-rise quantizer (WHY):** the only standard quantizer giving exactly 2^b symmetric levels (DSP-03).

## Special Considerations

- **Thread safety:** see the tables above. The UI never calls processing code; the editor reads the bank only through the message-thread-owned pointer.
- **Performance:** per voice per sample: 4 table reads + 3 lerps + quantize + 2 ADSR + one-pole ≈ 30 flops. 16 voices ≈ 500 flops per sample, far below budget at 96 kHz (PERF-02). A crossfade capture is 2048 lerps per voice per event.
- **Denormals:** `ScopedNoDenormals`; the one-pole and ADSR tails are the only decays; block `isfinite` scrub.
- **Sample rate:** mips are harmonic-count-based (fs-independent); L uses the current fs; xfadeLen, smoothers and ADSR are re-prepared in `prepareToPlay`. No bank rebuild on an fs change.
- **Latency:** 0, `setLatencySamples(0)`.
- **Determinism:** S&H RNG reseeded in `prepareToPlay`; phases reset at note-on, so offline renders are byte-stable (needed for golden gates).

## Stage 2 Amendments (2026-10-05)

Dated corrections from Stage 2 (stages/2-dsp/PLAN.md decision table). They override the text above where they disagree; nothing else changed.

1. **Mip level floor (D-A).** Band-limit On: `L = clamp(ceil(log2(f·2048/fs)), 1, 10)` (`wt::kMinBandLimitedLevel = 1`); Off stays L = 0. Worst-case sweep alias is −74.9 dB at 44.1/48/96 kHz; no note changes level at 44.1/48 kHz. A downward-only hysteresis applies to level changes (D-K): up switches at once, down needs `f < boundary·2^(−1/24)`.
2. **§11 Voice manager.** Mono is **true legato**: an overlapping note changes pitch only; amp env, mod env and position smoother continue. Last-note priority; release returns to the previous held note. A new note from silence or from a release tail retriggers (`noteOn()` without `reset()`).
3. **Velocity is squared** (§5 / §11 / System Architecture): `velGain = v²`, v = JUCE velocity 0..1.
4. **REG-01 reaper amendment (D-C).** The audio thread publishes `audioHeldBank` (this block's resolved bank) before the exit increment, and the sweep never frees the held bank. Free rule: `bank != held && (entries == exits || exits >= stamp + 2)`. All reaper atomics are seq_cst (hardening deviation from Prism's acquire/release). `audioHeldBank` is cleared in `prepareToPlay`/`releaseResources`. Reason: the verbatim port is a use-after-free with the frozen-cycle crossfader when the host idles.
5. **`AudioPlayHead::PositionInfo::getIsPlaying()` returns `bool`**, not `Optional` (`getBpm`/`getPpqPosition` are `Optional`).
6. **S&H** draws from a splitmix64 hash of (seed, cycleIndex), not a sequential `juce::Random` (D-J): deterministic, block-size independent, repeats on a transport loop.
7. **Base64:** standard `juce::Base64::toBase64` / `convertFromBase64` only; never `MemoryBlock::toBase64Encoding` (non-standard alphabet).
8. **Import publish / auto-select (D-M):** the worker publishes under `bankStateLock` (generation re-checked), then sets a pending flag and triggers a `juce::AsyncUpdater`; `handleAsyncUpdate` selects bank = Imported inside a begin/end gesture. Not `MessageManager::callAsync`. Status is polled via a version counter.
9. **Smoothed depth/amount (D-I):** `lfo_depth` and `env_amount` get the same 20 ms `SmoothedValue` as the position knob.
10. **State blob size:** the worst case (256 frames) is about 1.05 MB of FLAC16, 1.40 M base64 characters. Restore caps the attribute at 4 M characters.
11. **Crossfade shape is raised-cosine**, not linear: `w = 0.5 − 0.5·cos(π·k/len)` over the same 5 ms, equal-gain, same fold rule. A linear ramp's slope corners put a second-difference kick of |A−B|/len at both ends of the fade. That failed the QUAL-03 ratio gate on smooth low notes (A1 bank swap 1.73, Imported → empty 14.1, 16 held notes 1.68). With the raised cosine the same cases measure 0.996 / 1.31 / 0.88 (≤ 1.5). The exactness tier is unchanged against the new law (≤ 6e-8).
12. **Imported-bank reads off the audio thread (2026-10-06, verify W5).** Since Amendment 8 the import worker and `setStateInformation` publish, not just the message thread, so the original "the message thread is the publisher, so it may read the pointer directly" reasoning (§Core 12, Threading table, Visualization Data Path, row 17) no longer holds. Stage 3 (cycle view, bank thumbnails, harmonics) reads the Imported bank **only** through `getImportedBankSnapshot()`; ownership is a `shared_ptr` (`importedOwner`), not a `unique_ptr`. The raw `std::atomic<const WavetableBank*>` is for the audio thread only.
13. **Click-free hard stop and retrigger (2026-10-06, verify W1/W2, QUAL-01).** A hard stop (voice steal, Poly↔Mono switch, all-sound-off) adds the voice's last output sample back as a 2 ms raised-cosine decay to 0 (per-voice scalar; voices 1..15 are rendered in Mono so their switch tails play out). A note that starts on a still-sounding voice (Mono retrigger from a release tail) ramps `velGain` linearly over 3 ms; a start from idle stays instant. Gates: G-STEAL, G-SWITCH-TAIL, G-RETRIG-VEL.

## Stage 3 Amendments (2026-10-06)

14. **Viz change detection hashes the quantized output payload (D-P).** Every wire value is quantized once (`q = llround(x·10^d)`, non-finite → 0; 4 dp cycle / preQ / pos / f0 / nyquistH, 3 dp thumbs / lfo / menv / amp, 2 dp dB), FNV-1a runs over the int64 quanta, and the var is built from the same quanta only on emit. `lfo` is gated on depth (`lfo_depth > 0 ? dispLfo : 0`). Idle = 0 `cycleUpdate` events and 0 heap allocations per tick. Supersedes "when the inputs changed" in §Visualization Data Path.
15. **Display state additions (D-X).** `std::atomic<int> dispNote { -1 }`, `std::atomic<float> dispHz`, `std::atomic<double> displayFs` (relaxed, lock-free asserted) and `WtVoice::lastNote` (set in `startNote`, `noteOnDirect`, `setPitchNote`; named to avoid `-Wshadow-all` against the `midiNote` parameters). The `cycleUpdate` payload is the integration-checklist superset. With Interp On, `frame = -1`; silent = knob position, level 0, note -1, f0 = nyquistH = 0 (D-R).
16. **Harmonic dB reference = max |X_k| over bins 1..1023 (D-U)** of the heard cycle, kept at plan sign-off. A frame whose strongest partial lies above h32 shows honestly lower bars. One named constant `kRefMaxBin` flips it to 1..32.
17. **Lesson recipes (D-V, D-Y).** Stage 3 uses the integration checklist's five recipes (Alias Demo = Sine→Saw, Pos 1.0, Band-limit Off; octave jump page-side). §A9 (Alias Demo on Drive) remains the FUNC-08 Stage 4 target. `applyFactoryPreset` is a single pass over `ParamIDs::all`: target = normalized default unless the recipe overrides it, `output_level` skipped, params within 1e-6 skipped, one begin/set/end gesture per changed param, unknown id → false and no change, Imported untouched. Drops are decoded in the processor (`importFromBase64`: length cap before decode, standard Base64 only, localized error codes; D-Z).
18. **`bankUpdate` triggers and filename (D-S, D-T).** The editor timer emits `bankUpdate` when `getBankDisplayGeneration()` **or** the APVTS bank index changes (the gen bump is audio-thread only, so an idle host would otherwise leave the stack stale), with a content-hash dedupe; `uiReady` forces it. Order every tick: `bankUpdate` → `importStatus` → `cycleUpdate`. The `bankUpdate` filename comes from the cached blob read in the same `bankStateLock` scope as the imported-bank copy; `ImportStatus.filename` feeds only `importStatus`, so a failed import never renames the loaded bank.

## Stage 4 Amendments (2026-10-06)

Dated corrections from Stage 4 (stages/4-polish/PLAN.md decision table, D-AA…D-AW). They override the text above where they disagree; nothing else changed.

19. **Imported × presets = bank choice only (D-AC).** A user preset stores `bank` as a normal parameter (Imported = normalized 1.0) and nothing else about the imported audio: no embedded blob, no `customState`. A preset load never touches `IMPORTED_BANK`, `importedOwner`, the cached blob or the import status; its only `bankStateLock` write is clearing `pendingAutoSelect`. With nothing imported, a preset on Imported shows the Stage 3 empty-Imported prompt. **Supersedes** §State Persistence's sentence "A user preset *with* an imported bank must replace, not merge, the `IMPORTED_BANK` child." Gate: G-PRESET-IMPORTED.
20. **Preset manager (D-AA, D-AB, D-AF).** The suite `preset-manager` module (v1.0.9) is used only for the Factory / User folders (`~/Library/O-simpleWavetable/Presets`), `savePreset (name)` and `deletePreset (name)` with their factory guards, `initializeFactoryPresets` with its `.factory-version` sentinel, and `preset-manager.js`. The plugin never calls the module's XML state pair, its JSON apply, its file-dialog save / load, its custom-state callbacks or its prev / next (v1.0.9 still carries the stale `<CustomState>` child and an apply that sets `output_level`; logged upstream in CODE_REVIEW.md). The plugin keeps its own `getStateInformation` / `setStateInformation` and adds one root property, `currentPreset` (absent on restore → unnamed `""`). One apply core, `applyNormalisedTargets`, serves the recipe table, user JSON and factory names: it clears `pendingAutoSelect`, skips `output_level`, sets defaults for anything not listed, and brackets each changed parameter in its own gesture. A new `presetState { name, id, factory, modified }` event joins the editor push; the order every tick is `bankUpdate` → `importStatus` → `presetState` → `cycleUpdate` (extends Amendment 18).
21. **§A9 as shipped (D-AD).** One table, `Source/PresetRecipes.h`, is the sound authority for the 9 factory presets and the 5 lesson buttons (the lesson ids are a subset). Fill rule: §A9 wins where it names a value; the Stage 3 lesson recipe fills where §A9 is silent; the 4-bit PPG variant is the 9th entry. Alias Demo is on the Drive bank (Pos 100 %, Band-limit Off). Drive Sweep keeps §A9's envelope (menv A 0.01 / D 1.5 / S 0), and its en / fr / zh-Hans copy is rewritten to match ("strikes driven, relaxes to a sine"). Changes vs the Stage 3 lessons: Stepped Scan Tri → Saw, 0.18 → 0.25 Hz; Alias Demo Sine→Saw → Drive; Drive Sweep A 0.9 → 0.01, D 1.6 → 1.5, S 0.25 → 0; Vowel Pad Sine → Tri, 0.12 → 0.1 Hz, depth 0.9 → 1.0; 8-bit PPG S&H 3 → 4 Hz. **Supersedes** Amendment 17's lesson recipes; the rest of Amendment 17 (single-pass apply, `output_level` skipped, Imported untouched, `importFromBase64`) stands.
22. **Frozen-cycle crossfade keeps the outgoing cycle's own phase and rate (W4, D-AJ).** On a crossfade trigger the voice captures `xfPhase = phase` and `xfInc` = the increment the outgoing cycle was last rendered at; during the fade the frozen cycle is read at `xfPhase`, advancing by `xfInc`, not at the new pitch. A fold into an already running fade reads the frozen cycle phase-aligned (offset `xfPhase − phase`). Non-pitch triggers (bank, interp, band-limit) are bit-identical to before. Residual, logged in CODE_REVIEW.md: a second trigger within 5 ms of a level-crossing pitch change continues the unfinished part of the first fade at the newest pitch. Gates: G-LEGATO-XF, G-LEGATO-ALIAS, G-LEGATO-CLICK.
23. **Block-path hardening (D-AJ, D-AK).** (a) The MIDI chunk fill is byte-capped: a chunk ends before an event that would overflow the pre-sized reserve, so the audio thread never grows the buffer. (b) `std::atomic<bool> prepared` is set as the last statement of `prepareToPlay`; `processBlock` renders only when it is set; `releaseResources` does not clear it. (c) The audio thread tracks the last pitch-wheel value (`wheelNow`) and seeds Mono voice 0 with it at a Poly → Mono switch. (d) The drop cap is 16 MiB on both sides (`WavetableImporter::kMaxMemoryBytes` and the page `DROP_MAX_BYTES`); the Import button streams from disk and has no cap. Gates: G-MIDI-FLOOD + `--alloc-check`, G-UNPREPARED, G-MONO-WHEEL, G-DROP-CAPSYNC.
