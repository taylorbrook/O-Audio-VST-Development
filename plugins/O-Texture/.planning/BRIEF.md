# O-Texture - Creative Brief

## One-Line Pitch
Infinite evolving audio textures generated by a custom neural network -- feed it a sound or let it dream on its own.

## Plugin Type
Instrument / Effect hybrid (VST3/AU)

## Core Concept
O-Texture is a neural texture synthesizer. A custom 1D CNN Variational Autoencoder (VAE) learns the statistical essence of texture categories (rain, metal, wind, crowd, synth, organic) and generates infinite, non-repeating audio that sounds like the real thing -- but never loops. In **Generative mode**, an autoregressive prior model continuously invents new texture. In **Transform mode**, live audio input is re-synthesized through a target texture's character. An XY pad navigates the learned latent space, letting users sculpt the texture in real time.

This is not granular synthesis (no sample chopping), not wavetable (no oscillators), and not sample playback (no loops). The neural network has internalized what "rain" or "wind" sounds like and continuously generates novel audio from that understanding.

## Character
- **Generative and alive** -- output is always evolving, never static
- Organic, natural-sounding textures (not synthetic artifacts)
- Smooth morphing between texture variations via latent space navigation
- Ambient, atmospheric, textural -- designed for soundscapes and beds

## Architecture
- **Custom 1D CNN VAE** (~1.2M parameters per texture model)
- 32-dimensional latent space (compact, controllable)
- 4096-sample blocks (85.3ms at 48kHz) with overlap-add crossfading
- GRU-based autoregressive prior model for unconditional generation
- ONNX Runtime inference via ANIRA real-time thread pool
- 6 pre-trained texture models shipped with plugin

## Dual Modes
- **Generative**: Prior model generates latent sequences → decoder produces audio. No input needed.
- **Transform**: Audio input → encoder → latent manipulation → decoder → re-synthesized output.

## Controls (10 parameters)
| Parameter | Range | Default | Description |
|-----------|-------|---------|-------------|
| **Source** | Rain / Metal / Wind / Crowd / Synth / Organic | Rain | Select pre-trained texture model |
| **Mode** | Generate / Transform | Generate | Generative (no input) or transform (processes input) |
| **X** | 0.0 - 1.0 | 0.5 | Latent space X position (mapped to most active dimension) |
| **Y** | 0.0 - 1.0 | 0.5 | Latent space Y position (mapped to second most active dimension) |
| **Character A** | 0.0 - 1.0 | 0.5 | Third latent dimension -- secondary timbral axis |
| **Character B** | 0.0 - 1.0 | 0.5 | Fourth latent dimension -- secondary timbral axis |
| **Evolve** | 0.0 - 1.0 | 0.3 | Rate of random walk through remaining latent dimensions |
| **Brightness** | -100% to +100% | 0% | Post-processing tilt EQ |
| **Freeze** | Off / On | Off | Hold current latent position (stops evolution) |
| **Mix** | 0 - 100% | 100% | Dry/wet blend (relevant in Transform mode) |

## Signal Flow
```
GENERATIVE MODE:
Prior Model → Latent z → [User Controls modify z] → Decoder → Crossfade → Post-EQ → Stereo → Output

TRANSFORM MODE:
Input → Encoder → Latent z → [User Controls modify z] → Decoder → Crossfade → Post-EQ → Mix → Output
```

## DSP Notes
- Decoder runs on ANIRA background thread pool (not audio thread)
- Overlap-add crossfading: 50% overlap, 2048-sample hop, Hann window
- Stereo via latent decorrelation (slightly offset z vectors for L/R channels)
- Post-processing: 1-pole tilt EQ for brightness/warmth
- Latency: ~85-128ms (host-compensated). Irrelevant in Generative mode.
- CPU: ~5-10% single core (estimated, 1.2M param decoder at 23 blocks/sec)

## UI Vision
- XY pad as the dominant interface element (~50% of area)
- Animated particle visualization in the XY pad showing latent space activity
- Model selector with texture category icons
- Evolve rate visualized as orbital motion around current position
- Freeze state clearly indicated (XY pad border glow or frost effect)
- Compact secondary controls below XY pad
- Mode toggle (Generate/Transform) prominent at top

## Target User
- Ambient / drone producers creating evolving soundscapes
- Film / TV composers needing non-repeating atmospheric beds
- Game audio designers generating environmental textures
- Sound designers exploring generative audio
- Meditation / relaxation content creators

## Differentiators
- **First plugin to use a custom neural network for texture generation** -- no existing plugin does this
- vs Granular synthesis (O-TextureForge, Granulator II): generates truly novel audio, never loops or chops samples
- vs RAVE/Neutone: custom lightweight model, no external dependencies, approachable UX
- vs Sample libraries: infinite variation, never repeats, controllable in real time
- vs Noise generators: learned natural texture statistics, not synthetic noise

## Scope (v1 -- Core Engine)
**In scope:**
- Custom 1D CNN VAE (encoder + decoder + prior)
- PyTorch training pipeline with multi-scale spectral loss
- 6 pre-trained texture models (Rain, Metal, Wind, Crowd, Synth, Organic)
- ONNX export and ONNX Runtime inference via ANIRA
- Overlap-add crossfading for seamless block transitions
- Generative mode (prior-driven)
- Transform mode (encode → manipulate → decode)
- XY pad latent navigation
- Evolve modulation (random walk through latent space)
- Freeze control
- Post-processing EQ
- Stereo decorrelation
- WebView UI

**Out of scope for v1 (future versions):**
- User-trainable models (provide your own audio to train)
- Adversarial fine-tuning for higher quality
- MIDI control of latent dimensions
- Reverb tail
- Model blending (crossfade between texture categories)
- INT8 quantization for smaller model files

## Complexity Assessment
**VERY HIGH** -- This plugin requires:
1. Custom neural network architecture design (PyTorch)
2. Training pipeline with multi-scale spectral loss
3. Dataset curation (6 categories x 30 min each)
4. ONNX model export and optimization
5. ANIRA real-time inference integration in JUCE
6. Overlap-add audio block crossfading
7. Latent space analysis and control mapping
8. Prior model for autoregressive generation
9. WebView UI with interactive XY pad

Mitigating factors: architecture is fully designed (`research/o-texture-custom-vae-architecture.md`), model is intentionally lightweight (1.2M params), well-documented inference frameworks (ANIRA, ONNX Runtime).
