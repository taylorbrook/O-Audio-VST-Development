## Context to Preserve

**Plugin identity:**
- Transparent, clean, utilitarian compressor
- Feed-forward design for predictability
- Variable soft-knee (0-20 dB)
- Peak detection preferred for transparency
- Auto-gain calculation: `makeupGain = -threshold * (1 - 1/ratio)`

**Critical architecture decisions:**
- Custom compressor implementation (juce::dsp::Compressor lacks knee parameter)
- Stereo-linked compression (prevents image shift)
- Zero latency (no lookahead buffer)
- Peak envelope follower with attack/release ballistics

**DSP Implementation Notes (from architecture.md):**
- Attack coeff: `1.0f - std::exp(-1.0f / (attackTimeMs * sampleRate / 1000.0f))`
- Release coeff: `1.0f - std::exp(-1.0f / (releaseTimeMs * sampleRate / 1000.0f))`
- Soft-knee: Quadratic interpolation in range [threshold - knee/2, threshold + knee/2]
- Gain reduction: `x - (x / ratio)` where x = inputLevelDB - thresholdDB
