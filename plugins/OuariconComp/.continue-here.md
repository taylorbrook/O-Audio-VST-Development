## Context to Preserve

**Plugin identity:**
- Transparent, clean, utilitarian compressor
- Feed-forward design for predictability
- Variable soft-knee (0-20 dB)
- Peak detection preferred for transparency
- Auto-gain calculation: `makeupGain = -threshold * (1 - 1/ratio)`

**Critical architecture decisions:**
- Custom compressor implementation (juce::dsp::Compressor lacks knee parameter)
- Stereo-linked compression (prevents image shift)
- Zero latency (no lookahead buffer)
- Peak envelope follower with attack/release ballistics

**Implementation strategy:**
- Single-pass DSP implementation (moderate complexity, not phased)
- Start with hard knee (0 dB), add soft-knee incrementally
- Test threshold/ratio/attack/release before adding knee curve
- Reference FabFilter Pro-C 2 for knee behavior

**Key risks and mitigations:**
- Soft-knee curve tuning → Start hard, add soft incrementally
- Auto-gain accuracy → Provide manual OUTPUT_GAIN for fine-tuning
- Stereo-linked detection → Verify no image shift with test signals

**JUCE modules required:**
- juce_dsp (ProcessSpec, AudioBlock, Decibels, ScopedNoDenormals)
- juce_gui_extra (WebView UI)
