## Context to Preserve

**Plugin Features:**
- Dual timing mode: Free milliseconds (1-2000ms) OR tempo sync (12 subdivisions)
- Transparent digital delay (no coloration)
- Stereo spread via Haas effect (0-15ms offset, not ping-pong)
- Optional modulation (chorus-like movement, 0-10ms depth)
- Spillover on bypass (tail continues)
- Separate WET and DRY controls (independent gain stages)
- LED output meter (14 segments, OuariconComp style)

**Parameters (8 total):**
- TIME (1-2000ms) - delay time in free mode
- SYNC (on/off) - enable tempo sync
- DIVISION (12 choices) - note subdivision
- FEEDBACK (0-100%) - repeat amount
- SPREAD (0-100%) - stereo width
- MOD (0-100%) - delay modulation
- WET (0-100%) - delayed signal level
- DRY (0-100%) - clean signal level

**Visual Elements:**
- Output meter: 14-segment LED (RMS output level)

**DSP Components:**
- juce::dsp::DelayLine with Lagrange3rd interpolation
- juce::dsp::Oscillator for LFO (0.3 Hz sine wave)
- juce::dsp::Gain for wet/dry level control
- Custom feedback loop (0.0-0.95 gain limit)
- Custom Haas effect (asymmetric delay offset)
- RMS level calculation for output meter

**Implementation Strategy:**
- Single-pass DSP (score 2.4, below 3.0 threshold)
- All 8 parameters in one phase
- Output meter via WebView message passing

**Critical Patterns:**
- AudioPlayHead only in processBlock() (thread safety)
- Fallback to TIME if BPM unavailable (graceful degradation)
- Hard limit feedback at 0.95 (stability)
- Report tail size via getTailLengthSeconds() (spillover)
- Use juce::ScopedNoDenormals (denormal protection)
- RMS meter update rate ~30Hz (batched for performance)
- WebView member order: relays → webView → attachments (prevents release build crashes)
