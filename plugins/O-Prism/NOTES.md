## Description

Microtonal wavetable synthesizer rivaling Xfer Serum. Features 2 wavetable oscillators with morphing, sub oscillator, noise generator, dual multi-mode filters, 5 effects (reverb, delay, chorus, distortion, EQ), and the complete microtonal engine from O-Lyrica/O-Bells (24+ factory tunings, Scala/KBM import, EDO generators). 16-voice polyphony, 100+ factory wavetables, audio file import. WebView UI at 1200x800 with Ouaricon Naturalist aesthetic.

## Known Issues

### Known Limitations

- **White and Digital noise are ~3.4 dB quieter in the audio band at 96 kHz**
  than at 44.1 kHz for the same `noiseLevel`. A `±1` white sequence has
  fs-independent *total* power, so its power per Hz falls as `1/fs`. Found while
  verifying WR-05 (v1.28.0) and **not** a restatement of it: Pink escapes this by
  coincidence — its frequency-axis compression at a higher rate offsets the
  `1/fs` fall almost exactly, which is why correcting Pink's coefficients made it
  worse, not better. White and Digital have no filter to do that, so they take
  the full offset. Not fixed in v1.28.0: it is a new finding outside that batch's
  scope, and the fix is an `sqrt(fs/44100)` input-gain term on the affected noise
  types. Same class as `pattern_noise_bed_level_is_rate_dependent`.

- **Fold still aliases in the top octave at moderate drive.** Fixed in v1.29.0
  from -0.3 dB to -10.5 dB alias-to-signal at 4 kHz / drive 0.5, a 10 dB
  improvement — but the three saturator modes measure about -33 dB there, so Fold
  remains roughly 23 dB behind them in that one corner. Not a regression and not
  IN-09 reopened; IN-09 is resolved. Closing the gap further needs a different
  class of fix than oversampling or ADAA (the measured ceiling for both is in the
  v1.29.0 CHANGELOG), and `sin(pi*u)` will always alias more than `tanh`.

- **O-Strata carries the pre-fix DistortionProcessor.**
  `plugins/O-Strata/Source/dsp/DistortionProcessor.cpp` is byte-identical to
  O-Prism's v1.28.1 file apart from two comment lines, so it has IN-09 in full. It
  is not a tracked shared module — each plugin holds its own copy — so the v1.29.0
  fix did not propagate. Belongs to its own `/improve O-Strata`.

- **FM warp is not band-limit-corrected (WR-02 scope note).** The Sync and Bend
  mipmap-level scaling added in v1.28.0 does not extend to FM, whose modulation
  index is `fmInput` and changes every sample, so no cached scale describes it.
