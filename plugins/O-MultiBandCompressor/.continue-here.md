## Context to Preserve

**Architecture highlights:**
- 4 frequency bands with Linkwitz-Riley crossovers at 200Hz, 2kHz, 8kHz (adjustable)
- Each band has 12 parameters (Threshold, Ratio, Attack, Release, Knee, Makeup, Peak/RMS, Solo, Bypass, SC HPF, SC LPF, SC Listen)
- 9 global parameters (Input Gain, Output Gain, Mix, Auto-Makeup, M/S Mode, Xover1, Xover2, Xover3, [Display params])
- Total: 57 parameters (maximum complexity)

**Critical patterns to follow:**
- Linkwitz-Riley = 2 cascaded 2nd order Butterworth filters (use `juce::dsp::FilterDesign`)
- Soft knee uses quadratic interpolation: `slope × (x + knee/2)² / (2 × knee)`
- M/S encoding: `mid = (L+R)/√2`, `side = (L-R)/√2` (power-preserving)
- FFT smoothing: 70% old + 30% new (temporal averaging for stable display)
- Auto-makeup: Inverse of 100ms average GR, scaled to 80% (not 100% to avoid over-compensation)

**Performance targets:**
- <30% CPU at 48kHz stereo (Off mode, 4 compressors)
- <50% CPU at 48kHz stereo (Both mode, 8 compressors)
- ~10-12ms latency (IIR filters + attack lookahead)

**Phase implementation order:**
1. **Phase 4.1:** Single-band compressor with all features (foundation)
2. **Phase 4.2:** Add Linkwitz-Riley crossover + 4-band architecture
3. **Phase 4.3:** Sidechain filtering + M/S + Auto-makeup + Dry/Wet
4. **Phase 5.1:** WebView + Spectrum + Crossover handles
5. **Phase 5.2:** Parameter binding (57 params)
