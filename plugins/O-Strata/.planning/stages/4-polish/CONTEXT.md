## Findings from this discussion (facts the research + plan must respect)

1. **Persistence is reserved, not wired.** `getStateInformation` creates an empty `terrainImports` child (`PluginProcessor.cpp:1231-1234`); `setStateInformation` reads and ignores it (`:1280-1282`); `sourceMissing` is hard-false at `:1165`. The preset manager's `customSave` / `customLoad` setter (`OuariconPresetManager.h:65-66`) is **never called** in O-Strata (`grep customSave Source/PluginProcessor.cpp` = 0), so today a preset carries parameters only. Everything 4.1 needs on the data side already exists: `ImportSlot { bytes, name, sha256, decoded, revision }` + `getImportSlotCopy` (`PluginProcessor.h:205-216`), `importTerrainImage` (bytes path) and `importTerrainFile` (path form, returns `false` for a missing file — README `import` (f)).
2. **Two load orders to get right.** (a) `setStateInformation` restores parameters first and `terrainImports` after, so `osc?Terrain = Imported…` is already set when the image publishes — the oscillator follows the voice's set rule meanwhile (analytic fallback, Stage 3 SUMMARY deviation 1), so there is no silent gap; (b) the preset path applies parameters through `applyPresetJson` and then `customLoad` — same order. The `stateGeneration` bump must come **after** the image import is queued so the forced re-push shows the restored map (UI-04 regression criterion). The import job is asynchronous (≤ 100 ms at 1024², `import` (d)); ROADMAP's "two embedded 2 MB PNGs load in < 1 s" is the budget for decode + blur + projection of both slots.
3. **Fallback + Locate… is UI + C++.** The `#terrain-notice` node is bound to the pushed `sourceMissing` flag (`index.html:5081`, `PluginProcessor.h:183` status struct); `label.sourceMissing` is localised in three languages. Nothing exists for **Locate…**: a button inside the notice, a native (the chooser already exists as `chooseTerrainImage` — Locate… can reuse it with the slot's expected SHA-256 and refuse a file whose hash differs, or accept it and re-stamp — research item 3), and three new strings. The notice is transient for import failures (`NOTICE.transient`) and sticky for `sourceMissing`.
4. **Factory bank today = `Init`** (`FactoryPresets.cpp`, 49 lines, category "Init"). The bank is regenerated when `.factory-version` differs from `JucePlugin_VersionString`; the version stays 1.0.0 across the Stage 1 second pass and 4.1, so the on-disk `Init` under `~/Library/O-Strata/Presets/Factory/Init/` is an orphan 4.1 must delete (NOTES §Known Issues; Stage 1 CONTEXT D2). The five BRIEF use cases (breathing pad, feedback lead, microtonal Bandlimited bell, BYO-terrain placeholder on a library terrain, phase-distortion organ) are named presets; coverage: 6 terrains, 5 orbit families (Ellipse / Superellipse, Limaçon, Epitrochoid, Hypocycloid, Butterfly / Squarcle), feedback ≥ 3, Bandlimited ≥ 3. The harness loads the bank through `FactoryPresets::build` for H2 (ARCH H2 row) — currently `presets: 1 (Init)` in the H2 output.
5. **Chebyshev cost.** `clenshaw2D` (`ChebyshevSet.h:142`) is 2-D Clenshaw over the 153-float triangle, measured 84.6 ns per dependency-carried evaluation; H7 Bandlimited delta 11.61 / 12.06 % at verify vs 4.19 / 4.38 % at 2× and 7.38 / 7.50 % at 4×. The per-oscillator weighted copy (taper applied at publish) means the evaluator sees plain coefficients — the recurrence form needs no taper logic. `ChebyshevSet::liveCount` / the reaper are untouched by D4.
6. **What the CI Windows build can claim (COMPAT-02 and the WebView2 halves).** `ci-tests.yml`'s Windows job (O-Octagon's, lines 151-241) proves: MSVC compiles the code, the VST3 loads, pluginval 10 opens the editor (a blank WebView2 surfaces as an Editor-Automation failure or timeout). It **cannot** prove the 3D view renders correctly, the `dataTransfer.files` drop works, or the PERF-03 ≤ 2 ms figure on WebView2 — those need a human on a Windows machine, and there is none in the loop. **Ceiling for this stage:** COMPAT-02 → complete (build green + pluginval 10 on Windows); UI-01 / FUNC-07 → complete at "CI-built + editor opened under pluginval", their WebView2 hands-on rows recorded as a named deferral (owner none, blocked on hardware — O-Octagon's wording); PERF-03 → partial (WKWebView) if the Stage 3 human row 1 lands a number, else stays pending. REQUIREMENTS rows are annotated accordingly at Round B verify, not now.
7. **`ci-tests.yml` mechanics to mirror.** JUCE version read from `.github/juce-version.txt`; `vendored/JUCE-overrides` applied with the two `JUCE-NE-PATCH` greps; `SKIP_PLUGINS` built from every other `plugins/*/` folder; macOS single-arch, no `OUARICON_RELEASE` (harness hard-codes the dev manufacturer code); Windows: WebView2 NuGet step, `scripts/resolve-target.sh cmake-target` (which **warns and falls back to the folder name for O-Strata** — `juce_add_plugin(O-Strata` at `CMakeLists.txt:6`; the fallback happens to be right), pluginval 1.0.3 Windows zip, log artefact. O-Strata's harness target is `O-Strata-render-test` (`CMakeLists.txt:116-135`, `OUARICON_BUILD_TESTS`); `--gate all` ≈ 110 s locally (`export` and `orbits` never in `all`); `orbit-golden.mjs` needs Node. Third-party actions pinned by SHA.
