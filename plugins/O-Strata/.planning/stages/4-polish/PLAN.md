## Goal

Make the imported PNG survive plugin state and presets, make a missing source audible-but-not-silent and recoverable, and ship the factory bank. **Persistence:** the `terrainImports` child of the APVTS state and the preset-manager `customState` carry one `<slot>` per oscillator that holds an import — raw PNG bytes as standard base64 when the file is ≤ 2 MiB, else `path` + `sha256` + `name` — written and read by one processor-owned adapter pair; a restore re-imports through the Stage 2 API before the `stateGeneration` bump, so the view shows the restored map within one push interval. **Fallback:** an `Imported…` oscillator with no published image plays **Sine Product** on every quality path (today it is silent — RESEARCH C1), the `sourceMissing` flag reaches the status push, the notice grows a **Locate…** button whose native re-links the file only when its SHA-256 matches the slot. **Bank:** `FactoryPresets::build` becomes the 18-preset bank of RESEARCH §5.1 (six terrains, all eleven orbits, feedback × 3, Bandlimited × 3, the five BRIEF use cases), authored in engineering units, stamped `1.0.0+sha256(bank)` so the on-disk `Init`-only bank is swept and regenerated, and gated one preset at a time by H2 with the Coarse / Fine and osc-B blind spots closed. **Harness:** H10 grows the state round trip, the cap form, the missing / mismatched source, the two-PNG load budget and the UI-04 ordering row; smoke [5] asserts the new bank; the Round A gate list of RESEARCH §5.3 is green.

The one scope-affecting call in this plan is **Decision 2** (the 2 MiB cap contradiction): Stage 3 refuses every import above 2 MiB, so the path form and Locate… were unreachable by any user. This plan keeps the drop path exactly as Stage 3 verified it and raises the **file-chooser** cap to 8 MiB, which is the smallest change that makes FUNC-08's path form and QUAL-03's Locate… real features. Taylor can flip it before `/plugin-execute`.
