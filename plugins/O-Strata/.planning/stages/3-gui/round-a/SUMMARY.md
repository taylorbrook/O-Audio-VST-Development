4. **`.osc-view-btn` font stack gained the CJK faces** (measure-ui had flagged the six glyph buttons as undeclared under zh: 11 → 5 = baseline).
5. **`midiToNoteName` lives inside the byte-identical Tuning IIFE**, so the readout uses its own `noteName()` with the same convention (C4 = 60, sharps) rather than reaching into the IIFE.
6. **`tunedFrequency` is non-const** (`TuningEngine::getFrequency` is non-const); `copyCycle` takes a non-const processor for the same reason (`getAPVTS()`).
7. **`refreshTopNote` mirrors the oscillator's set rule**: a published set whose `key.terrain` ≠ the current terrain (the ≤ 100 ms window after a terrain change) yields −1, exactly as the voice plays the analytic 1× path then. In the sync harness path the readout poll precedes the publish, so the `topnote` rows poll twice (documented in the README row).
8. **`grep -c '<script type="module"'` reads 2** on both O-Prism and O-Strata (a comment mentions the tag); the layout gate counts `^<script type="module">` lines = 1, which is the intended assertion.
9. **Round A verify's `--inject-css` liveness form does not trip** the 666 assertion (the Terrain tab has 42 px of slack: 608 used of 650); `--viewport 1200x780` is the liveness control (51 failures).
