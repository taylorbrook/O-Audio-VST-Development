## Deviations and decisions taken in execution

1. **`copyHeightmap` follows the voice's set-selection rule, not "zeros when the pointer is null"** (Decision 31): in Bandlimited the map uses the candidate set only when `candidate->key.terrain == terrain` (the same test as `TerrainOscillator::updateBlockRate`), otherwise the analytic 1× fallback the voice actually plays — a view that went flat while the voice sounded the analytic terrain would contradict "the wireframe is the pushed heightmap of the active surface". Imported… with no published image still gives zeros (the voice is silent then).
2. **`force` bypasses the tick filters** for status and cycle as well as the heightmap. Decision 35's "not the tick filters" would drop a forced status / cycle push on an odd tick (the force flag is consumed) — the page-reload and preset cases need them; Round A's `if (force || even)` shape is kept.
3. **`.terrain-hud` takes pointer events** (`pointer-events: none` → default, `cursor: default`) so the ⌥-click perf burst of Decision 37 can land on it; it is a 10 px label in the bottom-left corner and a plain click does nothing.
4. **`selectNextPreset` / `selectPreviousPreset` return the loaded name** (`juce::String`, always loading when the bank is non-empty), not a bool — `notifyStateChanged()` fires on a non-empty name; the page still receives the name.
5. **The page imports only `makeScene, HM_N, perf, TAU`** — `viewProj`, `sampleH`, `surfaceH`, `orbitPoint`, `cycleFor` are used inside the module only. `TAU` joined the exports (the page's `snapshot()` needs it).
6. **`makeScene` gained a sixth argument `onNeedsRedraw`** — a context restore has to ask the page to redraw and the module is DOM-free; the badge callback is the fifth.
7. **`PLAYHEAD[osc]` is `null` until the first `terrainState`**; the scan point then rides the undisplaced orbit at θ = 0 and the HUD prints `θ 0.00` (the mockup's `{theta:0, x:0, y:0}` would have parked the point at the origin off the curve).
8. **Stub spy TDZ**: the first cut declared `const nativeCalls` beside `getNativeFunction`, below the preamble that publishes it — boot failed with "Cannot access 'nativeCalls' before initialization" on both plugins (memory `pattern_module_toplevel_init_tdz`); moved above the preamble.
9. **`gl.finish()` runs on every big-view frame** (the finish-inclusive figure of Decision 37) — at 30 Hz and sub-millisecond frames this is a stall of the same order as the frame; if a host shows UI jank it is the first thing to gate behind a flag.
10. **PERF-03 WKWebView rows and the hands-on rows were not driven** — see Task 13. The requirement's macOS half stays open for verify with the instrumentation in place; nothing in the code path is untested headlessly (the burst, the wrap report and the native call all ran in Chromium).
11. **The parity one-liner counts 32 natives** because its `[A-Za-z_]` name pattern skips `generateRank2` on both sides; the real count is 33 (`grep -c withNativeFunction`), all unique.
12. **Round B logs** live in the session scratchpad, not in `stages/3-gui/round-b-logs/` — every number is in the table above; nothing large was committed.
