### 2.3 Item 3 — Which voice feeds the ring; extracting one cycle

**Facts** `[VERIFIED: TerrainOscillator.cpp; StrataVoice.cpp]`:
- Ring slot `ring[(w & (kPoints−1))·4 + {0,1,2,3}] = {θ, px, py, y}`; `w = writeIndex.load(relaxed)` then `store(w+1, release)` after the four stores (`:408-415`). Reader: `load(acquire)`; `uint32_t` wraps after ≈ 12 h at 96 k — use unsigned differences.
- **θ is radians [0, 2π)** = `kTwoPi · phase`, phase post-warp (`:351-353, 443, 467-468`); the mockup consumes radians (`orbitPoint(p, i/N·TAU)`); the template's "theta in [0,1)" (`TEMPLATE.cpp:280`) is the odd one out.
- **px, py** = the orbit point AFTER affine, AFTER the feedback displacement, AFTER the ±1 clamp (`:360-361, 376-381, 413`) — the ring already stores the displaced path, so the trail IS the cycle.
- **y is PRE-saturation, PRE-DC-blocker** (`:413` precedes `saturate()` `:417`; the blocker runs on the summed output `:565-568`). The mockup's `surfaceH` uses `tanh(k·h)/tanh(k)` with **k = 1 + 7·sat** (`v2-ui.html:2305-2309`); the DSP uses **g = 1 + 4·sat** (`:427`) — fix the JS and apply the law on extraction.
- Only `partial == 0` writes (`:409`) — unison sub-voices never write.
- **Written per SUB-sample**: the write is inside `scan()`, called `os` times per base sample (`:519-520, 539-540, 548-549`); the header comment "per base sample" (`TerrainOscillator.h:84-85`) is wrong. Ring rate = fs·OS.
- **The one-voice rule already exists**: at block start every voice sets `oscA.setCaptureTarget(display ? captureA : nullptr)` with `display = currentMidiNote == processor->getLastPlayedNote()` (`StrataVoice.cpp:483-485`); `lastPlayedNote` is written in `startNote` (`:297`) and **never cleared** (`stopNote :406-418`). `voiceIndex` is only the harness phase seed (`StrataVoice.h:73, 236`). So Finding 4's "interleave" happens only when the same note is re-triggered while its older voice releases; the real gap is the ring **freezing** on its last cycle when the display voice ends while older notes sound.

**Rule for one trajectory** — recommend **A′**: keep `lastPlayedNote`; at block end, if the display voice is inactive, re-elect the active voice with the latest start order (≤ 16 `isVoiceActive()` loads, relaxed store, audio thread, no allocation; touchpoints `PluginProcessor.cpp:~1000`, `PluginProcessor.h:208-210`); the editor treats a non-advancing `writeIndex` as idle (no push, HUD dims). Rejected: B (capture-owner pointer — fixes the retrigger case only, adds pointer coupling), C (`voiceIndex == 0` — a random held note), D (every voice writes, page picks — 16 trajectories in one ring, no cycle recoverable).

**Extraction (message thread)**: (1) `w1 = load(acquire)`; `memcpy` the ring; `w2 = load(acquire)`; discard the newest `(w2 − w1) + 1` slots (torn); skip the tick if `w2 − w1 ≥ kPoints`. (2) From `k0 = w1 − 1` walk back while `θ[k] ≤ θ[k+1] + π` (a drop > π is the wrap, `:441-473`); the first wrap starts the current partial cycle, the second bounds the last COMPLETE cycle. (3) Resample to 512 by linear interpolation on slot index; for FM warp (θ non-monotone) fall back to the newest `L = fs·OS / f_display` slots with `f_display = getLastPlayedFrequency() · pitchRatio(coarse, fine)` (`PluginProcessor.h:229`, `StrataVoice.cpp:509-510`).
