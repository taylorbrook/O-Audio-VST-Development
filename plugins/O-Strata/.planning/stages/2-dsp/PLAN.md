## Goal

Both oscillators gain the two remaining terrain sources on the DSP side. **Bandlimited mode (Phase 2.4):** the terrain is a degree-16 Chebyshev triangle (153 coefficients) evaluated by 2-D Clenshaw at 1×, truncated per voice to D_max diagonals from K and f_note with a continuous raised-cosine taper, coefficient sets projected off the audio thread by a 50 ms scheduler (ModWheel / Aftertouch folded into the key, Terrain Freq clamped ≤ 2, Pitch Track inert), published by atomic pointer on the message thread, retired through the type-erased reaper, crossfaded on arrival, with readout atomics for Stage 3. **PNG path (Phase 2.5):** `TerrainImage` decoded, box-downsampled to ≤ 1024², luminance-mapped, 3-pass-box pre-blurred, read bilinearly with Mirror / Window edge handling, projected onto the same triangle at import for Bandlimited mode, reached through a processor import API (bytes or file) and the same scheduler (Blur / Edge re-runs at 150 ms debounce). The harness gains a message-loop `pump`, the Bandlimited H6 rows (≤ −90 dB), the swap storm, H10 (bytes determinism) and H11 (edge continuity), an ASan configuration, and a README listing H1–H11 with commands executable as written; `--gate all` stays ≤ 3 min.

**Requirements verified in Round B:** DSP-02; FUNC-06, QUAL-01 (Bandlimited halves → complete); DSP-04 (pre-blur / edge half → complete); PERF-01 (scheduler + import never on the audio thread); FUNC-07 (DSP half: import API, Blur, Edge); FUNC-08 (bytes half: identical bytes ⇒ identical render). Every other Stage-2 ID is re-verified by the final `--all` run. The `terrainImports` state child, presets, the UI and CI stay in Stages 3–4.
