# O-Detune v1.1.0 Improvement Brief

## Overview
Complete the implementation of O-Detune - the UI structure and parameter definitions exist, but most parameters are disconnected from the DSP and the UI aesthetic needs updating.

## Version Change
- **Current:** 1.0.0
- **Target:** 1.1.0 (MINOR - significant feature completions)

## Issues to Address

### 1. UI Aesthetic Update
**Problem:** Current UI uses dark purple/teal theme
**Solution:** Apply Ouaricon Botanical Aesthetic with:
- Paper background texture: `Resources/paper_background.jpg`
- Botanical slug illustration: `Resources/slug.png`
- Warm, natural color palette
- Handwritten/organic feel

### 2. Disconnected Parameters (DSP Bug)
**Problem:** Most parameters defined in APVTS but never read in processBlock()

**Disconnected parameters:**
- `wobble_era` - Never read (60s/70s/80s has no effect)
- `wobble_shape` - Never read (always uses sine LFO)
- `unison_voices` - Hardcoded to 3 (`constexpr int activeVoices = 3;`)
- `unison_dist` - Never read
- `unison_spread` - Never read
- `drive` - Never read
- `color` - Never read
- `age` - Never read
- `delay` - Never read
- `feedback` - Never read
- `random_amt` - Never read
- `wobble_sync` - Never read
- `mono_safe` - Never read

**Solution:** Implement DSP logic for each parameter in processBlock()

### 3. Random Wobble Shape
**Problem:** The "Random" option in wobble shape does nothing - LFO is hardcoded to sine
**Solution:** Implement truly random (sample-and-hold or smoothed noise) LFO when shape = "Random"
- Should be non-repeating, not a periodic pattern
- Consider smoothed random walk or sample-and-hold with interpolation

### 4. Era Character Implementation
**Problem:** Era selector (60s/70s/80s) exists but has zero implementation
**Solution:** Either:
- A) Implement meaningful character differences based on era:
  - 60s: Subtle, slower drift, tube-like warmth
  - 70s: Classic tape wobble, moderate depth
  - 80s: Digital-ish, cleaner pitch modulation
- B) Remove the era selector if not meaningfully implementable

**Recommendation:** Implement Option A - the parameters exist, make them meaningful
