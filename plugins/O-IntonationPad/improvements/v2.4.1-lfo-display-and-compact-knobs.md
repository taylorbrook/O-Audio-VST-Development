# Improvement: LFO-driven waveform display + compact lower knob rows

## Plugin
O-IntonationPad

## Version
v2.4.0 -> v2.4.1 (PATCH)

## Changes

### 1. Waveform displays update with LFO modulation
The wavetable waveform canvases (added in v2.4.0) currently only update when the user manually changes the bank or position knob. They should also animate to reflect the LFO modulation of the wavetable position (Rate + Depth parameters).

**Approach:** In the C++ `timerCallback()` (runs at 30Hz), emit the current effective wavetable position for each oscillator (after LFO modulation is applied) via a WebView event. The JS `WavetableDisplay` instances should listen for this event and redraw at the modulated position. This gives smooth visual feedback showing how the LFO sweeps through the wavetable.

- The processor already tracks `lfoPhaseA`/`lfoPhaseB` and computes modulated positions in `processBlock`
- Add a method to PluginProcessor that returns the current modulated position for each oscillator (read the LFO phase + depth + base position)
- In `timerCallback()`, emit an event like `"wavetableModPos"` with `{posA: float, posB: float}`
- In JS, listen for this event and call `fetchAndDraw()` on both displays with the modulated positions
- Keep the existing bank-change and manual position-change listeners as fallbacks

### 2. Make envelope/filter/randomization knob rows more compact
The two lower knob rows in the Synth tab (envelope: Attack, Decay, Sustain, Release, Filter, Flt LFO, Vel>Flt, Volume; and randomization: Timing, Detune) are too large and get clipped. Make them smaller so both rows and their value readouts are fully visible.

**Approach:** These knobs currently use the default (large) size. Change them to use `size: 'small'` in the `populateKnobs` calls for `synth-env-knobs` and `synth-random-knobs` in the DOMContentLoaded handler. This matches the oscillator knob sizing and should fit everything within the tab viewport.
