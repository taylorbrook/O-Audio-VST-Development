# Bug: Custom Scale Builder UI Not Visible

## Version
v1.5.0 (installed 2026-02-18)

## Symptom
When "Custom" is selected in the Key Scale dropdown on the Voice tab, no custom scale builder UI appears. The user expects to see the builder interface when selecting "Custom" from the dropdown.

## Root Cause (Investigation Needed)
The Custom Scale Builder was added to the **Tuning tab** (as a collapsible section in tuning-panel.js), NOT the Voice tab where the Key Scale dropdown lives. There is no connection between selecting "Custom" in the Voice tab dropdown and showing builder UI inline.

Two possible issues:
1. **UX gap**: Selecting "Custom" in the Voice tab dropdown should either show an inline builder OR navigate/prompt the user to the Tuning tab's Custom Scale section.
2. **Builder visibility**: The builder section in the Tuning tab may also need testing — confirm it renders and the collapsible toggle works.

Option A: When "Custom" is selected in keyScaleSelect dropdown, auto-switch to the Tuning tab and expand the Custom Scale builder section.
Option B: Add an inline mini-builder directly in the Voice tab when "Custom" is selected.
Option C: Show a hint message in the Voice tab saying "Build your scale in the Tuning tab" when Custom is selected.
