## Decisions made this discuss (the only open items)

### D1 — Built-in source samples: **procedural synthesis = the shipping v1.0 content**
The 4 built-ins (`fire` / `voice` / `water` / `piano`) did not exist in the repo and the
grain engine cannot make or validate sound without at least one. **User decision
(2026-06-24):** synthesize them procedurally to ship quality and treat the generated
`.wav` files as the **final v1.0 built-ins** (no later swap to recordings).

- **Assets:** `plugins/O-simpleGrain/Source/samples/{fire,voice,water,piano}.wav`,
  mono, 44.1 kHz, 24-bit PCM, ~2–3 s each (within the 10 s source cap).
- **Provenance / reproducibility:** generated by a checked-in, seeded script
  (`plugins/O-simpleGrain/tools/generate_samples.py`) so the shipping assets are
  regenerable and version-controlled.
- **Synthesis recipes:**
  - `fire` — low filtered brown-noise bed + random exponentially-decaying crackle bursts.
  - `water` — bandpassed noise stream + random rising-pitch "bloop" bubble chirps.
  - `voice` — glottal pulse train (~123 Hz, slight vibrato) through "ah" formant filters
    (F1≈730, F2≈1090, F3≈2440) + light breath.
  - `piano` — struck inharmonic partial sum (slightly stretched), per-partial exponential
    decay (highs decay faster) + onset hammer-noise transient.
- **Accepted risk:** `voice`/`piano` read as synthetic vs. real recordings — acceptable
  for a teaching instrument where granular *behaviour* (size/density/window/spray) is the
  lesson, not source fidelity. Fire/water synthesize convincingly.
- **Engine impact:** Phase 2.1 decodes the default (`fire`) at construction; Phase 2.3
  embeds all four via `juce_add_binary_data` + atomic hot-swap on `sourceSample`.

## Locked contract carried into DSP (from ARCHITECTURE.md — immutable)

**Engine model:** `juce::Synthesiser` + custom `GrainVoice : juce::SynthesiserVoice`
(8 voices). Per voice: preallocated `std::array<Grain, 24>` pool, round-robin /
**steal-oldest** spawn (never allocates, never xruns); global cap 192.

**Scheduler:** per-sample countdown; base period `= fs / density`; `scatter` jitters the
period (sync↔async, DSP-05); `velToDensity` opt-in scales effective density.

**Grain read:** 4-point **Lagrange** fractional read (random access) + per-grain
**rate-tracking one-pole** low-pass (`fc ≈ 0.5·fs/rate`) applied only when `rate > 1`
(band-limit up-transposition, DSP-08). Overlap-add summation; equal-power per-grain pan.

**Transposition (decision #2):** `rate = 2^((noteNumber − 60 + grainPitch + pitchSprayRand)/12)`.
ROOT_NOTE = 60 (C3) → source at recorded pitch on C3.

**Window LUTs:** five precomputed 2048-pt tables (rect / tri / Welch / Gauss / Hann),
linear-interp read by grain phase. **Rectangular click is an intended teaching artifact.**

**Read head (global, processor-owned):** `playheadPos` advanced by `scan%·realtime`/sample,
wrapped to `[0, sourceLen)`; `position` sets the resting point; `freeze` pins velocity to 0
with a **smoothed/crossfaded** engage/disengage (zipper-free, QUAL-01). Grains read offsets
relative to it ± `positionSpray`.

**Amp:** `juce::ADSR` (voice lifetime = `ampEnv.isActive()`); velocity→amp always-on;
`outputLevel` `SmoothedValue` (dB→lin, 20 ms) + overlap-aware headroom normalization.

**Sample loading:** built-ins embedded `.wav` → decode via
`AudioFormatManager::createReaderFor(MemoryInputStream)` + resample to engine rate
off-thread → **atomic pointer swap** publish. Load-your-own = macOS WebView
content-streaming drag-drop (**`juce::Base64::convertFromBase64`, NOT
`MemoryBlock::fromBase64Encoding`**) + `FileChooser` picker fallback; 10 s cap.

**Viz taps (audio thread, lock-free, no alloc, no FFT):** mono-sum → `VizRing`;
per-spawn grain event → `TripleBuffer<GrainCloudFrame>`; `std::atomic<int> activeGrainCount`.
FFT/cloud/meter built on the message-thread Timer (Stage 3 consumes these).

**Latency:** `setLatencySamples(0)` (`getLatencySamples()` non-virtual in JUCE 8 — do NOT override).
**Denormals:** `ScopedNoDenormals` + block-level `std::isfinite` scrub.
