**Part A: Create `.claude/scripts/create-digest.sh`**

Create a bash script that generates a DIGEST.json for a given plugin. Usage: `bash .claude/scripts/create-digest.sh <PluginName>`

The script must:
1. Accept plugin name as argument
2. Set `PLANNING="plugins/$1/.planning"`
3. Extract from STATUS.md frontmatter: stage, phase (use grep/sed)
4. Extract complexity score from ROADMAP.md (look for "Complexity Score" or "complexity" followed by a number)
5. Extract parameter IDs from parameter-spec.md (parse table rows starting with `| paramName`, extract the first column)
6. Extract DSP component names from research/ARCHITECTURE.md (look for class names or juce::dsp:: references)
7. Build a JSON object with python3:
   ```json
   {
     "plugin": "PluginName",
     "stage": "extracted_stage",
     "phase": "extracted_phase",
     "complexity": N,
     "parameters": ["param1", "param2", ...],
     "dsp_components": ["Component1", "Component2", ...],
     "contracts": {
       "brief": ".planning/BRIEF.md",
       "params": ".planning/parameter-spec.md",
       "arch": ".planning/research/ARCHITECTURE.md",
       "roadmap": ".planning/ROADMAP.md"
     },
     "decisions": {}
   }
   ```
8. Write to `plugins/$1/.planning/DIGEST.json`
9. Validate the output is under 2000 characters (approximately 500 tokens). If over, truncate parameter and component lists.
10. Make executable (chmod +x)

Handle missing files gracefully (empty arrays/strings for missing data). Use `jq` for JSON construction if available, fall back to python3.

**Part B: Add DIGEST generation trigger to checkpoint-protocol.md**

Update `.claude/skills/plugin-workflow/references/checkpoint-protocol.md` to add a DIGEST.json generation step at stage completion checkpoints. After the git commit for a stage completion, add:


This ensures DIGEST.json is updated at every stage boundary (Stage 0 complete, Stage 1 complete, etc.).
