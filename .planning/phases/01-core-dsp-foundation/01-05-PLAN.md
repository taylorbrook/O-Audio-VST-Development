   ```cpp
   void CrossoverFilter::precomputeFIRBank()
   {
       // Resize bank to hold all pre-computed filters
       firCoefficientBank.resize(kNumPrecomputedFilters);

       // Pre-compute coefficients for each frequency
       for (int i = 0; i < kNumPrecomputedFilters; ++i)
       {
           float freq = kMinFreq + static_cast<float>(i) * kFreqStep;
           firCoefficientBank[static_cast<size_t>(i)] = generateWindowedSincLowpass(freq, firTapCount);
       }
   }
   ```

4. **Add frequencyToIndex():**
   ```cpp
   int CrossoverFilter::frequencyToIndex(float freqHz) const
   {
       // Clamp and quantize to nearest pre-computed index
       freqHz = juce::jlimit(kMinFreq, kMaxFreq, freqHz);
       int index = static_cast<int>(std::round((freqHz - kMinFreq) / kFreqStep));
       return juce::jlimit(0, kNumPrecomputedFilters - 1, index);
   }
   ```

5. **Add loadFilterAtIndex():**
   ```cpp
   void CrossoverFilter::loadFilterAtIndex(int index)
   {
       // Load into inactive buffer, then swap
       const auto& coeffs = firCoefficientBank[static_cast<size_t>(index)];

       // Create AudioBuffer from pre-computed coefficients (this allocation is OK - called from non-RT thread only)
       juce::AudioBuffer<float> irBuffer(1, firTapCount);
       irBuffer.copyFrom(0, 0, coeffs.data(), firTapCount);

       // Load into INACTIVE buffer
       int active = activeFirBuffer.load();
       auto& targetConvolution = (active == 0) ? firLowpassB : firLowpassA;

       targetConvolution.loadImpulseResponse(
           std::move(irBuffer),
           sampleRate,
           juce::dsp::Convolution::Stereo::no,
           juce::dsp::Convolution::Trim::no,
           juce::dsp::Convolution::Normalise::no
       );

       // Atomic swap to new buffer
       activeFirBuffer.store((active == 0) ? 1 : 0);
       currentFirIndex.store(index);
   }
   ```

   Actually, **better approach for true RT-safety**:
   - Store coefficients in bank (done)
   - Do NOT reload Convolution on parameter change
   - Instead, in process(), directly use the appropriate pre-computed coefficients
   - But juce::dsp::Convolution requires loadImpulseResponse...

   **Simplest RT-safe solution**: Load ALL filters into separate Convolution objects at prepare time (memory heavy but bulletproof). Given 33 filters and memory constraints, let's try a middle ground:

   **REVISED APPROACH - Quantized response without reload:**
   - Pre-compute all coefficient vectors (done)
   - Keep single Convolution, loaded with initial frequency filter at prepare
   - When frequency changes in FIR mode: update currentFirIndex but DON'T reload
   - Filter uses the prepare-time loaded filter until next prepare
   - This is technically "stale" but completely RT-safe

   This matches VERIFICATION.md recommended fix #2: "Defer coefficient updates until next prepareToPlay"

   Update setCutoffFrequency to NOT trigger any FIR reload:
   ```cpp
   void CrossoverFilter::setCutoffFrequency(float freqHz)
   {
       freqHz = juce::jlimit(40.0f, 200.0f, freqHz);

       if (std::abs(targetCutoffHz - freqHz) > 0.01f)
       {
           targetCutoffHz = freqHz;

           // IIR mode: use smoothed value
           smoothedCutoff.setTargetValue(freqHz);

           // FIR mode: store desired index for next prepare()
           // Do NOT reload filter in real-time - deferred until prepareToPlay
           if (currentMode == Mode::HighFidelity)
           {
               pendingFirIndex = frequencyToIndex(freqHz);
           }
       }
   }
   ```
