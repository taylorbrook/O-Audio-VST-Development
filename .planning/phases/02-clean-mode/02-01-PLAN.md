Create a YIN-based monophonic pitch detector optimized for bass frequencies (30-200Hz):

**PitchTracker.h:**
- Class with prepare(double sampleRate, int maxBlockSize), reset() lifecycle
- detectPitch(const float* input, int numSamples) returns frequency in Hz (0 if no pitch)
- Private members: sampleRate, windowSize, writeIndex, buffer (ring buffer), yinBuffer
- Use std::vector for internal buffers (allocated in prepare only)

**PitchTracker.cpp:**
- Window size calculation: `(sampleRate / 30.0) * 2` for 2 periods at 30Hz minimum
- Cap window at 4096 samples for performance
- YIN algorithm steps:
  1. Accumulate samples into ring buffer
  2. Compute difference function d(tau)
  3. Compute cumulative mean normalized difference d'(tau)
  4. Find first minimum below threshold (0.1)
  5. Apply parabolic interpolation for sub-sample accuracy
  6. Return sampleRate / tau as frequency

**Key implementation details:**
- Ring buffer for continuous sample accumulation
- Threshold 0.1 (YIN default, stricter = fewer false positives)
- Return 0.0f when no pitch detected (no minimum below threshold)
- Parabolic interpolation: `tau + (s2-s0) / (2*(2*s1-s2-s0))`

Reference: de Cheveigne & Kawahara 2002 YIN algorithm, code example in 02-RESEARCH.md
