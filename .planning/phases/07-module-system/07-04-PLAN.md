## Command: /module:upgrade-all

Upgrade all modules across all plugins with preview before proceeding.

## Usage

```
/module:upgrade-all [--dry-run]
```

## Workflow

1. **Scan all modules**
   - For each module in registry.modules:
     - Compare version to installed versions in all plugins
     - Build list of available updates

2. **Show preview** (always, per user decision)
   ```
   /module:upgrade-all

   Module Update Preview
   ═══════════════════════════════════════════════════════════════

   scala-tuning-engine: 1.0.0 -> 1.1.0
     Plugins: O-IntonationPad (modified), O-Marimba
     Breaking: No

   preset-manager: 1.0.0 -> 1.2.0
     Plugins: O-Marimba, O-Tremolo, O-Lyrica
     Breaking: No

   analog-eq-unit: 1.2.0 -> 2.0.0
     Plugins: O-Marimba
     Breaking: YES (major version)

   Summary:
     3 modules with updates
     5 plugin updates total
     1 breaking change

   Proceed with upgrades? [y/n]:
   ```

3. **If confirmed:**
   - For each module, run the same workflow as /module:upgrade
   - Respect per-plugin choices for customized modules
   - Collect results

4. **Report summary:**
   ```
   Upgrade Complete
   ─────────────────────────────────────────────────────────────
   Modules updated: 3
   Plugins updated: 4
   Skipped (customizations): 1

   Details:
     scala-tuning-engine:
       O-IntonationPad: Skipped (local customizations)
       O-Marimba: Updated 1.0.0 -> 1.1.0

     preset-manager:
       O-Marimba: Updated 1.0.0 -> 1.2.0
       O-Tremolo: Updated 1.0.0 -> 1.2.0
       O-Lyrica: Updated 1.0.0 -> 1.2.0

     analog-eq-unit:
       O-Marimba: Updated 1.2.0 -> 2.0.0
   ```

## --dry-run Flag

Shows preview only, does not make changes.

## Manual Rebuild Guide (MODS-04)

### When Manual Intervention is Needed

1. **After /module:remove if you want full removal**
   - Delete copied files
   - Remove #include directives
   - Comment out ouaricon_add_module()

2. **After upgrade fails rollback**
   - Check build log for errors
   - May need code changes for new API

3. **After manual file edits**
   - Run /module:add again to resync (optional)
   - Modified flag tracks your customizations

### Rebuild Commands

```bash
cd /Users/taylorbrook/Dev/VST-development/build

# Rebuild single plugin
ninja O-IntonationPad_VST3 O-IntonationPad_AU

# Clear cache if CMake changes
rm -rf CMakeCache.txt CMakeFiles/
cmake ..
ninja
```

### Post-Build Verification

```bash
# Clear AU cache and reinstall
killall -9 AudioComponentRegistrar 2>/dev/null || true
rm -rf ~/Library/Caches/AudioUnitCache/

# Install fresh binaries
cp -R build/plugins/O-IntonationPad/O-IntonationPad_artefacts/Release/VST3/*.vst3 ~/Library/Audio/Plug-Ins/VST3/
cp -R build/plugins/O-IntonationPad/O-IntonationPad_artefacts/Release/AU/*.component ~/Library/Audio/Plug-Ins/Components/

# Verify AU registration
auval -a | grep -i IntonationPad
```

## Troubleshooting

### Module not found in CMake
- Verify ouaricon_add_module() line exists
- Check OuariconModules.cmake is included

### Registry out of sync
- Run /plugin:status to check state
- Registry is source of truth for module tracking

### Hash mismatch after manual edits
- Expected if you modified module files
- "modified: true" in registry tracks this
- /module:upgrade will warn before overwriting

## Design Decisions

Document key decisions from CONTEXT.md:
- Each plugin gets its own version (no forced single version)
- Soft removal keeps code
- Verbose output by default
- No auto-repair without prompting
