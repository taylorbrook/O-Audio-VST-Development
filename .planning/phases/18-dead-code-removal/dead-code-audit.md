**Estimated cleanup: variable (depends on wire-vs-delete decision)**

- **All 12 validator scripts** in `.claude/hooks/validators/` are called by task-validator-dispatch.py (wired in settings.json) or SubagentStop.py. If SubagentStop is deleted, some validators lose their secondary caller but remain active via task-validator-dispatch.
