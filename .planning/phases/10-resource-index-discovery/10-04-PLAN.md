def discover(

    agent_role: str,               # Agent role: "dsp", "ui", "build", "research"

3. **Weighted scoring algorithm** (from research):
```python
def score_document(doc, stage, agent_role, keywords):
    score = 0.0
    # Stage match: 0.4 weight
    if stage in doc["stages"]:
        score += 0.4
    # Agent role match: 0.35 weight
    if agent_role in doc["agents"]:
        score += 0.35
    # Keyword overlap: 0.25 weight (normalized)
    if keywords:
        doc_keywords = set(doc["keywords"])
        query_keywords = set(k.lower() for k in keywords)
        overlap = len(doc_keywords & query_keywords)
        if overlap > 0:
            score += min(overlap / 3.0, 1.0) * 0.25
    return score
```

4. **Result tiering:**
- `primary`: Document matches BOTH stage AND agent role (score >= 0.75)
- `supplementary`: Document is above threshold but doesn't match both dimensions

5. **Return format:** List of dicts sorted by relevance (descending):
```python
{
    "path": "research/...",
    "title": "...",
    "summary": "...",
    "relevance": 0.85,
    "tier": "primary",
    "match_reasons": ["stage_match", "role_match", "keyword:fft"]
}
```
