    **Create `.claude/scripts/canary-test.sh`:**

    ```bash
    #!/bin/bash
    # Canary test script for Plugin Freedom System
    # Tests O-SimpleReverb (standard plugin) and O-AnalogEQ (WebView plugin)
    # Run after any system-level changes to verify no breakage

    set -e

    PROJ_DIR="/Users/taylorbrook/Dev/VST-development"
    BUILD_DIR="$PROJ_DIR/build"

    echo "=== PFS Canary Test ==="
    echo "Date: $(date)"
    echo ""

    # Ensure build directory exists and has been configured
    if [ ! -f "$BUILD_DIR/build.ninja" ]; then
      echo "ERROR: Build not configured. Run cmake first."
      exit 1
    fi

    cd "$BUILD_DIR"

    # --- Canary 1: O-SimpleReverb (standard plugin) ---
    echo "--- Canary 1: O-SimpleReverb ---"
    echo "Building VST3 + AU..."
    ninja O-SimpleReverb_VST3 O-SimpleReverb_AU 2>&1 | tail -5

    echo "Clearing AU cache..."
    killall -9 AudioComponentRegistrar 2>/dev/null || true
    rm -rf ~/Library/Caches/AudioUnitCache/
    rm -rf ~/Library/Caches/com.apple.audiounits.cache

    echo "Installing..."
    rm -rf ~/Library/Audio/Plug-Ins/VST3/O-SimpleReverb.vst3
    rm -rf ~/Library/Audio/Plug-Ins/Components/O-SimpleReverb.component
    cp -R plugins/O-SimpleReverb/O-SimpleReverb_artefacts/Release/VST3/O-SimpleReverb.vst3 ~/Library/Audio/Plug-Ins/VST3/
    cp -R plugins/O-SimpleReverb/O-SimpleReverb_artefacts/Release/AU/O-SimpleReverb.component ~/Library/Audio/Plug-Ins/Components/

    echo "Validating AU..."
    if auval -v aufx Srvb Oblq 2>&1 | grep -q "PASS"; then
      echo "PASS: O-SimpleReverb AU validation passed"
    else
      echo "WARN: auval did not explicitly PASS — check manually"
    fi

    # --- Canary 2: O-AnalogEQ (WebView plugin) ---
    echo ""
    echo "--- Canary 2: O-AnalogEQ (WebView) ---"
    echo "Building VST3 + AU..."
    ninja O-AnalogEQ_VST3 O-AnalogEQ_AU 2>&1 | tail -5

    echo "Installing..."
    rm -rf ~/Library/Audio/Plug-Ins/VST3/O-AnalogEQ.vst3
    rm -rf ~/Library/Audio/Plug-Ins/Components/O-AnalogEQ.component
    cp -R plugins/O-AnalogEQ/O-AnalogEQ_artefacts/Release/VST3/O-AnalogEQ.vst3 ~/Library/Audio/Plug-Ins/VST3/
    cp -R plugins/O-AnalogEQ/O-AnalogEQ_artefacts/Release/AU/O-AnalogEQ.component ~/Library/Audio/Plug-Ins/Components/

    echo "Validating AU..."
    if auval -v aufx AneQ Oblq 2>&1 | grep -q "PASS"; then
      echo "PASS: O-AnalogEQ AU validation passed"
    else
      echo "WARN: auval did not explicitly PASS — check manually"
    fi

    echo ""
    echo "=== Canary Test Complete ==="
    ```

    Make the script executable: `chmod +x .claude/scripts/canary-test.sh`

    **Important notes for the script:**
    - The `auval` manufacturer/type codes above are EXAMPLES — read the actual CMakeLists.txt for each plugin to get the correct PLUGIN_CODE and MANUFACTURER_CODE
    - Check `plugins/O-SimpleReverb/CMakeLists.txt` for the actual codes
    - Check `plugins/O-AnalogEQ/CMakeLists.txt` for the actual codes
    - Update the auval command accordingly: `auval -v aufx {PLUGIN_CODE} {MANUFACTURER_CODE}`

    **Run the canary test:**
    ```bash

    ```

    Both plugins must build successfully. AU validation should pass (at minimum, build without errors).

    If build fails: debug in place (per discretion decision). Check if path changes in hooks broke any build-time validation.
