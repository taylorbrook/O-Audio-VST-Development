### J2. The gate-file inventory grep returns THREE and the answer is FIVE — it is blind to two shapes

Stage 3's `260904-g5l-SUMMARY.md` §1 gives the canonical inventory grep, and every wave since has
used it. Fired repo-wide at planning time, comment-stripped exactly as g5l spells it:

```bash
for f in plugins/*/tests/*.js; do
  perl -0777 -pe 's{/\*.*?\*/}{}gs; s{//[^\n]*}{}g; s{^\s*\*.*$}{}gm' "$f" \
    | grep -q "en,fr\|\['en', *'fr'\]" && echo "${f#plugins/}"

```

It returns exactly three: `O-Bowed`, `O-Reed`, `O-Wind`. That number is where wave 4e's N12 and
s71's item 3 both get "exactly three two-language gate files remain in the repo". **It is wrong for

| `plugins/O-Contrabass/tests/ui_frontend_check.js` | it holds **no list and no `en,fr` string at all** — the enumeration is per-language **object property access** on each table entry | asserts `e.fr`, `!e.fr.t`, `I18N[k].fr.t`, `I18N[k].fr.b` at raw **L196-197, L256, L269-273**, feeding two real `check()` calls |

**Say this in the SUMMARY as a correction to the inventory method, not only to the count.** A grep
that has been the rollout's inventory for six waves has a false-negative class, and the class is

### J3. Enumeration form 1 appears for the first time — and it HARD-FAILS on the flip

Waves 4a-4c found forms 2, 3, 4 and 5. Wave 4d found the fifth. Wave 4e reported explicitly that
**form 1 (an assertion on `LANGUAGES.join(',')`) is absent**. It is present here, on three plugins,
at raw line numbers:

| plugin | raw line | the assertion |
|---|---|---|
| O-Wind | **L295** | `check(LANGUAGES.join(',') === 'en,fr', …)` — tagged `[0]` |
| O-Reed | **L252** | same shape, untagged |
| O-Bowed | **L227** | same shape, untagged |

**This is the loudest failure mode in the rollout and the only benign one.** Unlike the vacuous-green
shapes, a form-1 assertion cannot go quiet: the instant `LANGUAGES` gains a third member, all three
gates fail at their first check with a message naming the actual list. The danger is not that it
hides — it is that an executor who flips the table before repairing the gate sees three red gates
and cannot tell them from a real regression.

**Repair shape:** the loader on all three already publishes `LANGUAGES` from its `vm` sandbox
(O-Wind L187, O-Reed L172, O-Bowed L152 — `runInContext` publishing `{ I18N, TIP_BINDINGS,
LANGUAGES }`), and all three already destructure it (L290 / L249 / L221). So there is nothing to
add to a loader. Replace the joined-string equality with a **shape assertion plus a derive-or-abort**
in O-ReverseDelay's shipped form: assert `LANGUAGES` is a non-empty array whose first member is the
English code, and abort with the refusal message rather than sweep a guessed list (C5/C6).
**Word the explanatory comment as prose (C8)** — spelling the superseded two-element literal in the

## Execution shape — every long command runs in the BACKGROUND

**Non-negotiable, and the reason is a measured failure.** Wave 4d's first executor stalled on the
600-second no-progress watchdog **three times**, and a stalled agent's context cannot be resumed —
the work was lost and a fresh executor had to re-derive it. Every command in this plan that can
exceed ~60 seconds MUST be dispatched with `run_in_background: true` and polled, never run in the
foreground.

That covers, without exception:

| command class | why it stalls |
|---|---|
| `./scripts/build-and-install.sh <Folder>` | a full CMake + ninja build, minutes |
| `auval -v <type> <subtype> <mfr>` | a cold registry rescan |
| `node scripts/measure-ui.js …` | Playwright, every state, three languages |
| `node scripts/check-ui-labels.js …` | same |
| `node scripts/boot-all-uis.js --strict-tips` | boots all 43 UIs — measured ~4 min |
| `node plugins/<Name>/tests/ui_tip_render_check.js` | Playwright, 36+ anchors x N languages — measured 60-120 s each |
| `node scripts/i18n-zh-lint.js` (repo-wide) | 44 plugins, 2841 entries |
| the blind reverse dispatch (`claude -p …`) | an external agent reading up to 92 rows |

Poll with an until-loop on a sentinel written by the backgrounded command itself
(`echo ALLDONE >> …`), not with a fixed `sleep`. **`timeout` does not exist on this machine.**

**s71's D11 corrects the auval budget and this plan adopts the correction:** the "~15 minute cold
rescan" figure is stale. Measured on this machine on 2026-09-06, `auval -a` after five consecutive
installs took **84 seconds**, and five `auval -v` runs together took under two minutes; the five
builds took **3 minutes total**. The batch-at-the-end discipline is still right — it is one rescan
instead of five — but **do not refuse a mid-batch check on the strength of a 15-minute budget.**

**Each task below is independently executable by a FRESH executor.** Each carries its own required
reading, its own precondition-fire block, its own restatement of the ship bar and its own commit
stream. Nothing in Tasks 2-6 depends on holding Task 1's context — only on Task 1's **committed
artifacts and its written record**, which is why the tracer's findings are a deliverable rather than
a side effect.

### Tooling traps confirmed live during this planning pass

- **A zsh glob that matches nothing ABORTS the whole command**, including the parts that would have
  matched. This planning pass lost a CSS census to `ls <root>/css/*.css` on five plugins that have no
  `css/` directory at all. Use `find`, or guard with `(N)`.
- **`perl -0777` piped into a shell variable then `grep -c`'d silently returned empty** on
  O-Contrabass's 2552-line `index.html` during this pass and reported five zeros that were not zeros.
  **Write the stripped file to a temp path and grep the FILE.**
- **`grep -P` with a Han property byte-matches on this machine** and reports phantom hits on the
  middle dot U+00B7 — which every one of these four consumers renders, in `Intervals · notes: {n}`.
  Use the `perl -CSD` form in the verify blocks. A Han script property in perl **without** `-CSD` is
  inert.
- **Comment-blind greps lie.** Strip comments before any code count:
  `perl -0777 -pe 's{/\*.*?\*/}{}gs; s{//[^\n]*}{}g; s{^\s*\*.*$}{}gm' <file>`.
- **`auval -v` takes THREE UNQUOTED words** (M14). `auval -v "aumu OWnd OuDv"` prints
  `Invalid Arguments: auval` and no further output, which across five plugins reads exactly like five
  validation failures.
- **`./scripts/build-and-install.sh` resolves the `juce_add_plugin` target itself, so pass the FOLDER
  name** even on O-GrainScatter, whose target is `OuariconGrainScatter`.
- **`timeout` does not exist on this machine**, **zsh does not word-split an unquoted variable**
  (s71 D9: `set -- $PV` in a `for PV in "O-Bowed 1.9.0" …` loop hands the body one path — run those
  loops under `bash -c`), and **every `--include` glob must be quoted** or the grep fails entirely

- **`awk '/name: X/,/^  - name: /'` range patterns collapse to one line** (s71 D9) — awk tests the
  END pattern on the START line. Working form:
  `awk '/- name: X/{f=1;next} f&&/^  - name: /{f=0} f'`.
- **`resolvePlaywright()` in `scripts/serve-ui.js` returns the MODULE, not a path** — passing it to

- **Comment-stripped line numbers are NOT the numbers you edit.** Every raw line number cited in J2-J16
  is a **raw** number. Census with the stripped file; edit with the raw one.
