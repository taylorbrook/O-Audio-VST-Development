## 4. Structural findings — merged across all three tasks

### F1. The gate was BLIND to a file five shipping products run — and the blindness was proven, not argued

`check-i18n`'s `pageModules` was index.html's inline scripts plus the plugin's own
`js/` directory. A module embedded from CMake was scanned by **nothing**, so
assertion 12 could not see the panel's prose and assertion 15 would have read its
keys as dead.

The extension derives the list by **scanning the build file**, never a transcribed
filename list — the same rule the file already argues for its directory scan.
CMake `#`-comment lines are dropped first; deduped by resolved path **and** by
code; `.bundle.js`/`.min.js` route through the existing `bundlesSkipped` path; and
a path CMake names that is **not on disk** raises a check failure rather than
silently shrinking the scanned set.

**Fired unrestricted repo-wide BEFORE a byte of the module was keyed. Exit 7:**

| Plugin | `[12]` findings | newly-scanned source |
|---|---|---|
| O-Bassoon / O-Bowed / O-Reed / O-Wind | **39** each | tuning-panel.js |
| O-Contrabass | **46** | tuning-panel.js **+ preset-manager.js** |
| O-Marimba | 5 | analog-eq-unit.js, compressor-unit.js |
| O-ReverseDelay | 6 | preset-manager.js |

The five FAIL lines, verbatim, are in `260906-s71-TASK1-SUMMARY.md` §3; the full
capture is `scratchpad/s71-stepB-repowide-BEFORE.txt`. A gate that cannot fail on
the unlocalized module cannot certify the localized one. **It could, and it did.**

**This is the first evidence in the rollout that a plugin can be fully localized
in its own files and still render unkeyed English from a module it embeds.** Every
"this plugin passes check-i18n" claim made before Task 1 was scoped to the
plugin's own directory.

### F2. The NARROWING arm was taken, and the control survived it

O-Marimba's and O-ReverseDelay's findings are **rendered English with no key** —
`Load`, `Save`, `Previous preset`, `Next preset`, `Default`, `EQ`, `COMP`, `GR` —
so they fail the first arm's own test of "a one-line trivial fix touching no
rendered string". `preset-manager.js` alone has eighteen consumers.

Implemented as a named, commented constant carrying the reason, the seven-plugin
red set and a TODO naming the four still-unscanned files:

```js
const CMAKE_MODULE_JS_SCOPE = /(^|\/)tuning-panel\.js$/;
```

A **basename regex, not a path allowlist**, so a new consumer embedding the panel
from a different directory is still picked up — the "pass by not looking" shape
the file argues against everywhere else. Re-fired repo-wide at exit **5**: exactly
the five consumers still RED at 39 each, the three out-of-scope plugins green.

### F3. A key collision that would have shipped a French regression, caught only by arithmetic

O-Contrabass **already owned** `label.loadScl` for its own `#scl-load-btn`
(*Load .scl…* / *Charger .scl…*). The module's row of the same name, inserted
later in the same object literal, **silently overwrote it** — duplicate object
key, last one wins — changing a shipping button's French to *Ouvrir .SCL* and
losing both the ellipsis and the reviewed wording.

**Nothing but the plan's own arithmetic caught it:** 57 + 37 should be 94, the
gate read **93**, and `check-i18n` passed at 93. Fixed by renaming the
*plugin-local* key to `label.loadSclFile`; the shared module vocabulary keeps
`label.loadScl`.

**Generalize before the next module lands rows in five tables:** the LABELS-count
arithmetic is currently the *only* detector for a shared-module key colliding with
a consumer's private key. A `no key is declared twice in one table` assertion
would catch it directly and does not exist.

### F4. "Copied verbatim" was FALSE on two strings — and is now measured, not asserted

MTS's French counted captions use **U+00A0** before the colon; the first
transcription wrote **U+0020**. `i18n-fr-lint` went **exit 2** with ten `T4`
findings (`label.intervalsCount` + `label.noteCount` × 5 plugins).

This is exactly the failure the "copy, not authoring" claim invites. Fixed, then
**proven**: a Node script evaluated MTS's and each consumer's `LABELS` and
byte-compared all 37 `en`/`fr` strings, the `sameAsEn` flags, and O-Bassoon's
`zh-Hans` strings + `reviewed:'bt'`. Result: `VERBATIM: all 37 rows byte-identical
to MTS in en/fr, +zh on O-Bassoon only`.

**O-Bowed was RED on the tree AS FOUND** between `842bf6e0` and `d848337a` — it
