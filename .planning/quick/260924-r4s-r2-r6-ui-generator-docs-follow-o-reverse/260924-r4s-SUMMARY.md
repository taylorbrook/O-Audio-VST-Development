- **The reduced-motion reference is stricter than the reference plugin.** O-ReverseDelay's `@media (prefers-reduced-motion)` block covers only the armed-Freeze pulse, although its CSS has other transitions, including the `.knob` scale. The docs require a counterpart for every transition and animation, including the knob. They also say plainly that O-ReverseDelay's block is the reference for the shape of a counterpart, not for its coverage.
