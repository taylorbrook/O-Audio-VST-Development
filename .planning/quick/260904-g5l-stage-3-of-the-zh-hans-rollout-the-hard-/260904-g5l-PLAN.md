## Shared commands

Referenced by name from the tasks. Run from the repo root.

```bash
SCRATCH="${TMPDIR:-/tmp}/zh-stage3" && mkdir -p "$SCRATCH"

HAN_GATE <Plugin>     find plugins/<Plugin>/Source \( -name '*.h' -o -name '*.cpp' \) -print0 \
                        | xargs -0 perl -CSD -ne 'print "$ARGV\n" and close ARGV if /[\x{2E80}-\x{9FFF}\x{F900}-\x{FAFF}\x{FF00}-\x{FFEF}]/'
                      expected: NO OUTPUT.
                      A blanket non-ASCII grep is WRONG here (Stage 2 C-1/C-2): `grep -P` does not
                      exist in BSD grep, and these files legitimately carry U+2014, U+2500 and
                      friends in comments. Scope to Han, and pair it with HAN_CONTROL.

HAN_CONTROL <path>    perl -CSD -ne 'print "$ARGV\n" and close ARGV if /[\x{2E80}-\x{9FFF}\x{F900}-\x{FAFF}\x{FF00}-\x{FFEF}]/' <path-to-that-plugin's-i18n.js>
                      expected AFTER the fill: prints that path. A HAN_GATE zero is only
                      believable when HAN_CONTROL fires on the same one-liner.

COMMIT_PRECHECK       git branch --show-current   # expect: main
                      git status --short          # ONLY this task's files may be modified
                      Re-run BOTH immediately before every commit, never once at task start —
                      another session shares this checkout's index and HEAD (CLAUDE.md).

DUP_ROWS              grep "^| O-" PLUGINS.md | awk -F'|' '{print $2}' | sort | uniq -d
                      expected: EMPTY.
```

**Back-translation loop, per plugin.** `--plugin` is what scopes the walk; `--emit` only writes
a `target` field into the manifest (Stage 2 C-3), so **always pass both**. Name the files
`<name>.tsv` and `<name>.en.tsv` so the post-`f2k` manifest derivation resolves without help,
and pass `--manifest` explicitly anyway — an explicit `--manifest` naming a missing file refuses
loudly, which is itself a control.

```bash
node scripts/i18n-zh-backtranslate.js --emit <Plugin> --plugin <Plugin> \
  --out "$SCRATCH/<plugin>-zh.tsv" \
  --forward-provenance "<what produced the Chinese, and when>"
# then the INDEPENDENT reverse pass writes "$SCRATCH/<plugin>-zh.en.tsv"
node scripts/i18n-zh-backtranslate.js --ingest "$SCRATCH/<plugin>-zh.en.tsv" --plugin <Plugin> \
  --manifest "$SCRATCH/<plugin>-zh.tsv.manifest.json" \
  --provenance "<what produced the en-prime, and when — must differ from the forward string>"
```

Since `37c9b2ab` the emitted ids are **opaque 12-hex per-batch salted**. The batch alone
identifies neither plugin nor key, so the reverse pass may be handed the file as-is. It must
return the id **exactly as received**, and the manifest must never travel with the batch.
