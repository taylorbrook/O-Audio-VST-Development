**Blindnesses you must carry into the review, stated in the review file itself:**

   readout *typography, alignment, width, or position* are fine. O-Bells has a `params.tsv`
   and an overrides file, so its ranges are closer to real — say which in its review.
2. **A result through the generic stub proves layout and text. It never proves a control is
   wired.** No "this control is dead" findings from this harness.
3. **Colour, font and spacing facts come from `measure-ui.js --mode box` rows, not from
   sampling pixels in a JPEG.** The screenshots are for composition, hierarchy and alignment
   judgement. A hex value or a px value in a finding must trace to a computed-style row.
4. **A skipped state is a coverage hole, not a pass.** `serve-ui`/`measure-ui` click with
   `force: true`, so a control under a popover is clicked *through* it silently
   (`pattern_forced_click_under_popover_silent_coverage_hole`). The duplicate-frame detector in
   `shoot-ui.js` is what makes that visible — honour it.
5. **If a plugin cannot render** (`exit 77`, a bridge gap, a page error), the review file says
   so under `## Coverage` and the affected findings are omitted. **Do not silently fall back to
   reading `index.html` and presenting the result as a visual review.**

    `S.resolvePlaywright()` and exit **77** with a loud message if it is null.
  - `S.buildRoot(plugin)` for the assembled tree and `S.readEditorSize(plugin)` for the frame;
    exit 1 if there is no `setSize`. Launch the page with `newPage({ viewport: { width, height } })`
    — the option is `viewport`, and the misspelled `viewportSize` is a silent no-op that leaves

    fall back to a guessed pair. `--langs` overrides.
  - Walk states from `plugins/<Name>/tests/i18n-states.json`, prefixed by a synthetic `default`,
    **cumulatively with no reset between states and one page load per language** — a state can
    require an earlier one, and resetting measures pages the plugin never produces.
  - Accept the three step forms the repo's state files actually use: `click`, `dblclick`, `eval`,
    read from `st.steps` or the bare `st.click` / `st.dblclick` / `st.eval` key. Clicks take
    `{ timeout: 1500, force: true }`. Settle ~160ms after each state.
  - Capture `type: 'jpeg', quality: 92` to `<out>/<lang>__<NN>-<slugified state name>.jpg`.
    Measured at planning time: q92 is 111KB against 460KB for the PNG of the same 700x450 frame
