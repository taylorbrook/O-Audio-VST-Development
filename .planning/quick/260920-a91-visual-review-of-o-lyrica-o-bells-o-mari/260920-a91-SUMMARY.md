## Deviations from Plan

**1. [CLAUDE.md precedence] Committed on `main` rather than a phase branch**
- **Found during:** Task 1, pre-commit HEAD assertion
- **Issue:** The GSD executor's default guard halts when HEAD is the protected/default branch.
- **Resolution:** `CLAUDE.md` mandates trunk-based development ("all plugin work happens on
  `main`"), `.planning/config.json` sets `git.branching_strategy: "none"`, and the dispatching
  context explicitly instructed path-scoped commits on `main`. The project directive takes
  precedence. Every commit was path-scoped with `git commit -- <paths>`, preceded by a fresh
  `git branch --show-current` + `git status --short`, and verified afterwards for unintended
  deletions. `.claude/agent-memory/research-planning-agent.md` (another session's change) was
  never staged.

  O-Lyrica finding 12 recommendation was corrected to leave O-Lyrica alone and change
