<objective>
Add a CI guard that fails when `vendored/JUCE-overrides/` was derived from a JUCE version other
than the one pinned in `.github/juce-version.txt`, so a JUCE bump cannot silently copy stale
8.0.14 files over a newer JUCE.

Purpose: today the only check after the override copy is `grep -q "JUCE-NE-PATCH"`. That marker is
inside the vendored file itself, so it passes no matter which JUCE the override was cut from — a
bump to 8.0.15 keeps it green while shipping 8.0.14 sources into the two most delicate VST3 files.
Output: a recorded provenance manifest, a guard script that proves derivation against the pristine
upstream, and that guard wired into all four override-copy sites.

Landing this BEFORE any version bump is the whole point — it is the tripwire the bump must trip.
</objective>
