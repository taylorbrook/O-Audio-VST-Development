**The caption's y-offset: change `height / 2 - 10` to `height / 2`. Do NOT set `textBaseline`.**

The `- 10` is vestigial. It exists only because a second line was drawn at
`+ 10`; the pair straddled the centre. With one line left, `height / 2 - 10` leaves
a 14px caption sitting a full line-box high in the canvas for no reason.

`ctx.textBaseline = 'middle'` at `height / 2` would centre it exactly and would
pair naturally with the `ctx.textAlign = 'center'` already on line 921 — and it is
**rejected**, because `ctx` here is the same context object the live analyser
caches as `spectrumCtx` (see observed state). `textBaseline` is persistent context
state, so setting it in the placeholder silently arms a trap for the first person
who adds text to the live spectrum path. It is inert today and free later; that is
exactly the shape of defect wave 4d's M3 warns about. The default alphabetic
baseline at `height / 2` puts the glyph block's optical centre ~5px above true
centre, which is close enough and costs nothing.
</decision_the_plan_owes_an_answer_to>
