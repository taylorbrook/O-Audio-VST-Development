# Phase quick-261019-gk9 Plan 08: js/app.js effects Summary

Six effects now open an O-Prism-style typed value field when you double-click a dial or its readout. Reset moved to an Alt/Option-click that runs in one gesture. It reads each plugin's C++ default; Orbit's bare 0.5 fallback is gone, and FreqPulse gets a new `getParameterDefaults` native function. The help text in all three languages and the two frontend tests now describe the new gestures.

## Deviations from Plan

1. **[Rule 1 - Bug] Two `scaledToNorm` helpers did not guard skew.** Tapestop's and ReverseDelay's existing `scaledToNorm(st, scaled)` computed `Math.pow(x, p.skew)` with no skew guard, and Octagon's old reset applied pow without clamping. The helpers now clamp before the pow and fall back to skew 1. Tapestop and ReverseDelay keep their existing `(st, scaled)` signature, which reads live `st.properties`.
2. **[Rule 2] ms knobs on ReverseDelay honour `s`.** grainSize and delayScatter also take `s`, not only delayTime, so typing "0.1 s" no longer clamps to the floor.
3. **Octagon readout parameter is named `value`.** In `attachValueEntry` it is called `value` (not `valueEl`) so section 6's static textContent whitelist (`VALUE_RECEIVERS`) still passes without growing the whitelist.
4. **Tapestop editor comments left stale.** Tapestop's PluginEditor.cpp/.h comments still say "dblclick-reset". They are not user-visible, and Tapestop was already building when I found them. The ReverseDelay and Octagon comment equivalents were updated.
