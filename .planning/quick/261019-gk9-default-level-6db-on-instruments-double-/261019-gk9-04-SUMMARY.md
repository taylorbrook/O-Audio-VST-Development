# Quick 261019-gk9 Plan 04: Linear-gain synths + remaining dB instruments Summary

Prism and Strata master volume now defaults to 0.501187 (−6 dB) and is user-owned in each plugin's own preset manager. Formant and MicrotonalSampler output defaults to −6 dB, and MicrotonalSampler's `.omspreset` files no longer carry or restore it. simpleWavetable, Formant and MicrotonalSampler (knobs and both trim-slider sets) now use the O-Prism double-click value entry, with reset moved to Alt/Option-click. All five plugins are bumped, built, installed, auval-listed and committed path-scoped.

Note on `commits`: main is shared with seven parallel executors. `git rev-list --count before..HEAD` counts 17 commits in total; the 5 above are this plan's, measured with a pathspec on its five plugin folders.

### O-simpleWavetable (UI only; output_level was already −6 dB and user-owned)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Prism/Strata smoother initialisers still held 0.8**
- **Found during:** Task 1 / Task 2.
- **Issue:** `SmoothedValue masterVolSmoothed { 0.8f }` plus `reset()` with no `setCurrentAndTargetValue`. The first block of a fresh instance would ramp down from 80% to the new 50% default.
- **Fix:** the initialiser now matches the param default (0.501187f).
- **Files modified:** `PluginProcessor.h` in both plugins. This file is not in files_modified, but it is inside the owned folders.
- **Commits:** feeb1f7f, 2f36c678.

**2. [Rule 3 - Blocking] gk9 `--syntax` gate failed on an HTML comment in simpleWavetable (pre-existing)**
- **Issue:** the header comment contained the literal text `<script type="module">`. The gate's regex treated the comment prose as a script.
- **Fix:** reworded the comment to `module-script (type="module")`. No behaviour change. check-i18n is still green.
- **Commit:** 6c52fd48.

**3. [Rule 3 - Blocking] MicrotonalSampler `ui_frontend_check.js` WR-05 failed at baseline (pre-existing)**
- **Issue:** the regex looked for `sliderDragEnded()` inside the wheel handler body. Since v1.28.0 the close runs through `setTimeout(endWheelGesture)`, so the regex went stale.
- **Fix:** the check now also accepts that path. It passes on HEAD's file too, so it is a fix to the test, not to the code.
- **Commit:** b2fb00fb.

**4. [Rule 2 - Correctness] Alt-click inside an open entry field would have reset the control (Formant, MicrotonalSampler)**
- **Issue:** the capture listener sits on an ancestor of the readout.
- **Fix:** the listener ignores targets with `.knob-value-input`.

**5. [Rule 2 - Correctness] Stepped-knob entry and native trim adapters**
- **Issue:** `ComboBoxState` and the native-fn range inputs have no SliderState.
- **Fix:** adapters per contract item 4. `setChoiceIndex` and `invokeNative` are single complete operations, so the adapters' drag-bracket members are no-ops. This is disclosed rather than treated as a missing gesture pair.

**6. Minor additions inside the owned folders**
- O-MicrotonalSampler `PluginEditor.cpp`: a comment-only edit ("double-click reset" → "Alt/Option-click reset").
- O-Strata: `tests/render-harness/README.md` key count updated.
