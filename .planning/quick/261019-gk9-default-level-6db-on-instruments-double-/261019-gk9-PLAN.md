## Shared execution protocol (identical text in all eight plans)

- **Gate script** `/tmp/gk9-gates/gk9-gate.js` (embedded verbatim in every plan; first executor writes it): `[--entry=NAME] <files>` fails any dblclick handler that resets/writes a value, a missing `attachValueEntry`, or a missing Alt reset; `--syntax` node-checks edited JS and inline scripts; `--boot <Plugin>` boots the page headless via `scripts/boot-all-uis.js` and fails on page errors. Baseline run on today's tree reproduces the locked census exactly (Prism, Strata, Emulator, MultiBandCompressor already pass; Polystutter has no Alt reset).
- **Build serialization (chosen approach: mkdir lock):** every `./scripts/build-and-install.sh <Name>` + auval runs inside one `/tmp/gk9-build.lock` (mkdir spin, holder pid recorded, a dead holder's lock is broken automatically), one plugin per acquisition, launched in the background to stay clear of the 600 s watchdog. Never `--reconfigure` (it deletes the shared `build/`). Render harnesses are not built (they would need `-DOUARICON_BUILD_TESTS=ON` on the shared build dir).
- **Commits:** one per plugin, `git commit -- plugins/<Name>` after re-checking `git branch --show-current` (= main) and `git status --short` immediately before; never `git add -A`, never PLUGINS.md, never tag. Executors write their SUMMARY but do not commit it (or STATE.md / PLAN files) — the quick orchestrator makes the docs commit.
- **Per plugin:** patch bump in CMakeLists.txt + `## [X.Y.Z] — 2026-10-19` CHANGELOG entry; SUMMARY records old -> new version for the PLUGINS.md follow-up.

## Implementation notes the executors and the developer should know

1. **Shared preset header (O-Bowed, O-Contrabass, O-Lyrica, O-Wind).** These four use `modules/persistence/preset-manager/cpp/OuariconPresetManager.h` (shared, off-limits), whose apply resets every parameter to its default. User-ownership is implemented plugin-locally through the header's existing `setMigrationCallback` hook: the output key is pinned to its live value before the reset + apply, so a preset load nets to no change. Disclosed side effects: one transient default write inside the apply call, and user presets saved by the shared header still carry the key (ignored on load). Follow-up: a `setUserOwnedParameters` hook in the shared module.
2. **O-Texture legacy sessions.** The new `outputLevel` would otherwise make every pre-update session 6 dB quieter; `setStateInformation` sets it to 0 dB when the restored state lacks it, honouring D-03's "saved sessions load unchanged". Range −60..+12 dB (planner's choice under D-03's "or match family": matches O-TextureForge).
3. **Defaults for Alt-click.** Plugins with no default source get a `getParameterDefaults` native function (O-Contrabass pattern) rather than a hand-copied JS table.
4. **Non-default preset levels stripped** (voicing follow-ups, not gain fixes, per the "presets never set output gain" rule): O-Prism masterVol 0.75 base / 0.7; O-IntonationPad masterVolume 0.8–0.9 across its bank; some O-Contrabass defs (e.g. +0.5 dB). Each SUMMARY lists them.
5. **Help text** that said "double-click to reset" (Contrabass, MicrotonalSampler trim hint, Octagon ×2, ReverseDelay and Tapestop footers) is rewritten in en/fr/zh; new zh rows ship at `reviewed: 'mt'` and fr at `reviewed: false` — a blind back-translate pass and a French read are follow-ups.
6. **PLUGINS.md** is dirty from another session and is not touched; the eight SUMMARYs list the version rows to apply later.
