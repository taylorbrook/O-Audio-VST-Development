## Locked decisions (from 261019-gk9-CONTEXT.md, numbered here for traceability)

- **D-01 Presets:** output level is user-owned — stripped from factory presets; preset apply never resets or writes it; user-preset save never writes it (O-Bells `isUserOwnedParameter` pattern). Session state still recalls it.
- **D-02 Reset gesture:** double-click on a dial opens manual value entry; reset-to-default moves to Alt/Option-click, bound capture-phase (Prism convention).
- **D-03 Gain stages:** output level is the last stage (after FX/EQ; a final safety clip / NaN scrub may follow). Bells + Wind per-voice gain moves post-FX. Linear params (IntonationPad `masterVolume`, Prism/Strata `masterVol`) keep their ranges, default 0.501187. Texture gets a new dB `outputLevel` (default -6, smoothed, last stage) + knob. Existing param IDs and ranges never change.
- **D-04 Skip:** O-Bassoon, O-Freeze, O-Gain, O-Reed, O-simpleFM are not touched by any plan.
- **D-05 Smoothing:** unsmoothed last-stage gains (Bowed, Lyrica, Marimba, TextureForge) get a SmoothedValue ramp.
- **D-06 UI defaults:** knob/readout default displays and JS default tables (`PARAMS`, `DEFAULT_VALUES`, `data-default`, Alt-reset targets) match -6 dB.
- **D-07 Entry semantics:** O-Prism `attachValueEntry` is the reference (contract below); Family-C readout editors (Bells/IntonationPad/Lyrica/Wind) are upgraded to it; resets that skipped the gesture pair gain it when moved to Alt-click; non-numeric readouts parse sensibly.
- **D-08 Scope:** rotary dials/knobs, plus knob-like sliders that currently reset on dblclick. Not curves, XY pads, envelope/waveform editors, glyphs.
- **D-09 Repo:** trunk `main`, path-scoped commits, patch bump + `## [X.Y.Z]` CHANGELOG entry per plugin, PLUGINS.md NOT touched (versions listed in SUMMARY), never tag, `Source/ui/public/modules/` never edited.

## Value-entry contract (D-02, D-07, D-08)

Reference: `plugins/O-Prism/Source/ui/public/index.html` lines 3064-3168 (`scaledToNorm`, `attachValueEntry`), 3485-3568 (parsers `numOf` / `parseDirect` / `parsePercent` / `parseFreq` / `parseSeconds` / pan), 3304-3313 (Alt-click capture reset), 3348-3353 (dblclick handler), 672-696 (`.knob-value-input` CSS). Port it into each plugin's own knob file — no shared module exists; do not create one, and do not create new UI files (they would need binary-data registration in CMake). Keep the function name `attachValueEntry` so the gate finds it.

1. Overlay: an `<input class="knob-value-input">` appended inside the readout element; readout text kept but `color: transparent`; input ink copied from the readout's computed colour; CSS copied verbatim from Prism (absolute, `font-family: inherit; font-size: inherit` — form controls do not inherit fonts on their own). Zero layout shift.
2. Enter or blur commits; Esc cancels; text equal to what was shown is never written back.
3. Parse to the SCALED (C++-unit) value, or null to reject: direct (dB, st, ct, Hz without k, plain numbers, ms on ms-scaled params); percent (divide by 100 when C++ is 0..1 or -1..1 but reads %); freq (`k` multiplies by 1000, bare number = Hz); seconds (only on seconds-scaled params whose readout flips ms/s: explicit unit wins, bare number inherits the unit on screen); pan (`L`/`R`/`C`); choice/stepped (match option text case-insensitively, else a number, snapped); `-inf`/`inf`/`off` -> range start. A readout in a unit different from C++ converts back in the parser.
4. Commit: `sliderDragStarted()` -> `setNormalisedValue(scaledToNorm(v, state.properties))` -> `sliderDragEnded()`. `scaledToNorm` clamps BEFORE the pow (NaN guard) and reads the live `start/end/skew` from `state.properties`, never a JS range table. A lambda-ranged param that already has a page-side adapter routes through that adapter. A control not backed by a SliderState (e.g. a native-function trim slider) gets a small adapter object exposing the same five members (`getNormalisedValue`, `setNormalisedValue`, `sliderDragStarted`, `sliderDragEnded`, `properties`) so `attachValueEntry` stays unchanged.
5. Every listener that writes the readout's `textContent` skips while `valueEl.dataset.editing === '1'` (otherwise the open input is wiped); `close()` re-renders from live state.
6. The input stops propagation of `pointerdown`, `mousedown`, `dblclick`, `wheel` and `keydown`, so it never starts a knob drag or reaches global key handlers.
7. A dial with no readout element gets the input overlaid on the dial itself (absolute, centred), same semantics.
8. dblclick handler (on the dial and on its readout): `if (e.altKey) return;`, close any open wheel gesture, call `attachValueEntry(...)`. It never writes the parameter itself. The old reset-on-dblclick code is deleted, not left beside it.

## Output-level contract (D-01, D-03, D-05, D-06) — instruments

1. Only the default value changes: dB params -> `-6.0f`; linear params -> `0.501187f`. ID, range, interval, unit untouched.
2. Last stage: the gain multiplies the processor output after every FX/EQ/reverb stage; only a final safety clip / NaN scrub may follow.
3. Smoothed: `juce::SmoothedValue<float>` (Linear — a -60 dB floor mapping to 0 breaks Multiplicative), about 20 ms, on the LINEAR gain; seeded in `prepareToPlay` with `reset (sampleRate, 0.02)` + `setCurrentAndTargetValue (currentLinearGain())` so the first block ramps from neither 0 nor 1; target set once per block; applied via `applyGainRamp` or per sample. An existing smoother stays as is.
4. User-owned: a static `isUserOwnedParameter (const juce::String& id)` (shape of O-Bells `Source/OuariconPresetManager.h:123`) is consulted in every reset-to-defaults loop, every preset apply loop and every user-preset save; factory preset tables no longer name the param; any "preset modified" comparison ignores it. `getStateInformation` / `setStateInformation` are untouched (saved sessions recall their stored value). Variant for plugins whose preset manager is the SHARED `modules/persistence/preset-manager/cpp/OuariconPresetManager.h` (O-Bowed, O-Contrabass, O-Lyrica, O-Wind — the module is off-limits): in the processor constructor call `presetManager.setMigrationCallback(...)` with a lambda that sets the output param's key in the incoming `parameters` object to the param's live normalised `getValue()` — the shared apply runs migrate, then reset-to-defaults, then apply, so the level nets to unchanged on every load path (`loadPreset`, `loadPresetFromFile`, `applyPresetData`). Disclose in SUMMARY: one transient default write inside the apply call, and user presets saved by the shared header still carry the key (ignored on load); a `setUserOwnedParameters` hook in the shared module is the follow-up.
5. UI default tables / readout initial text for the output param use the new normalised default (per-plugin table above; confirm skew is 1 in C++ first — a 3-argument `NormalisableRange` has skew 1).
6. Test/harness files that encode the old default are updated to the new contract; render harnesses are NOT built (they need `-DOUARICON_BUILD_TESTS=ON`, which would reconfigure the shared `build/`).

## Gate script

If `/tmp/gk9-gates/gk9-gate.js` does not exist, create it (`mkdir -p /tmp/gk9-gates`, then the Write tool) with exactly this content — all eight gk9 plans carry the identical script, so whichever executor writes it first wins and the rest reuse it:

```js
// gk9 static gates (quick 261019-gk9). Run from the repo root.
//   node /tmp/gk9-gates/gk9-gate.js [--entry=NAME] <ui file>...   dblclick handlers + Alt reset + entry fn
//   node /tmp/gk9-gates/gk9-gate.js --syntax <file>...            node --check every .js and inline <script>
//   node /tmp/gk9-gates/gk9-gate.js --boot <PluginFolder>         headless boot; fails on any page error
'use strict';
const fs = require('fs'), os = require('os'), path = require('path'), cp = require('child_process');
const argv = process.argv.slice(2);
// Blank comments to spaces so indices and line numbers survive.
const blank = (s) => s.replace(/[^\n]/g, ' ');
const stripComments = (s) => s
    .replace(/\/\*[\s\S]*?\*\//g, blank)
    .replace(/(^|[^:'"\\])(\/\/.*)$/gm, (m, a, b) => a + blank(b));
const tmpFile = (ext) => path.join(os.tmpdir(), `gk9-${process.pid}-${Math.random().toString(36).slice(2)}.${ext}`);
let fail = 0;

if (argv[0] === '--boot') {
    const name = argv[1];
    const out = tmpFile('json');
    const r = cp.spawnSync(process.execPath, [path.resolve('scripts/boot-all-uis.js'), '--plugin', name, '--json', out], { encoding: 'utf8' });
    if (r.status === 77) { console.log('BOOT-UNVERIFIED: Playwright unresolvable (exit 77) - NOT a pass'); process.exit(77); }
    if (r.status !== 0 || !fs.existsSync(out)) {
        console.log(`BOOT-HARNESS-FAIL exit=${r.status}\n${(r.stdout || '').slice(-1500)}${(r.stderr || '').slice(-800)}`);
        process.exit(1);
    }
    const res = JSON.parse(fs.readFileSync(out, 'utf8'));
    fs.unlinkSync(out);
    if (!res.length) { console.log(`BOOT-NO-RESULT for ${name}`); process.exit(1); }
    const errs = res.flatMap((x) => x.pageErrors || []);
    for (const e of errs) console.log(`PAGEERROR ${String(e).slice(0, 200)}`);
    console.log(`BOOT ${name}: pageErrors=${errs.length}`);
    process.exit(errs.length ? 1 : 0);
}

if (argv[0] === '--syntax') {
    for (const f of argv.slice(1)) {
        const src = fs.readFileSync(f, 'utf8');
        const chunks = [];
        if (/\.html?$/i.test(f)) {
            const re = /<script\b([^>]*)>([\s\S]*?)<\/script>/gi; let m;
            while ((m = re.exec(src))) {
                if (/\bsrc\s*=/i.test(m[1])) continue;
                const type = (m[1].match(/\btype\s*=\s*["']([^"']+)["']/i) || [])[1] || 'text/javascript';
                if (!/^(module|text\/javascript|application\/javascript)$/i.test(type)) continue;
                chunks.push({ code: m[2], mod: /^module$/i.test(type), line: src.slice(0, m.index).split('\n').length });
            }
        } else {
            chunks.push({ code: src, mod: /^\s*(import|export)\b/m.test(src), line: 1 });
        }
        for (const c of chunks) {
            const tmp = tmpFile(c.mod ? 'mjs' : 'cjs');
            fs.writeFileSync(tmp, c.code);
            const r = cp.spawnSync(process.execPath, ['--check', tmp], { encoding: 'utf8' });
            fs.unlinkSync(tmp);
            if (r.status !== 0) {
                fail++;
                console.log(`SYNTAX-FAIL ${f} (script from line ${c.line})\n${(r.stderr || '').split('\n').slice(0, 6).join('\n')}`);
            } else console.log(`SYNTAX-OK ${f}:${c.line}`);
        }
    }
    process.exit(fail ? 1 : 0);
}

let entryName = 'attachValueEntry';
const files = [];
for (const a of argv) { if (a.startsWith('--entry=')) entryName = a.slice(8); else files.push(a); }
if (!files.length) { console.log('usage: gk9-gate.js [--entry=NAME] <ui file>...'); process.exit(2); }
const defRe = new RegExp(`function\\s+${entryName}\\b|\\b${entryName}\\s*[=:]\\s*(?:async\\s+)?(?:function\\b|\\([^)]*\\)\\s*=>|[\\w$]+\\s*=>)|^\\s*(?:async\\s+)?${entryName}\\s*\\([^)]*\\)\\s*\\{`, 'm');
const resetRe = /\.setNormalisedValue\s*\(|setValueNotifyingHost|invokeNative\s*\(|\.value\s*=(?!=)|\breset\w*\s*\(|\bdef\b|(?<!prevent)Default|\bdefaults?\b|DEFAULT/;
let altSeen = false, entryDefined = false, handlers = 0;
for (const f of files) {
    const raw = fs.readFileSync(f, 'utf8');
    const src = stripComments(raw);
    if (/\baltKey\b/.test(src)) altSeen = true;
    if (defRe.test(src)) entryDefined = true;
    if (/\.ondblclick\s*=/.test(src)) console.log(`CHECK-ONDBLCLICK-PROPERTY ${f} (review by hand)`);
    const re = /addEventListener\(\s*['"]dblclick['"]\s*,/g; let m;
    while ((m = re.exec(src))) {
        handlers++;
        const line = src.slice(0, m.index).split('\n').length;
        // The handler = everything up to the paren that closes addEventListener(.
        let i = re.lastIndex, depth = 1;
        for (; i < src.length; i++) { if (src[i] === '(') depth++; else if (src[i] === ')' && --depth === 0) break; }
        const body = src.slice(re.lastIndex, i);
        const rawBody = raw.slice(re.lastIndex, i);
        if (/^\s*[\w$.]+\s*(?:,[^]*)?$/.test(body) && !/=>|function/.test(body)) {
            console.log(`CHECK-NAMED-HANDLER ${f}:${line} (follow the reference; review by hand)`);
            continue;
        }
        const allow = rawBody.match(/gk9-allow:\s*([^\n*]*)/);
        if (resetRe.test(body)) {
            if (allow) console.log(`ALLOWED ${f}:${line} (${allow[1].trim()})`);
            else { fail++; console.log(`FAIL-RESETS-OR-WRITES ${f}:${line}`); }
        } else if (body.includes(entryName)) console.log(`OK-ENTRY ${f}:${line}`);
        else console.log(`CHECK-NON-DIAL ${f}:${line} (allowed only for a documented curve/XY/waveform/glyph/list target)`);
    }
}
if (!entryDefined) { fail++; console.log(`FAIL-NO-ENTRY-FN: no definition of ${entryName} in the given files`); }
```

## Serialized build + install (all eight plans share `build/`)

Concurrent ninja runs in one build dir corrupt each other, and `build-and-install.sh` also kills AudioComponentRegistrar and clears the AU cache. So every build + install + auval goes through ONE mkdir lock, one plugin per acquisition. Launch with the Bash tool's `run_in_background: true` and wait for the exit notification — a lock wait plus a full rebuild (the VERSION bump recompiles the whole plugin) can exceed the 600 s watchdog; never poll in a foreground loop. Substitute NAME:

```bash
bash -c '[ -f scripts/build-and-install.sh ] || { echo "not at repo root"; exit 1; }
L=/tmp/gk9-build.lock
until mkdir "$L" 2>/dev/null; do
  H=$(cat "$L/pid" 2>/dev/null)
  if [ -n "$H" ] && ! kill -0 "$H" 2>/dev/null; then rm -rf "$L"; fi
  sleep 10
done
echo $$ > "$L/pid"; trap "rm -rf $L" EXIT
./scripts/build-and-install.sh "$1" || exit 1
A=$(auval -a 2>/dev/null | grep -iE -- ": $1(-dev)?([[:space:]]|$)") || { sleep 10; A=$(auval -a 2>/dev/null | grep -iE -- ": $1(-dev)?([[:space:]]|$)"); }
echo "$A"; [ -n "$A" ] || { echo "AUVAL: $1 not listed"; exit 1; }
case "$A" in *"Cannot open"*) echo "AUVAL: $1 listed but cannot open"; exit 1;; esac' _ NAME > /tmp/gk9-build-NAME.log 2>&1; echo "exit=$?"; tail -40 /tmp/gk9-build-NAME.log
```
