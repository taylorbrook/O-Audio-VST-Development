### O-Texture 0.6.1
- **Output param:** new `outputLevel`, `ParameterID { "outputLevel", 2 }`, "Output Level", −60..+12 dB, step 0.1, default **−6.0 dB**, label dB. It is added last in the layout.
- **Placement:** `outputLevelSmoothed` (Linear, 20 ms, on the linear gain) is seeded in `prepareToPlay` from the live value. Its target is set once per block, and it is applied with `applyGain` after `buffer.applyGain(mix)` as the true last stage. At ≤ −60 dB it maps to 0 (mute), and the readout shows `-inf dB`.
- **Legacy sessions:** `setStateInformation` checks after `replaceState` whether the restored XML has a `PARAM id="outputLevel"`. If not, it sets the param to 0 dB, so old sessions keep their loudness.
- **Editor:** `outputLevelRelay` ("outputLevelSlider") + `withOptionsFrom` + `outputLevelAttachment`. The Relays -> WebView -> Attachments order is kept, and the destructor resets in reverse order.
- **UI:** an Output knob-container after Mix in the bottom strip (`id="knob-outputLevel"`, initial `-6.0 dB`), bound with defaultNorm 0.75 (skew 1 confirmed). It fits the strip without CSS changes (space-around, 4 items), confirmed in a headless screenshot.
- **dblclick sites converted:** the vertical sliders (Char A/B, Evolve: track + `.value` readout) and the knobs (Brightness/Mix/Output: dial + `.knob-value` readout). These are named `openEntry` handlers that only call `attachValueEntry` and return on `altKey`. The old reset-on-dblclick code is deleted.
- **Alt reset:** `bindAltReset` uses capture-phase **`pointerdown`** on the slider column / knob-container (an ancestor of the pointer-drag target) with `preventDefault` + `stopPropagation` and the gesture pair. It ignores presses inside an open entry field. Defaults come from the existing bind tables.
- **Readout guards:** `updateKnob` / `updateVerticalSlider` skip writing while `dataset.editing === '1'`.
- **i18n rows added:** `label.outputLevel` (en Output / fr Sortie `reviewed: false` / zh 输出 `reviewed: 'mt'`), `tip.outputLevel` (en/fr `false`/zh `'mt'`), and the TIP_BINDINGS row `['#knob-outputLevel','tip.outputLevel','.knob-container']`. The French body uses U+00A0 before `;` and units (fr-lint T5/T7).
- **Tests:** `tests/ui_tip_render_check.js` iterates TIP_BINDINGS, so it picked up the new knob without edits. It went from 311 to 334 PASS, 0 FAIL, before and after.
- **Gates:** gk9-gate main.js 0 failures. Syntax OK (main.js, index.html, i18n.js). Boot pageErrors 0 (baseline 0). check-i18n / fr-lint --strict / zh-lint / check-ui-labels all exit 0.
- **Presets:** none exist (D-01 nothing to strip).

## Deviations from Plan

**1. [Rule 1 - Bug] TextureForge Grain Size reset landed near 13 ms instead of 50 ms**
- Found during: Task 2
- Issue: the JS default 0.08 is the LINEAR position, but GRAIN_SIZE is skewed (10..500, skew 0.5), so it decoded to about 13.1 ms. Moving the reset to Alt-click would have kept the wrong target.
- Fix: defaultNorm 0.2857 (= sqrt(40/490)), with a CHANGELOG "Fixed" line.
- Commit: `1d3d99fd`

**2. [Rule 3 - Blocking] TextureForge did not compile (pre-existing, not caused by this plan)**
- Found during: Task 2, first build (`logs/O-TextureForge/build_20261019_170416.log`)
- Issue: umappp v3.3.2 fetches `knncolle` at `master`. The refetched headers (build/_deps, Sep 26) use `std::filesystem`, which libc++ marks unavailable below macOS 10.15, and the suite deploys to 10.13. As a result `UMAPProjection.cpp` (untouched) failed. The installed 1.5.0 dates from Sep 25, before the refetch.
- Fix: `target_compile_definitions(OuariconTextureForge PRIVATE _LIBCPP_DISABLE_AVAILABILITY)` on Apple, scoped to the shared-code target. TextureForge never calls knncolle's prebuilt save/load. A one-line CHANGELOG "Build" note was added.
- Follow-up: pin knncolle (FetchContent_Declare it at a fixed tag before umappp) for deterministic builds. This likely affects release CI for TextureForge too.
- Commit: `1d3d99fd`

**3. [Rule 3] TextureForge i18n.js readout exemption key** — not in the plan's file list. The `'0 dB'` key was updated to `'-6 dB'` because index.html's authored readout changed. Without that, the exemption would be stale. The gates passed both ways.

**4. Value-entry adaptation (TextureForge)** — Grain Size, Density and Gain use empty formatters, a pre-existing bug since v1.0.0 noted in i18n.js, so their readouts are always blank. Their entry field opens over the dial (contract item 7) on a paper chip (`.knob-value-input.on-dial`), using entry-only formatters (`12.0 ms`, `8`, `-6.0 dB`). The blank readouts were NOT fixed (visible change, out of scope). See Follow-ups.

**5. formatFn signature (Texture)** — Texture readouts render SCALED values, so `attachValueEntry` re-renders via `formatFn(state.getScaledValue())` instead of Prism's `formatFn(norm)`. The semantics are otherwise identical.

**6. Ledger** — the per-plan HEAD ledger file was not written before the first commit (other executors commit to the same trunk). `commits: 3` is measured with the path filter over this plan's five folders from the start HEAD `ed99a5f5`.
