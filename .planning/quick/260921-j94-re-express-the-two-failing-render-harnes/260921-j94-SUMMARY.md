## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The ratio control's own bound was wall-clock-derived**

- **Found during:** Task 1, after the first green run.
- **Issue:** The second `[sched]` control was first written exactly as the plan specified —
  denominator `max(fast.ms, kRefFloorMs) * K` taken live from a `syncScheduler()` measurement. The
  sync publish measured 2.30–6.94 ms across runs, safely under the 10 ms floor, so the control
  worked. But a runner slow enough to inflate that sync publish past ~21 ms would raise the
  control's bound above the real ModWheel wait and flip the control's verdict to
  `(control PASSED — the probe is vacuous)` — a load-induced failure. That is the *same defect this
  entire task exists to remove*, reproduced inside the control meant to prove the fix.
- **Fix:** the control now asserts against the **floored** bound (`kRefFloorMs * kK` = 30 ms), which
  is the tightest bound the ratio expression can ever impose, and prints the measured sync figure
  beside it as evidence the fast path really does land at or below the floor. Strictly stronger and
  no longer load-sensitive.
- **Files modified:** `plugins/O-Strata/tests/render-harness/main.cpp`
- **Commit:** `bb4e070b`

**2. [Process] A combined commit was created and split before it was published**

- **Found during:** Task 1 commit step.
- **Issue:** Task 2's edits were already in the working tree when Task 1 was staged, so the first
  commit (`39dd25f1`, 242 insertions) carried both tasks — violating the atomic per-task commit
  constraint.
- **Fix:** saved the verified file to the scratchpad, `git reset --soft HEAD~1` + `git reset`,
  inverted the three Task 2 edits in place with the editor (**never** `git checkout`/`git restore`
  on the file), verified by diff that only the `[sched]` block differed and that `gateH7()` was
  byte-identical to the original, committed Task 1 alone as `bb4e070b`, then restored the saved file
  (sha `e142706b…`, verified identical) and committed Task 2 as `e11dfa1f`.
- **Net effect:** history contains the two intended atomic commits. `39dd25f1` was never pushed and
  is unreachable.
