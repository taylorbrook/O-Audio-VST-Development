## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream action publisher -> CI runner | Third-party code executes in a job that can reach the eight Apple signing secrets. A mutable tag lets the publisher (or anyone who compromises them) change that code after review. |
| GitHub-issued `GITHUB_TOKEN` -> repository | Every job receives a token; without a declared default, the scope is whatever the repo/org default grants. |
| external contributor -> workflow triggers | Currently closed: no `pull_request` and no `pull_request_target`. A future edit is the only way this boundary opens. |
