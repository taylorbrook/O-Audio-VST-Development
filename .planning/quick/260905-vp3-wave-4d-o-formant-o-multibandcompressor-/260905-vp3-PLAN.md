### P5. `VERSION` is a CMake VARIABLE on O-MultiBandCompressor, and R9's own pattern returns nothing

```
L9   set(OMBC_VERSION 1.11.2)
L13      VERSION ${OMBC_VERSION}
```

The pattern wave 4c's verify blocks use — the keyword anchored at line start followed by an
optionally-quoted digit — matches **neither line**. It returns empty, and an executor reading
"prints the shipped version" as the criterion sees a blank and has no signal at all.

Wave 4c's N5 records R9 surviving its own plan being wrong (O-Bassoon's value was quoted when the
plan said none were). This is the same rule meeting a harder case: the value is not a literal
after the keyword in any form. **The bump goes on the `set()` line, and the verify must read the
resolved value** — either by matching the `set()` form as well, or by asking CMake. The verify
blocks below use a two-arm reader that handles both shapes; a one-arm reader is the defect.

### P6. The gear defect has TWO shapes, and only one of them is greppable

Every prior wave found the same shape: an **exclusivity clause** asserting the settings panel
holds the language and nothing besides. That is what a negative grep can see. O-Formant has it.

**O-ReverseDelay's is a silent omission.** Its `settings` body reads, in full: *"Choose the
language of this hover help. The choice is remembered with the session."* It asserts nothing
false in words — it simply never mentions the hover-help switch, which exists (`tips-toggle` is
in its table, and `check-i18n` [16] requires it). There is no clause to negative-grep and no
phrase a probe could name. **Only reading the body against the live panel finds it**, and the
consequence is identical: a Chinese reader is told the panel holds one thing when it holds two.

Wave 4c's ratio was 4 false / 2 correct on an exclusivity clause. This wave's is 2 false / 3
correct, and one of the two falses is invisible to the instrument that found all the others.

### P7. O-MultiBandCompressor's language body is ALREADY correct — the first in the rollout

Wave 4c's plan states as a fact that all six of its plugins carried the fixed-pair language
enumeration; every wave before it found the same. O-MultiBandCompressor's `lang-select` body does
not:

> *"Language of this hover help and of the labels on the page. The choice is remembered with the
> session and is not carried by presets. Value readouts and preset names stay in English."*

No count, no pair, nothing that a third option makes false. Its `settings` body is likewise
correct and names both choices. The file's own comment at the entry records that it was rewritten
at v1.11.0 for exactly this class of staleness.

**Read both, leave both, and record them as checked non-defects with the entry cited.** An
unexamined correct body and an unexamined false one look identical in a diff — and a wave that
mechanically deletes because the last four waves deleted would strip a true sentence here. The
rule is check, then act.

### Tooling traps confirmed live during this planning pass

- `system_profiler SPFontsDataType | grep -c "Family: X$"` is the installed-family measurement.
  Do not infer availability from a stack's contents.
- `./scripts/build-and-install.sh` resolves the `juce_add_plugin` target itself, including one
  level of `${VAR}` indirection (verified in the source at L129–164), so **pass the FOLDER name**
  even on O-ReverseDelay and O-Marimba, whose targets differ from their folders.
- `O-Formant` and `O-ReverseDelay` write their editor size with a space before the paren. Both
  `check-ui-labels` and `measure-ui` parsed them correctly — verified, at 800 × 600 and 940 × 768
  — but the space form exists and a hand-rolled parser keyed on the tight form misses it.
- C11 still holds: **`timeout` does not exist on this machine**, **zsh does not word-split an
  unquoted variable**, and **every `--include` glob must be quoted** or the grep fails entirely
  and the count reads as a clean zero.
- **Comment-blind greps lie.** Strip comments before any code count:
  `perl -0777 -pe 's{/\*.*?\*/}{}gs; s{//[^\n]*}{}g; s{^\s*\*.*$}{}gm' <file>`.
- **`grep -P` with a Han property byte-matches on this machine** and reports phantom hits on the
  middle dot U+00B7. Use the `perl -CSD` form in the verify blocks. A Han script property in perl
  **without** `-CSD` is inert.
- **A stale-enumeration alternation must spell the language word in BOTH languages, and this plan's
  own probe did not until it was fired.** The pattern every prior wave carried keys on the French
  spelling of the language name. The English bodies here read *"between English and French"* and
  *"English and French are available"* — the English spelling, which that pattern does not match.
  Fired against the pre-work tree the first version reported **3 hits on O-Formant and 1 each on the
  other three**; the corrected alternation reports **4 and 2**. Every body it missed is one this wave
  must delete. **Fire every negative probe against the tree as found before trusting its zero** —
  a probe that has never printed a hit has not been shown to be able to.

## Stage-4 executor rules — non-negotiable, cited by number below

Carried verbatim from Stage 3 (R1–R9) and wave 4a (W1–W5), with waves 4b and 4c folded in.

- **R1 — Author at `'mt'`, always.** Never write `'bt'` at authoring time. `check-i18n` accepts
  `'bt'` as a valid enum member and the lint's R1 only reports entries *below* the bar, so a
  premature `'bt'` is invisible to every automated check in this repo. Promotion happens only
  after the reverse read, in its own commit.
- **R2 — Read ALL triples with `--verbose`.** `--ingest` truncates to 12. Across four prior waves
  essentially no real finding ranked inside the default twelve. O-Formant's 245 rows make twelve
  5% of the batch. The score is a sort key, not a verdict.
- **R3 — Screen `TERMS` for page collisions BEFORE authoring.** Report any two *different* English
  keys mapping to one root that co-occur on a page. Qualify **both** sides, never one.
- **R4 — Fresh blind reader AND fresh salt per correction round.** They guard different things:
  the salt stops correlation against seen ids, the fresh agent stops self-agreement. A correction
  round also needs a **different model** — a fresh session of the same model guards correlation
  but not self-agreement. A round that corrects nothing needs no round two; say so in the commit
  rather than leaving the asymmetry unexplained (wave 4c deviation 4).
- **R5 / W4 — `--emit` is CORPUS-scoped and its own usage line is wrong. Pass BOTH `--emit
  <Plugin>` AND `--plugin <Plugin>`.** Following the usage line emits the entire corpus — 2440
  already-shipped rows dispatched to an external reader as this plugin's work.
- **R6 — Pass `--manifest` explicitly and fire the blinding controls per batch.** ids pure 12-hex,
  no key fragment, ids returned identical and in order, rows well-formed with no Han surviving in
  the returned English, and a sha256 of the zh column against the committed tree.
  **Forbid repo access in the dispatch explicitly.** `--forward-provenance` is **REQUIRED at
  emit**: without it `--ingest` refuses rather than reporting, and that refusal is correct.
  Per wave 4c's N7, expect the "no product name in the batch" control to report a **non-zero**
  count on any plugin whose own copy names itself — four of these five name themselves in a
  product-name row. **Read the hit and adjudicate it; do not treat the count as pass/fail.**
- **R7 — zh geometry failures are SHRINKS. Assert equality, pin at the widest of three.**
- **R8 — A French-era `min-width` pin is a FLOOR, not safety.** Re-measure every one. Grep for
  existing declarations on a selector before appending, or a new pin at higher specificity
  silently un-pins a French one and moves the **fr** arm. Counts per plugin are in the table;
  O-Formant's 17 min-width and 22 letter-spacing declarations are the wave's largest surface.
- **R9 — Version truth is `CMakeLists.txt`.** Read the **value**; never grep for a literal; the
  value may be quoted **and may be held in a variable (P5)**. Use a reader that handles both.
- **W1 — The CJK tail goes BEFORE the trailing generic.** Chromium resolves a bare `serif` or
  `sans-serif` against the document's `lang`, so under `zh-Hans` the generic is already a Chinese
  face and a tail written after it is never consulted. The shipped convention, copied verbatim
  from `plugins/O-Detune/Source/ui/public/index.html:57` and `:481`, is
  `…, 'PingFang SC', 'Microsoft YaHei', serif` for the serif arm and
  `Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif` for a form-4 rule, with the mono case
  placing the tail before its own generic.
- **W2 — OR the visibility flag across states.** `measure-ui` already does this and discloses the
  identity ratio on every run; any hand analysis must too.
- **W3 — Check `I18N_EXEMPT` membership BOTH ways.** Every exempt option word in an English body
  must survive verbatim into the Chinese, and every non-exempt caption must not. Units in a range
  clause follow the READOUT, not the prose. **O-Formant's exempt list is the wave's hard case**:
  it carries ARPABET vowel and consonant codes, IPA glyph tables, formant-index markers and
  factory preset names, each with a decision citation. Read it in full before authoring a body
  that names a control.
- **W5 — Expect a Z8 violation after any Latin→Han token swap.** A space that is correct while a
  token is Latin becomes an intra-Han space the moment it is replaced. Under the flipped gate this
  blocks.
- **C3 — Measure at the SHIPPING FRAME and walk the states CUMULATIVELY.** `measure-ui` parses the
  frame from each plugin's own `PluginEditor.cpp` and applies states in file order with no reset.
  Do not substitute a hand-rolled sweep at a chosen viewport.
- **C5 / C6 — DERIVE-OR-ABORT on every repaired gate, and fire the control.** A derived list that
  goes empty walks zero languages and reports every assertion green. Apply the guard to the WALK
  and to the per-language MAP LOOKUPS as well as to the list (P2). Revert the plant by **targeted
  edit, never `git checkout --`**, and confirm sha256 byte-identity against HEAD.
- **C7 — Author the new language from the CORRECTED English.** Make the enumeration deletions
  first, **re-read the file**, then author from the file as it then stands. No tool in this repo
  compares a `zh` body against its own `en`; only the reverse read catches a row that outlives the
  sentence it was translated from.
- **C8 — Do not spell the superseded literal in the comment that explains it.** Word it as prose,
  or this wave's own stale-enumeration probe keeps reporting a plugin that is fixed.
- **N1 (wave 4c) — the `line-height-normal` screen CANNOT reach 0 on most pages.** `han` is
  computed over the node's own text **plus `data-tip`, `data-tip-title` and `aria-label`**, so a
  numeric readout carrying a Chinese `aria-label` is a finding forever: it has no Han to render,
  its box is identical on both arms, and no pin can change that. Shipped, wave-4b-passed O-Tremolo
  reads 3 today. **The load-bearing criterion is `check-ui-labels` reporting 0 moved.** Pin every
  leaf that MOVES; leave every evidenced non-mover and **name each residual with its measured
  `enH == zhH`**.
- **N4 (wave 4c) — a `termNote` is ENTRY-scoped.** A term used as both a caption and a tooltip
  title needs **two** notes, or Z5 fires on the title with the caption already clear.
- **N8 (wave 4c) — read every body that names a control.** An option word visible on the page
  stays verbatim **only when it is exempt**, because an exempt option reads the same in every
  language. A keyed one must be named by its localized caption.
- **N9 (wave 4c) — budget for FLOORS, not clips.** Every non-`line-height` pin in wave 4c was a
  `min-width` or `min-height` and every one existed because the Chinese was **smaller**. Never
  fixed: a floor must not cap a language that needs a wider sentence or a third line.
- **N10 / N11 (wave 4c) — derive a `line-height` pin PER LINE and per SIZE.** Check the line count
  before dividing: a caption that already wraps in English gives a box that is two line boxes, and
  a naive box-over-font-size ratio doubles it. A class rendered at two sizes needs two pins and
  two selectors to hang them on.
- **Two nodes a keyed scan always misses:** the `#tooltip` surface (filled from `data-tip` at
  hover time, never keyed) and the endonym `<option>` (the only Han in the markup). Universal.

## The per-plugin procedure (nine steps, identical for all five)

Every task runs this loop. Written once here, referenced, not repeated.

1. **Screen for glossary page collisions (R3)** — before authoring a string. Push the plugin's
   English label set through `TERMS`; report any two different keys sharing a root that co-occur
   on a page. Then run the **mechanical downstream check**: after authoring, group the zh
   renderings and report any two *different* keys sharing one, excluding same-control pairs (a
   caption and its own tooltip title) and same-English pairs. The R3 screen alone only fires when
   both sides are glossary keys and is blind otherwise.
2. **Correct the stale bodies FIRST (C7, P6, P7).** In `js/i18n.js`, remove from the language
   hover-help the sentence that names or counts the selector's options, in the **en body and the
   fr body both** — on the four that carry it. On the two whose settings body misdescribes the
   panel, correct it: O-Formant's is an exclusivity clause and takes a **deletion**; O-ReverseDelay's
   is an omission and takes a **one-clause addition** naming the switch that is actually there.
   On O-MultiBandCompressor **both** bodies are already true — read them, leave them, record them
   as checked non-defects with the entry cited. On O-Marimba and O-FreqPulse the settings body is
   correct and only the language body takes the deletion. Then re-read the file before step 3.
3. **`js/i18n.js` — the table.** Add the Chinese code to `LANGUAGES` and a `'zh-Hans'` value on
   **every** key in both `I18N` and `LABELS`, all at `reviewed: 'mt'` (R1), authored from the file
   as it stands after step 2.
4. **`index.html`** — the endonym `<option value="zh-Hans">` beside the fr option, its content
   **copied byte-for-byte from `plugins/O-Detune/Source/ui/public/index.html:1039`** and never
   retyped (P14). All five files already use the entity convention for the French endonym;
   confirm per plugin rather than assuming.
5. **Font work, in three separable halves (W1, P9, P10).** Serve the page, switch to Chinese, and
   run `node scripts/measure-ui.js --plugin <Name> --mode box --report all` — **after** the table
   lands, because before it the Han-gated screens are a vacuum (P11). Then:
   - **the tail half**, on stacks whose Latin is already safe: append before the trailing generic,
     at the sites named in P10;
   - **the face-naming half**, on the stacks whose only survivor is a generic: name an installed
     face, and add the tail as well wherever that node can receive Han;
   - **the form-4 half**, on the nodes `undeclared-font` names: a rule with **Arial FIRST** then
     the tail, so en/fr Latin metrics do not move.
   Record which sites took which treatment and why.
6. **`PluginProcessor.h`** — widen the two-way `languageCode` / `languageIndex` ternary to
   three-way, pure ASCII. There is no language parameter to touch (P13). Zero Chinese characters
   anywhere under `Source/`.
7. **Gate repair, every language site (P2, P3, P4, C5, C6)** — where a gate file exists: derive
   the language list from the table's own export, restructure the walk into a loop over that
   derived list, and generalize every per-language map lookup and comparison to run over the
   derived list minus English. Fire the derive-or-abort control against the **walk**. Word the
   explanatory comment as prose (C8).
8. **Geometry pass (R7, R8, N1, N9, N10, N11)** — run the zh arm of `check-ui-labels` and let it
   *name* the offenders, plus `measure-ui --report line-height-normal` and `--report wrap-count`.
   Expect four shapes: `line-height: normal` inheritance (pin each named **mover** at its measured
   English line box, derived from the box, per line, unitless, never global); a content-sized
   element that shrank and pulled its neighbours (a **floor**, never a fixed size); a Han run whose
   min-content width is one character in an auto-sized table or grid (`nowrap` **plus** a
   min-width); and Latin display conventions applied to Han, where `letter-spacing` and generous
   side padding are trimmed under `html[lang="zh-Hans"]` **with the trim value MEASURED** — the
   shipped precedent for that selector form is `plugins/O-Prism/Source/ui/public/index.html:1298`.
   Re-run until **0 moved** on all three arms, and name every `line-height-normal` residual with
   its measured `enH == zhH`.
9. **Commit at `'mt'`, blind reverse read, promote and ship.** Path-scoped
   `git commit -- plugins/<Name>` — the reverse pass runs against a committed tree. Then
   `--emit <Plugin> --plugin <Plugin>` to a fresh `--out` with `--forward-provenance`, dispatch to
   a blind reader (`claude -p "<prompt>" --model <model> --allowed-tools ""` from a cwd **outside**
   the repo, with repo access forbidden in the prompt), `--ingest` with an explicit `--manifest`
   and `--verbose`, batching tables above ~92 rows into chunks. Read **every** triple. For each
   drift the discriminator is **collision on the page**, not drift distance: can a reader on this
   page confuse this string with another control on the same page? A caption must also not collide
   with its own tooltip title. Re-author on collision; accept otherwise, and **write the reason
   down**. Then flip to `reviewed: 'bt'`, bump the version from the CMakeLists value (R9, P5),
   write the CHANGELOG entry naming the disclosed quality level and the +30% Han line-box figure,
   and `./scripts/build-and-install.sh <FolderName>` — the script resolves the `juce_add_plugin`
   target itself, so pass the **folder** name even on O-ReverseDelay and O-Marimba.

**Deferred to the end of the batch:** `auval`. A cold `auval` after an install rebuilds the whole
AU registry (~15 min); five separate runs would cost five rescans. Build and install all five,
then sweep once.

**`reviewed: 'native'` stays OPEN on all five and is not a blocker.** This project has no native
Chinese reader. A disclosed quality level, printed by lint rule R1 on every run and stated in all
five CHANGELOGs.
