### Q2. The gate's loader ALREADY EXISTS and publishes the wrong set of names

Wave 4d's M2 is about a gate with **no** path to the table. O-Tapestop's is the next case along and
it is a different, quieter shape: `tests/ui_tooltip_clamp_check.js` **already requires `vm`**
(L86), **already reads `js/i18n.js`**, and **already runs it in a context** (L201) — but the line
it publishes is:

```
L201  vm.runInContext(`${i18nSrc}\n;globalThis.__x = { I18N, TIP_BINDINGS };`,
```

`LANGUAGES` is not in that set, and the file contains **zero** references to it. So the derive has
a loader, an open sandbox and the table already parsed — and still nothing to derive from until
**one identifier** is added to that object literal.

**Why this is worth its own finding:** an executor who greps for `vm` or `runInContext` to decide
whether the loader work is needed gets a hit and concludes the file is ready. The loader is ready.
The *published set* is not. **Grep for `LANGUAGES`, not for the loader** — this file returns 0 and
1 respectively, and only the first number is the one that matters.

The edit is one identifier plus the derive, the shape assertion and the abort — roughly 12 lines,
against M2's ~35 for a loader built from nothing. Budget accordingly, and copy the shape from
`plugins/O-ReverseDelay/tests/ui_tooltip_clamp_check.js`, which shipped the repaired form in
wave 4d (see Q3).

## Execution shape — every long command runs in the BACKGROUND

**Non-negotiable, and the reason is a measured failure.** Wave 4d's first executor stalled on the
600-second no-progress watchdog **three times**, and a stalled agent's context cannot be resumed —
the work was lost and a fresh executor had to re-derive it. Every command in this plan that can
exceed ~60 seconds MUST be dispatched with `run_in_background: true` and polled, never run in the
foreground.

That covers, without exception:

| command class | why it stalls |
|---|---|
| `./scripts/build-and-install.sh <Folder>` | a full CMake + ninja build, minutes |
| `auval -v <type> <subtype> <mfr>` | a cold registry rescan is ~15 minutes for the sweep |
| `node scripts/measure-ui.js …` | Playwright, every state, three languages |
| `node scripts/check-ui-labels.js …` | same |
| `node scripts/boot-all-uis.js --strict-tips` | boots all 43 UIs |
| `node plugins/O-Tapestop/tests/ui_tooltip_clamp_check.js` | Playwright, 35 anchors × N languages |
| `node scripts/i18n-zh-lint.js` (repo-wide) | 43 plugins, 2312 entries |
| the blind reverse dispatch (`claude -p …`) | an external agent reading up to 92 rows |

Poll with an until-loop on a sentinel written by the backgrounded command itself
(`echo ALLDONE >> …`), not with a fixed `sleep`. **`timeout` does not exist on this machine.**

**Each task below is independently executable by a FRESH executor.** Each carries its own required
reading, its own precondition-fire block and its own commit stream. The orchestrator may dispatch
one executor per task. Nothing in Task 2 or Task 3 depends on holding Task 1's context — only on
Task 1's **committed artifacts and its written record**, which is why the tracer's findings are a
deliverable rather than a side effect.

## Stage-4 executor rules — non-negotiable, cited by number below

Carried verbatim from Stage 3 (R1–R9) and wave 4a (W1–W5), with waves 4b, 4c and 4d folded in.

- **R1 — Author at `'mt'`, always.** Never write `'bt'` at authoring time. `check-i18n` accepts
  `'bt'` as a valid enum member and the lint's R1 only reports entries *below* the bar, so a
  premature `'bt'` is invisible to every automated check in this repo. Promotion happens only after
  the reverse read, in its own commit. **And read the emitter's `rows` column rather than estimating
  a budget** — Q1, and the third wave running.
- **R2 — Read ALL triples with `--verbose`.** `--ingest` truncates to 12. Across five prior waves
  essentially no real finding ranked inside the default twelve. The score is a sort key, not a
  verdict.
- **R3 — Screen `TERMS` for page collisions BEFORE authoring.** Report any two *different* English
  keys mapping to one root that co-occur on a page. Qualify **both** sides, never one — **except**
  in M13's shape, where two *different* roots collide; there, qualify the side that is ambiguous
  about what it does and **write down why the other was left**.
- **R4 — Fresh blind reader AND fresh salt per correction round.** They guard different things: the
  salt stops correlation against seen ids, the fresh agent stops self-agreement. A correction round
  also needs a **different model** — a fresh session of the same model guards correlation but not
  self-agreement. A round that corrects nothing needs no round two; say so in the commit.
- **R5 / W4 — `--emit` is CORPUS-scoped and its own usage line is wrong. Pass BOTH `--emit
  <Plugin>` AND `--plugin <Plugin>`.** Following the usage line emits the entire corpus — **3073**
  already-shipped rows dispatched to an external reader as this plugin's work.
- **R6 — Pass `--manifest` explicitly and fire the blinding controls per batch.** ids pure 12-hex,
  no key fragment, **ids returned identical AND IN ORDER** (M12 — a reader can drop a row and
  return the right line count), rows well-formed with no Han surviving in the returned English, and
  a sha256 of the zh column against the committed tree. **Forbid repo access in the dispatch
  explicitly**, and dispatch from a cwd **outside the repo** with `--allowed-tools ""`.
  `--forward-provenance` is **REQUIRED at emit**: without it `--ingest` refuses rather than
  reporting, and that refusal is correct. **Fire both refusal controls** — the missing-provenance
  refusal and the wrong-manifest refusal — and record that each actually fired, per
  `pattern_withheld_source_leaks_via_ids_and_inert_provenance_check`. Expect the "no product name in
  the batch" control to report a **non-zero** count on any plugin whose own copy names itself.
  **Read the hit and adjudicate it; do not treat the count as pass/fail.**
- **R7 — zh geometry failures are SHRINKS. Assert equality, pin at the widest of three.**
- **R8 — A French-era `min-width` pin is a FLOOR, not safety.** Re-measure every one. Grep for
  existing declarations on a selector before appending, or a new pin at higher specificity silently
  un-pins a French one and moves the **fr** arm. **O-Lyrica's 30 min-width and 25 letter-spacing
  declarations are this wave's entire existing pin surface (Q14); the other four have none.**
- **R9 — Version truth is `CMakeLists.txt`.** Read the **value**; never grep for a literal; the
  value may be quoted **and may be held in a variable — on three of this wave's five (Q9)**. Use the
  two-arm reader unconditionally.
- **W1 — The CJK tail goes BEFORE the trailing generic.** Chromium resolves a bare `serif`,
  `sans-serif` or `monospace` against the document's `lang`, so under `zh-Hans` the generic is
  already a Chinese face and a tail written after it is never consulted. The shipped convention,
  copied verbatim from `plugins/O-Detune/Source/ui/public/index.html:57` and `:481`, is
  `…, 'PingFang SC', 'Microsoft YaHei', serif` for the serif arm and
  `Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif` for a form-4 rule, with the mono case
  placing the tail before its own generic.
- **W2 — OR the visibility flag across states.** `measure-ui` already does this and discloses the
  identity ratio on every run; any hand analysis must too.
- **W3 — Check `I18N_EXEMPT` membership BOTH ways.** Every exempt option word in an English body

  its localized caption instead. Units in a range clause follow the READOUT, not the prose. **One
  body can need both directions** (M10).
- **W5 — Expect a Z8 violation after any Latin→Han token swap.** A space that is correct while a
  token is Latin becomes an intra-Han space the moment it is replaced. Under the flipped gate this

- **C3 — Measure at the SHIPPING FRAME and walk the states CUMULATIVELY.** `measure-ui` parses the
