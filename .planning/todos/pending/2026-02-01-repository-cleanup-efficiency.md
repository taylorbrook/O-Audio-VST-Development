## Problem

Repository review identified ~1.5GB of removable content and several organizational issues:

### Critical (Immediate)
1. **847 .o files tracked in git** — Build artifacts inflating repo size
2. **build/ directory committed** — 1.1GB regenerated by cmake, shouldn't be in git
3. **6 local plugin build directories** — 400-500MB in plugins/O-{AnalogEQ,Comp,Marimba,SimpleReverb,Polystutter,Tremolo}/build/
4. **40 .DS_Store files** — macOS metadata pollution throughout repo

### High Priority
5. **Plugin naming inconsistencies** — 5 CMake plugin IDs don't match directory names:
   - OMarimba → O-Marimba
   - OuariconDigitalDelay → O-DigiDelay
   - OuariconAnalogEQ → O-AnalogEQ
   - OLyrica → O-Lyrica
   - OPolystutter → O-Polystutter

6. **Duplicate preset manager** — OuariconPresetManager.h copied in O-Bass, O-Comp, O-DigiDelay instead of using module

7. **tache_plugins orphaned** — 17 third-party plugins (6.9MB) not integrated into build

8. **Scattered documentation** — Content spread across /docs/, /research/, /.planning/

### Medium Priority
9. **backups/ directory** — 209MB redundant with git history; use tags instead
10. **.ideas/ directories** — ~30MB of old mockups; archive to separate branch
11. **.gitignore too minimal** — Only 2 entries, missing build artifacts

## Solution

### Phase 1: Git cleanup
```bash
# Update .gitignore
/build/
/plugins/*/build/
**/*.o
**/.DS_Store
/backups/

# Remove from tracking
git rm -r --cached build/
git rm --cached '**/.DS_Store'
find . -name ".DS_Store" -delete
rm -rf plugins/O-{AnalogEQ,Comp,Marimba,SimpleReverb,Polystutter,Tremolo}/build/
```

### Phase 2: Standardization
- Rename CMake plugin IDs to match directory names
- Remove duplicate preset managers, wire to module
- Decide on tache_plugins (integrate, archive, or remove)

### Phase 3: Organization
- Consolidate documentation structure
- Archive .ideas/ to separate branch
- Replace backups/ with git tags
