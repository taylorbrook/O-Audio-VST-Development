Create `.claude/scripts/inject-context.py` implementing the full context injection utility. The script must:

**Import discover-resources.py via importlib.util** (hyphenated filename requires this):
```python
import importlib.util
spec = importlib.util.spec_from_file_location("discover_resources", SCRIPT_DIR / "discover-resources.py")
discover_module = importlib.util.module_from_spec(spec)
spec.loader.exec_module(discover_module)
discover = discover_module.discover
resolve_role = discover_module.resolve_role
```

**Core function: `inject_context(plugin_name, stage, agent_type, keywords=None, token_budget=4000) -> str`**

Execution flow:
1. Call `discover(stage=stage, agent_role=agent_type, keywords=keywords, plugin_name=plugin_name)` to get ranked resources
2. Load stage-specific pattern file if applicable (stages 1-3 via STAGE_PATTERN_MAP)
3. Read and extract content from top-ranked resource files
4. Format into XML-delimited block
5. Enforce token budget
6. Return formatted string (or empty string on any error)

**Token budget allocation (hard cap: 4,000 tokens):**
- Stage pattern file: first priority, up to 2,500 tokens. If pattern file exceeds 2,500 tokens, truncate by keeping lines up to budget and appending truncation notice with file path.
- Primary tier resources (score >= 0.75): remaining budget minus 200 tokens. Extract frontmatter summary + first major section (## heading). Use `extract_content(filepath, max_tokens)` function.
- Supplementary tier mentions: 200 tokens reserved. One-line format: `- **{title}**: {summary}` plus file path.

**Token estimation: `estimate_tokens(text) -> int`**
- Use `int(len(text) / 3.5)` -- conservative heuristic, slightly overestimates for safety margin.

**Content extraction: `extract_content(filepath, max_tokens=800) -> str`**
- Parse YAML frontmatter with `re.match(r'^---\n(.*?)\n---\n?(.*)', content, re.DOTALL)` + `yaml.safe_load`
- Start with title (bold) and summary from frontmatter
- Add first ## section from body if within budget
- Append `_Full document: {filepath}_` for optional deeper reading
- Return empty string if file doesn't exist or parse fails

**Stage pattern auto-injection: `get_stage_pattern_content(stage, max_tokens=2500) -> str | None`**
```python
STAGE_PATTERN_MAP = {
    1: "troubleshooting/patterns/stage-1-patterns.md",
    2: "troubleshooting/patterns/stage-2-patterns.md",
    3: "troubleshooting/patterns/stage-3-patterns.md",
}
```
- Read full content of matching pattern file
- If tokens exceed max_tokens, truncate line-by-line and append: `\n_[Truncated for token budget. Full file: {path}]_`
- If file missing, print warning to stderr and return None

**Output format: `format_context_block(...)` -- use XML tags per research recommendation:**
```xml
<research_context>
## Relevant Research Resources

The following research has been automatically discovered as relevant
to your current task. Primary resources are MUST-READ.

### MUST-READ (Primary Tier)

**{title}** (relevance: {score})
{extracted content}

### Supplementary
- **{title}**: {summary}
  _Path: {path}_

### Stage Patterns (auto-injected)
{pattern file content}
</research_context>
```

Show relevance scores (per research recommendation). Order by relevance descending.

**Zero-result behavior:** When discovery returns zero results AND no stage pattern exists, return:
```xml
<research_context>
No relevant research resources discovered for this context.
</research_context>
```
If discovery returns zero results BUT a stage pattern exists, still return the pattern in a block.

**Graceful failure:** Wrap entire `inject_context()` body in try/except. On any exception, print `Warning: Context injection failed: {e}` to stderr and return empty string `""`.

**Missing file handling:** In `extract_content()`, if `Path(filepath).exists()` is False, print warning to stderr and return empty string. Same for stage pattern files.
