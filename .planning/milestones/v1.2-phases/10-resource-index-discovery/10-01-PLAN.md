  <action>
Install the jsonschema Python package:
```bash
pip3 install jsonschema
```

Create `.claude/resource-index.schema.json` using JSON Schema Draft 2020-12. The schema defines the manifest structure:

Top-level object with required fields:
- `$schema` (string) — self-reference to schema file
- `version` (string, const "1.0.0")
- `generated` (string, format date-time)
- `documents` (array of DocumentEntry)

No additional properties allowed at top level.

DocumentEntry definition (in `$defs`):
- `path` (string, pattern `^research/.+\.md$`)
- `title` (string, minLength 1, maxLength 150)
- `summary` (string, minLength 10, maxLength 500)
- `domain` (string, enum: dsp, ui, build, workflow)
- `type` (string, enum: algorithm, pattern, guide, reference)
- `keywords` (array of lowercase-hyphenated strings `^[a-z0-9-]+$`, minItems 3, maxItems 15)
- `stages` (array of integers 0-4, minItems 1)
- `agents` (array of strings enum: dsp, ui, build, research, minItems 1)

All DocumentEntry fields required, no additional properties.

Use the exact schema structure from the research document's "JSON Schema for resource-index.json" code example. The `$id` should be `"./resource-index.schema.json"`.

  <action>
Create `.claude/hooks/validators/validate-research-frontmatter.py` following the existing validator conventions (see contract_validator.py for patterns: dataclasses for results, pathlib for paths, exit codes 0/1/2).

The validator:
1. Accepts a file path as argv[1]
2. Checks if the file is in `research/` directory and is a `.md` file (skip non-research files silently with exit 0)
3. Skips files named `README.md` (exit 0 silently)
4. Parses YAML frontmatter using PyYAML (regex: `^---\n(.*?)\n---` with re.DOTALL)
5. Validates all required fields exist: title, summary, domain, type, keywords, stages, agents
6. Validates enum values: domain in {dsp, ui, build, workflow}, type in {algorithm, pattern, guide, reference}, agents items in {dsp, ui, build, research}
7. Validates keywords are lowercase alphanumeric with hyphens: `^[a-z0-9-]+$`
8. Validates stages are integers 0-4
9. Reports errors to stderr, exits with code 1 on errors, 0 on success

Use ONLY PyYAML (already installed) — do NOT import jsonschema in the hook (hooks have tight timeouts). This is structural validation only, not JSON Schema validation.

Include a `REQUIRED_FIELDS` set and `VALID_DOMAINS`, `VALID_TYPES`, `VALID_AGENTS` sets as module-level constants. Follow the validation hook pattern from the research document's "Frontmatter Validation Hook Pattern" code example.

Script should be executable (`chmod +x`).
