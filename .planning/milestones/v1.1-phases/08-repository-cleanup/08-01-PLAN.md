<task type="auto">
  <name>Task 2: Execute git history cleanup</name>
  <files>None (git operations only)</files>
  <action>
CRITICAL: This task rewrites git history. The backup branch provides recovery.

1. Create a fresh clone for cleanup (required by git-filter-repo):
   ```bash
   cd /Users/taylorbrook/Dev
   git clone https://github.com/taylorbrook/VST-development.git VST-cleanup-temp
   cd VST-cleanup-temp
   ```

2. Execute the cleanup with git-filter-repo:
   ```bash
   git filter-repo \
     --path build/ \
     --path backups/ \
     --path-glob '*.o' \
     --path-glob '*.a' \
     --path-glob '*.dylib' \
     --path-glob '*.DS_Store' \
     --path-glob '.ninja_deps' \
     --path-glob '.ninja_log' \
     --invert-paths
   ```

3. Re-add remote (git-filter-repo removes it for safety):
   ```bash
   git remote add origin https://github.com/taylorbrook/VST-development.git
   ```

4. Verify size reduction:
   ```bash
   du -sh .git
   ```
   Should be under 100MB (target: 50-80MB)

5. Verify history integrity:
   ```bash
   git log --oneline | head -20
   git fsck --full
   ```

6. Force push to origin:
   ```bash
   git push --force --all origin
   git push --force --tags origin
   ```

7. Update the original working directory:
   ```bash
   cd /Users/taylorbrook/Dev/VST-development
   git fetch origin
   git reset --hard origin/main
   ```

8. Remove the temporary clone:
   ```bash
   rm -rf /Users/taylorbrook/Dev/VST-cleanup-temp
   ```

IMPORTANT: The backups/ folder will also be removed from the working tree since it was in git history. This is expected - those files are preserved in the backup branch.
  </action>
