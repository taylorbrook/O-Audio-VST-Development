Create two files:

**merge-critic-reports.py** — Python utility for merging critic reports into unified severity-ranked output:
- Accept a list of report file paths as command-line arguments (or a directory path)
- Read each JSON report file
- Extract critic name, issues list from each report
- Normalize severity levels: "error" → "blocker" for unified consistency
- Severity order: blocker (0) > warning (2) > note (3) > info (4)
- Merge all issues into a single list sorted by severity (highest first)
- Each unified issue contains: severity, critic (source), id, category, location, description, fixSuggestion
- Compute counts: blocking_count, warning_count, note_count
- Compute `progression_allowed`: true only if blocking_count == 0
- Output JSON to stdout conforming to critic-report-unified.schema.json:
  ```json
  {
    "stage": "from first report or CLI arg",
    "plugin": "from first report or CLI arg",
    "timestamp": "ISO 8601",
    "critics_run": ["critic-dsp", "critic-architecture"],
    "unified_issues": [...sorted by severity...],
    "progression_allowed": true/false,
    "blocking_count": N,
    "warning_count": N,
    "note_count": N
  }
  ```
- Exit 0 if progression_allowed, exit 1 if blocked
- Handle edge cases: empty report files, reports with no issues, malformed JSON (skip with warning to stderr)
- Make the script importable as a module AND runnable as CLI (`if __name__ == "__main__"` pattern)
- Use structured JSON validation feedback format per Claude's Discretion: machine-parseable `errors[].type` fields with human-readable `message` strings

**critic-report-unified.schema.json** — JSON Schema (draft 2020-12) for unified critic output:
- Required properties: `stage` (string), `plugin` (string), `timestamp` (string, format: date-time), `critics_run` (array of strings), `unified_issues` (array), `progression_allowed` (boolean), `blocking_count` (integer, minimum 0), `warning_count` (integer, minimum 0), `note_count` (integer, minimum 0)
- `unified_issues` items schema: `severity` (enum: blocker, warning, note, info), `critic` (string), `id` (string, pattern: `^[A-Z]+-[0-9]+$`), `category` (string), `location` (string), `description` (string, minLength 10), `fixSuggestion` (string, minLength 10)
- Use `$schema: "https://json-schema.org/draft/2020-12/schema"` per project convention (JSON Schema draft 2020-12 from PROJECT.md key decisions)
- `additionalProperties: false` at top level
