<objective>
Implement persistent memory for five key agents so they retain learned patterns across sessions.

Purpose: Agents currently start every session with zero learned context. The dsp-agent rediscovers the same workarounds (e.g., ScopedNoDenormals for ARM), the troubleshoot-agent re-investigates known issues, and the validation-agent doesn't remember past patterns. By persisting agent learnings to `.claude/agent-memory/` files and injecting them via SubagentStart hooks, each agent starts with accumulated knowledge from previous plugin work.

Output: inject-agent-memory.sh hook, 5 seed memory files, updated settings.json with SubagentStart handler, 5 agent .md files with persistent_memory instructions.
</objective>

**Part A: Create `.claude/hooks/inject-agent-memory.sh`**

Create a SubagentStart hook script that:
1. Reads stdin to get the hook input JSON
2. Extracts `agent_type` from the input (use `jq -r '.agent_type // empty'`)
3. Constructs memory file path: `.claude/agent-memory/${AGENT_TYPE}.md`
4. If the memory file exists, read its content and output a JSON response with `additionalContext`:
   ```json
   {
     "hookSpecificOutput": {
       "hookEventName": "SubagentStart",
       "additionalContext": "<memory file content>"
     }
   }
   ```
5. If the memory file does not exist, exit 0 with no output (agent starts without memory)
6. Use `jq -n --arg ctx "$CONTENT"` to properly escape the content for JSON
7. Make executable (chmod +x)

**Part B: Create `.claude/agent-memory/` directory with 5 seed files**

Create seed memory files for each of the 5 agents. Each file follows this template:

```markdown

## Learned Patterns
(No patterns recorded yet. This agent will add learnings from plugin work here.)

## Common Issues
(No issues recorded yet.)

## Last Updated
(Not yet updated)
```
