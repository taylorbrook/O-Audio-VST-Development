Create the workflow directory structure:

```
.planning/workflow/
├── schemas/
│   ├── registry.schema.json
│   ├── checkpoint.schema.json
│   └── active-plugin.schema.json
└── checkpoints/
    └── .gitkeep
```

For registry.schema.json, adapt from existing `.claude/schemas/plugin-registry.schema.json`:
- Use JSON Schema draft 2020-12
- Add $id field pointing to relative path
- Keep PluginEntry with: path, stage, phase, status, created, lastActivity, modules, expressMode, blockedBy
- Add version field (string, semver format)
- Add focused field (string or null)
- Use strict additionalProperties: false

For checkpoint.schema.json, create from RESEARCH.md pattern:
- version: "1.0.0" (literal)
- plugin: string
- timestamp: ISO 8601 datetime
- stage: string (e.g., "2-dsp")
- phase: enum ["discuss", "research", "plan", "execute", "verify"]
- task: object with plan (string), taskNumber (integer), taskTitle (string)
- state: object with completedTasks (int array), remainingTasks (int array), handoffContext (string)
- filesModified: string array

For active-plugin.schema.json:
- plugin: string or null
- focusedAt: ISO 8601 datetime or null
- loadedContext: object with statusMd (boolean), currentPlan (string or null), currentContext (string or null) - optional

All schemas must have additionalProperties: false at the root level.
  </action>
