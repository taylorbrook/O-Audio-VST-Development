**Create common type first:**

`.claude/schemas/agent-contracts/common/plugin-reference.json`:
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "common/plugin-reference",
  "title": "Plugin Reference",
  "description": "Standard plugin identifier used across contracts",
  "type": "object",
  "required": ["plugin_name"],
  "properties": {
    "plugin_name": {
      "type": "string",
      "minLength": 1,
      "pattern": "^[A-Z][a-zA-Z0-9-]*$",
      "description": "Plugin name matching directory in plugins/"
    }
  },
  "additionalProperties": false
}
```

**Create schemas for plugin-workflow, build-automation, plugin-ideation:**

Per CONTEXT.md decisions:
- Most fields required (strict)
- `additionalProperties: false` (reject unknown fields)
- Use draft 2020-12 $schema
- Include $id for reference

Schema structure:
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "{agent-name}.input",
  "title": "{Agent Name} Input Contract",
  "description": "Required inputs for {agent-name} invocation",
  "type": "object",
  "required": [...],
  "properties": {
    // Derive from AUDIT.md "Actual Inputs" section
  },
  "additionalProperties": false
}
```

For output schemas, include conditional requirements using `if/then`:
```json
{
  "if": { "properties": { "status": { "const": "failure" } } },
  "then": { "required": ["error"] }
}
```

Reference 01-RESEARCH.md code examples for exact patterns.
