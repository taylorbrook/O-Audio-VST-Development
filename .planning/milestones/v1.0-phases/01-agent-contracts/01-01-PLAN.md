```markdown
# Agent Contract Schemas

JSON Schema definitions for agent input/output contracts.

## Schema Naming Conventions

- Input schemas: `{agent-name}.input.json`
- Output schemas: `{agent-name}.output.json`
- Shared types: `common/{type-name}.json`

## Schema Version

All schemas use JSON Schema draft 2020-12.

## Validation Rules

Per CONTEXT.md decisions:
- Most fields required (strict)
- `additionalProperties: false` (rejects unknown fields)
- Error messages must be actionable

## Directory Structure

```
agent-contracts/
├── README.md                    # This file
├── common/                      # Shared type definitions
│   └── plugin-reference.json    # Reusable plugin identifier
├── plugin-workflow.input.json
├── plugin-workflow.output.json
├── build-automation.input.json
├── build-automation.output.json
... (one pair per core agent)
```

## Adding a New Schema

1. Create `{agent-name}.input.json` with $schema and $id
2. Create `{agent-name}.output.json` with $schema and $id
3. Reference from agent's SKILL.md or agent file
4. Add to CHANGELOG.md

## Versioning

Per CONTEXT.md: Full semver (MAJOR.MINOR.PATCH)
- MAJOR: Breaking changes (removed/renamed fields)
- MINOR: New optional fields
- PATCH: Documentation, formatting

Central changelog: `.claude/schemas/CHANGELOG.md`
```

This establishes the foundation for Plan 02 to create actual schemas.
