<task type="auto">
  <name>Task 2: Create run-code-review.sh script</name>
  <files>.planning/workflow/scripts/run-code-review.sh</files>
  <action>
Create bash script that prompts user for code review at stage boundaries:

**Arguments:**
- Usage: run-code-review.sh [plugin] [stage] [--skip-review]
- Exit codes: 0=APPROVED, 1=CHANGES_REQUESTED or BLOCKED, 2=SKIPPED (with justification)

**Workflow:**
1. Display stage-specific checklist from template
2. Render template with [PLUGIN] and [STAGE] replaced
3. Display checklist sections relevant to current stage
4. Prompt for verdict (approved/changes/blocked)
5. If not approved, prompt for notes
6. Save review-notes.md to plugins/[Plugin]/.planning/stages/[stage]/

**Skip handling (per CONTEXT.md):**
- --skip-review prompts for justification
- Justification logged to plugins/[Plugin]/.planning/gate-bypasses.log
- Returns exit code 2 (SKIPPED)

**Display format:**
- Use ANSI colors for visual hierarchy
- Show checklist items as reminders (user checks mentally, not automated)
- Prompt for verdict interactively

**Integration point:**
- run-gate.sh (plan 05-01) will invoke this script at end of gate if automated checks pass
- Plan 05-03 will wire this invocation

Make script executable (chmod +x).
  </action>
