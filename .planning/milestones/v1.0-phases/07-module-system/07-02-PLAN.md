  <action>
Create compute-hash.py that computes SHA-256 hash of a module's source files.

The script should:
1. Accept module path as argument: ./compute-hash.py modules/tuning/scala-tuning-engine
2. Find all source files (recursively):
   - Include: *.cpp, *.h, *.hpp, *.js, *.ts, *.yaml, *.json, *.md
   - Exclude: hidden files (.*), __pycache__, node_modules
3. Sort file paths for deterministic ordering
4. Hash file contents using SHA-256:
   - For each file: update hasher with file path (relative) + file contents
   - This ensures renamed files produce different hashes
5. Output: sha256:{first 16 hex characters}

Example output:
```
sha256:a1b2c3d4e5f6g7h8
```

Algorithm (from RESEARCH.md):
```python
import hashlib
from pathlib import Path

def compute_module_hash(module_path: Path) -> str:
    hasher = hashlib.sha256()
    extensions = {'.cpp', '.h', '.hpp', '.js', '.ts', '.yaml', '.json', '.md'}

    for file_path in sorted(module_path.rglob("*")):
        if file_path.is_file() and not file_path.name.startswith('.'):
            if file_path.suffix in extensions:
                rel_path = str(file_path.relative_to(module_path))
                hasher.update(rel_path.encode())
                hasher.update(file_path.read_bytes())

    return f"sha256:{hasher.hexdigest()[:16]}"
```

Add --verify flag that compares computed hash against a provided hash:
./compute-hash.py modules/tuning/scala-tuning-engine --verify sha256:a1b2c3d4e5f6g7h8
Exit 0 if match, exit 1 if mismatch.
