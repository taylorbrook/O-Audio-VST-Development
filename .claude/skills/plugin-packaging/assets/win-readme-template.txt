INSTALLATION LOCATION

After installation, {{PLUGIN_NAME}} will be available in:
  C:\Program Files\Common Files\VST3\{{PRODUCT_NAME}}.vst3

Note: Windows supports VST3 format only (no AU).

SYSTEM REQUIREMENTS

- Windows 10 or Windows 11 (64-bit)
- Compatible DAW with VST3 support

DAW SETUP

Ableton Live:
  Options > Preferences > Plug-ins > enable "Use VST3 Plug-in System Folder"
  Rescan plugins or restart Ableton

FL Studio:
  Options > Manage Plugins > click "Find plugins" or "Start scan"
  The standard VST3 path is scanned automatically

Reaper:
  Options > Preferences > VST > Add path: C:\Program Files\Common Files\VST3
  Click "Re-scan" or restart Reaper

Bitwig Studio:
  Settings > Plug-ins > enable "VST3" and scan
  The standard VST3 path is scanned automatically

Studio One:
  Studio One > Options > Locations > VST Plug-ins
  Add path if needed: C:\Program Files\Common Files\VST3
  Rescan from Instruments/Effects browser

UNINSTALL

To remove {{PLUGIN_NAME}}:
  1. Open Settings > Apps > Installed apps (or Control Panel > Programs and Features)
  2. Search for "{{PRODUCT_NAME}} VST3 by Ouaricon Audio"
  3. Click Uninstall and follow the prompts

Alternatively, manually delete:
  C:\Program Files\Common Files\VST3\{{PRODUCT_NAME}}.vst3
Then rescan plugins in your DAW.
