## 1. Commercial Spatial Audio Plugins

### Tier 1: Professional / High-End

#### FLUX:: SPAT Revolution
- **Website:** https://www.flux.audio/project/spat-revolution/
- **Pricing:** Essential $359 (perpetual) | Ultimate ~$1,790 (perpetual) or $125/month subscription
- **Techniques:** Object-based spatialization, Ambisonics (up to 7th order), binaural, WFS (Wave Field Synthesis), VBAP, DBAP, HOA, KNN, transaural
- **Key Features:**
  - Standalone application with DAW integration via Send/Return plugins (AAX, AU, VST3)
  - Real-time room simulation with perceptual acoustic parameters
  - Supports standard hardware audio interfaces and network audio (Dante, AVB, MADI)
  - Advanced source/room visualization
  - Automation from DAW, OSC, RTTrPM, ADM-OSC
- **Market Position:** Top-of-line professional tool for broadcast, live sound, post-production, and immersive installations. The most feature-complete spatialization engine available.
- **Status:** Actively developed and maintained.

#### Dolby Atmos Renderer / Production Suite
- **Website:** https://professional.dolby.com/
- **Pricing:** Subscription-based ($299/year for Music, variable for Post)
- **Techniques:** Object-based + bed (channel-based) hybrid rendering, binaural monitoring
- **Key Features:**
  - Deep DAW integration (Pro Tools, Logic Pro, Nuendo)
  - Industry standard for immersive music delivery (Apple Music, Tidal, Amazon Music)
  - Object panning, bed routing, binaural monitoring
  - Required for Dolby Atmos deliverables
- **Market Position:** De facto standard for commercial immersive music delivery. Not a creative spatial tool per se, but the required endpoint.

#### NUGEN Audio Halo Suite
- **Website:** https://nugenaudio.com/halosuite/
- **Pricing:** Halo Upmix ~$483 | 3D Immersive Extension ~$194 | Suite bundle saves ~$498
- **Techniques:** Algorithmic upmixing, neural dialog extraction, surround/immersive
- **Key Features:**
  - Natural upmix from stereo to 5.1, 7.1, 7.1.4, Atmos beds
  - No artificial reverb/chorus/delay added
  - Ambisonic output support
  - Pro Tools, Nuendo integration for Atmos workflows
- **Market Position:** Professional broadcast/post-production upmixing. Standard tool for content repurposing.

### Tier 2: Mid-Range Creative Tools

#### Dear Reality dearVR PRO 2 / dearVR MUSIC
- **Website:** https://www.sennheiser.com/en-us/immersive/dear-reality

  - Formats: 9.0.4, 9.1.4, 9.0.6, binaural, Ambisonics
- **Market Position:** Was the most popular mid-range spatial plugin for music production.
- **CRITICAL STATUS NOTE (2025):** Sennheiser/Dear Reality announced products will no longer be developed or maintained. Licenses deactivated July 31, 2025. Users should seek alternatives. This creates a significant market gap.

| Segment | Price Range | Key Players | Status |
|---------|------------|-------------|--------|
| Pro Broadcast/Post | $359-$1,790+ | SPAT Revolution, Dolby, NUGEN | Stable, enterprise |

## 2. Free / Open-Source Spatial Audio Plugin Suites

### IEM Plug-in Suite
- **Website:** https://plugins.iem.at/
- **GitHub:** https://github.com/tu-studio/IEMPluginSuite
- **License:** GPLv3
- **Formats:** VST, AU, LV2 (macOS, Windows)
- **Built with:** JUCE
- **Ambisonics order:** Up to 7th order
- **Plugins (20+):**
  - **AllRADecoder** - Loudspeaker decoder with AllRAD algorithm
  - **BinauralDecoder** - Binaural Ambisonics decoder
  - **DirectionalCompressor** - Spatial domain compressor
  - **DirectivityShaper** - Shape source directivity in Ambisonics
  - **DistanceCompensator** - Level/delay compensation for speaker arrays
  - **DualDelay** - Ambisonic delay with DAW sync
  - **EnergyVisualizer** - Real-time energy distribution visualization
  - **FdnReverb** - Feedback delay network reverb
  - **GranularEncoder** - Ambisonic granular synthesizer (first of its kind)
  - **MatrixMultiplier** - Flexible Ambisonics matrix processing
  - **MultiBandCompressor** - Spatial-image-preserving multiband compressor
  - **MultiEncoder** - Multi-source Ambisonic encoder
  - **MultiEQ** - Ambisonic equalizer
  - **OmniCompressor** - Omnidirectional Ambisonic compressor
  - **ProbeDecoder** - Decode/monitor single direction
  - **RoomEncoder** - Room simulation in Ambisonics
  - **SceneRotator** - Rotate Ambisonic scenes (head tracking)
  - **SimpleDecoder** - Simple loudspeaker decoder
  - **StereoEncoder** - Stereo-to-Ambisonics encoder
  - **ToolBox** - Format conversion utilities
- **Strengths:** Most comprehensive free Ambisonic suite. Academic rigor. Active maintenance.
- **Weaknesses:** Academic UI, not particularly user-friendly for music producers. Steep learning curve.

### SPARTA (Spatial Audio Real-Time Applications)
- **Website:** https://leomccormack.github.io/sparta-site/
- **GitHub:** https://github.com/leomccormack/SPARTA
- **License:** GPLv3
- **Formats:** VST, VST3, AU, LV2, AAX
- **Built with:** JUCE + Spatial Audio Framework (SAF)
- **Ambisonics order:** Up to 10th order
- **Plugin Suites Included:**
  - **SPARTA Suite:**
    - AmbiBIN - Binaural Ambisonics decoder with SOFA loader, head tracking via OSC, multiple decoding methods (LS, SPR, TA, Mag-LS)
    - AmbiDEC - Frequency-dependent loudspeaker decoder (up to 128 speakers)
    - AmbiDRC - Dynamic range compression in the spherical harmonic domain
    - AmbiENC - Ambisonics encoder/panner (up to 128 inputs)
    - Array2SH - Convert microphone array signals to spherical harmonics
    - Beamformer - Beamforming from spherical harmonic signals
    - Binauraliser - Direct binaural rendering with SOFA HRTF loading
    - Decorrelator - Adaptive signal decorrelation
    - DirASS - Directional Audio Source Separator
    - MatrixConv - Matrix convolver
    - MultiConv - Multi-channel convolver
    - Panner - VBAP-based panner
    - PowerMap - Sound-field visualization
    - Rotator - Scene rotation
    - SLDoA - Spatial Localization of Directions of Arrival
    - Spreader - Source spreading/widening
  - **COMPASS Suite:** Parametric spatial audio processing
  - **HO-DirAC Suite:** Higher-order Directional Audio Coding
  - **CroPaC Binaural Decoder**
  - **HO-SIRR:** Room impulse response renderer
- **Strengths:** Most technically advanced open-source spatial suite. 10th-order Ambisonics. Built-in SOFA support. Excellent for research and production.
- **Weaknesses:** Optimized for Reaper. GPLv3 license restricts commercial use. Academic UIs.

### Ambisonic Toolkit (ATK)
- **Website:** https://www.ambisonictoolkit.net/
- **GitHub:** https://github.com/ambisonictoolkit
- **License:** LGPLv3 (more permissive than GPL)

## 3. Open-Source C++ Libraries for Spatialization

### Spatial Audio Framework (SAF) -- RECOMMENDED
- **GitHub:** https://github.com/leomccormack/Spatial_Audio_Framework
- **License:** ISC License (very permissive, BSD-like, commercial-friendly)
- **Language:** C/C++
- **Documentation:** https://leomccormack.github.io/Spatial_Audio_Framework/
- **Core Modules:**
  - `saf_hoa` - Higher-order Ambisonics encoding/decoding (binaural + loudspeaker)
  - `saf_sh` - Spherical harmonic and spherical array processing
  - `saf_vbap` - Vector-base Amplitude Panning
  - `saf_cdf4sap` - Covariance Domain Framework for Spatial Audio Processing
  - `saf_hrir` - HRIR/HRTF loading and processing
  - `saf_reverb` - Room simulation and reverb algorithms
  - `saf_utilities` - Cross-platform utilities, FFT wrappers
- **HRTF/SOFA Support:** Built-in SOFA loading via libmysofa or netcdf
- **Performance Libraries:** Intel MKL, Apple Accelerate, OpenBLAS, SIMD (SSE, AVX, AVX-512)
- **JUCE Integration:** Proven integration via SPARTA plugins (20+ JUCE plugins built on SAF)
- **Key Strengths:**
  - ISC license allows commercial use without restriction
  - Extremely comprehensive spatial audio algorithms
  - Proven in production (SPARTA suite)
  - Active development by Leo McCormack (Aalto University)
  - CMake build system
- **Assessment:** **Best candidate for JUCE plugin integration.** Permissive license, comprehensive algorithms, proven JUCE compatibility, and active maintenance.

### libmysofa
- **GitHub:** https://github.com/hoene/libmysofa
- **License:** BSD 3-Clause
- **Language:** C
- **Key Features:**
  - Lightweight SOFA file reader
  - Minimal dependencies
  - CMake integration (find_package support)
  - Normalizes HRTF data on load
  - Checks SimpleFreeFieldHRIR compliance
  - Suitable for embedded/plugin use
- **Key Functions:** `mysofa_open()`, `mysofa_getfilter_float()`, `mysofa_close()`
- **Assessment:** Essential building block for any plugin loading user-provided SOFA HRTFs. Lightweight and permissively licensed. Used by SAF internally.

### Google Resonance Audio
- **GitHub:** https://github.com/resonance-audio/resonance-audio
- **License:** Apache 2.0
- **Language:** C++
- **Key Features:**
  - Binaural rendering with HRTF
  - Ambisonics encoding/decoding
  - Sound source spatialization
  - Room effects (early reflections, late reverb)
  - Occlusion and near-field effects
  - Cross-platform (iOS, Android, Windows, macOS, Linux, Web)
- **Game Engine Integration:** Unity, Unreal, FMOD, Wwise
- **Assessment:** Originally designed for VR/AR. Very capable for game audio. Development appears to have slowed since Google open-sourced it in 2018. Community maintains engine plugins. Apache 2.0 license is commercial-friendly. Good reference implementation but may require effort to integrate with JUCE audio plugin architecture.

### Steam Audio (Valve)
- **GitHub:** https://github.com/ValveSoftware/steam-audio
- **License:** Apache 2.0 (fully open-sourced February 2024)
- **Language:** C++
- **Key Features:**
  - HRTF-based binaural rendering
  - Physics-based sound propagation (ray tracing)
  - Occlusion, transmission, reflection modeling
  - Ambisonics support
  - Real-time and baked propagation
  - Geometry-aware reverb
- **Assessment:** Most advanced physics-based spatial audio engine available as open source. Apache 2.0 is commercial-friendly. Designed for games but the core DSP is applicable to plugins. Would need adapter layer for JUCE integration. Excellent for occlusion/propagation if building game-audio-style spatialization.

### 3D Tune-In Toolkit (3DTI)
- **GitHub:** https://github.com/3DTune-In/3dti_AudioToolkit
- **License:** GPL v3
- **Language:** C++
- **Key Features:**
  - Real-time binaural spatialization
  - HRIR convolution with overlap-save algorithm
  - Barycentric HRIR interpolation
  - Acoustic parallax (independent left/right ear HRIR selection)
  - Interaural Time Difference (ITD) customization by head size
  - Near-field source simulation
  - Distance-based frequency attenuation (air absorption)
  - Ambisonic-based reverberation with BRIR convolution
  - Hearing aid and hearing loss simulation
- **Assessment:** Excellent binaural renderer with unique hearing-accessibility features. GPL license limits commercial redistribution. Good reference for high-quality HRTF convolution algorithms.

### OpenAL Soft
- **GitHub:** https://github.com/kcat/openal-soft
- **License:** LGPL v2
- **Language:** C/C++ (C++17)
- **Latest Version:** 1.24.3
- **Key Features:**
  - 3D audio positioning API
  - Built-in HRTF support for headphone rendering
  - Ambisonics (up to 3rd order B-Format)
  - Environmental effects (reverb, occlusion, obstruction via EFX)
  - Multi-channel output (mono through 7.1, HRTF, UHJ, B-Format)
- **Assessment:** Mature, battle-tested 3D audio API. LGPL allows linking in commercial software. Designed as a system-level audio API rather than a DSP library, so integration into a JUCE plugin would be architecturally awkward. Better suited as a reference for HRTF and Ambisonics algorithms.

### VISR (Versatile Interactive Scene Renderer)
- **Website:** https://www.s3a-spatialaudio.org/visr
- **License:** BSD-style (open source)
- **Language:** C++ core with Python API
- **Key Features:**
  - Modular signal processing framework
  - Object-based audio rendering
  - VBAP, Ambisonics, binaural rendering
  - Python rapid prototyping
  - DAW/Max/MSP integration capability
  - Runtime component library with FIR/IIR filtering, delay lines, gain matrices
- **Assessment:** Academic framework from University of Surrey. Good for research but less actively maintained than SAF. Python integration is interesting for prototyping but not useful for JUCE plugins.

### libspatialaudio
- **GitHub:** https://github.com/videolabs/libspatialaudio
- **License:** LGPL v2.1
- **Language:** C++
- **Key Features:**
  - Ambisonic encoding/decoding
  - Binauralization
  - Used in VLC media player
- **Assessment:** Lightweight library used in VLC. LGPL license allows commercial linking. Less feature-complete than SAF but simpler to integrate for basic Ambisonic needs.

## 4. HRTF Datasets

### Major Free Datasets

#### MIT KEMAR
- **URL:** https://sound.media.mit.edu/resources/KEMAR.html
- **Subjects:** 1 (KEMAR dummy head)
- **Measurements:** 710 directions
- **Format:** WAV, also available in SOFA
- **Sampling Rate:** 44.1 kHz
- **License:** Free, citation required
- **Notes:** The classic reference HRTF. Used in countless publications. Small/large pinnae variants. Widely used as a "generic" HRTF for headphone rendering.

#### CIPIC Database
- **URL:** https://www.ece.ucdavis.edu/cipic/spatial-sound/hrtf-data/
- **GitHub (SOFA):** https://github.com/amini-allight/cipic-hrtf-database
- **Subjects:** 45 (public release, 90+ total measured)
- **Measurements:** 1,250 directions per subject (25 azimuths x 50 elevations)
- **Format:** MATLAB, SOFA conversion available
- **Sampling Rate:** 44.1 kHz
- **HRIR Length:** 200 samples
- **License:** Public domain (Release 1.0)
- **Notes:** High spatial resolution. Includes KEMAR with small and large pinnae. One of the most widely used individual HRTF datasets. Includes anthropometric measurements for personalization research.

#### LISTEN Database (IRCAM)
- **URL:** http://recherche.ircam.fr/equipes/salles/listen/download.html
- **Subjects:** ~50
- **Measurements:** 187 directions per subject
- **Format:** WAV, MATLAB
- **Sampling Rate:** 44.1 kHz
- **License:** Free for research
- **Notes:** Raw and compensated (equalized) versions. From IRCAM, a leading audio research institute.

#### ARI HRTF Database
- **URL:** https://sofacoustics.org/data/database/ari/
- **Project Page:** https://projects.ari.oeaw.ac.at/research/experimental_audiology/hrtf/database/hrtfItEARI.html
- **Subjects:** 220+
- **Format:** SOFA
- **License:** Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)
- **Notes:** Large subject pool. In-the-ear measurements. Equalized at various frequency ranges. CC BY-SA means derivative works must share under same license -- important consideration for commercial plugins.

#### SONICOM HRTF Dataset
- **URL:** https://www.sonicom.eu/tools-and-resources/hrtf-dataset/
- **Subjects:** 300 (extended dataset, 2024)
- **Measurements:** High-resolution, full-sphere
- **Includes:** HRTFs, HpTFs, depth pictures, 3D ear/head/torso scans, synthesized HRTFs via Mesh2HRTF
- **Format:** SOFA
- **License:** MIT License
- **Notes:** **Newest and largest high-quality HRTF dataset.** MIT license is ideal for commercial use. Includes 3D scans for personalization. Part of the Listener Acoustic Personalization Challenge. Accompanied by Spatial Audio Metrics (SAM) Python toolbox.

#### RWTH Aachen KEMAR High-Resolution
- **URL:** https://www.akustik.rwth-aachen.de/cms/institut-fuer-hoertechnik-und-akustik/forschung/~lsly/hrtf-datenbank/
- **Subjects:** 1 (KEMAR)
- **Measurements:** High-resolution (2702 directions on full sphere)
- **Format:** SOFA
- **Notes:** Extremely high spatial resolution. Accompanied by 3D scan of the KEMAR head.

### SOFA Format Overview

**SOFA (Spatially Oriented Format for Acoustics)** is the standardized file format for HRTF data.

- **Standard:** AES69-2015 (Audio Engineering Society)
- **File format:** Based on NetCDF-4 / HDF5
- **Convention for HRTFs:** SimpleFreeFieldHRIR
- **Advantages:**
  - Standardized metadata (position, sampling rate, listener/source info)
  - Self-documenting files
  - Supported by all major spatial audio tools
  - Growing repository at https://sofacoustics.org/data/database/
- **Software support:**
  - libmysofa (lightweight C reader)
  - SOFA Toolbox v2.4 (MATLAB, latest July 2025)
  - SOFApy (Python)
  - Supported natively by SAF, SPARTA, IEM Suite, OpenAL Soft

### Dataset Comparison for Plugin Distribution

| Dataset | Subjects | License | Commercial OK | SOFA Available | Best For |
|---------|----------|---------|---------------|----------------|----------|
| **MIT KEMAR** | 1 | Free (cite) | **Yes** | Yes | Default/fallback HRTF |
| **CIPIC** | 45 | Public domain | **Yes** | Yes | User-selectable HRTFs |
| **LISTEN** | ~50 | Research | Unclear | Conversion needed | Research reference |
| **ARI** | 220+ | CC BY-SA 3.0 | Conditional* | Yes | Large subject pool |
| **SONICOM** | 300 | **MIT** | **Yes** | Yes | **Best for commercial** |
| **RWTH KEMAR** | 1 | Research | Check terms | Yes | High-res default HRTF |

*CC BY-SA requires derivative works to share under same license.

**Recommendation for plugin distribution:**
1. **Ship with:** MIT KEMAR as default (small, universally recognized, free)
2. **Optional loading:** Support user-provided SOFA files via libmysofa
3. **Bundled selection:** Include a curated subset from SONICOM (MIT license, 300 subjects, ideal for personalization)
4. **Avoid bundling:** ARI (CC BY-SA share-alike restrictions) and LISTEN (unclear commercial terms)

## 6. Strategic Analysis & Opportunities

### Market Gaps (as of early 2026)

1. **Mid-range binaural panner with room simulation** -- dearVR's discontinuation leaves a clear gap. No single plugin under $200 combines intuitive binaural 3D panning, quality room simulation, and Ambisonics encoding in a modern, user-friendly package.

2. **SOFA-loading binaural plugin with modern UI** -- Existing SOFA-capable tools (SPARTA AmbiBIN, sofapan) have academic/research UIs. A polished, WebView-based UI with visual 3D positioning would be differentiated.

3. **Personalized HRTF selection** -- With 300 subjects in SONICOM (MIT license), a plugin could offer a "find your best match" feature based on listener characteristics. No commercial plugin does this well.

4. **Cross-format spatial plugin** -- A plugin that simultaneously outputs binaural (headphones), stereo (speakers with cross-talk cancellation), and Ambisonics (for further processing) from a single instance.

### Recommended Technical Stack for a JUCE Spatial Plugin

```
DSP Core:       Spatial Audio Framework (SAF) -- ISC license
SOFA Loading:   libmysofa -- BSD-3 license
Default HRTF:   MIT KEMAR -- free, cite
Optional HRTFs: SONICOM subset -- MIT license
GUI:            JUCE WebView (WebBrowserComponent)
Visualization:  WebGL-based 3D source positioning
Head Tracking:  OSC input (compatible with head trackers)
Output Formats: Binaural stereo, 1st-7th order Ambisonics, speaker layouts
```

### Key Technical Approaches

1. **Binaural rendering via HRTF convolution** -- Core technique. Convolve mono/stereo input with interpolated HRIRs based on source azimuth/elevation/distance. SAF provides optimized implementations.

2. **Ambisonics encoding/decoding** -- Encode sources into Ambisonics domain, decode to binaural or loudspeaker layouts. Flexible and format-agnostic. SAF supports up to 10th order.

3. **VBAP (Vector Base Amplitude Panning)** -- For loudspeaker rendering. Simple, efficient, widely understood. SAF module available.

4. **Room simulation** -- Early reflections via image-source method + late reverberation via FDN. Creates externalization and distance perception. SAF includes reverb module.

5. **Near-field correction** -- Distance-dependent filtering to simulate proximity effect. Important for realistic distance rendering beyond simple level attenuation.
